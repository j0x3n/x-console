# 产品说明

## 使用者和场景

只有一个用户，就是你。面板部署在一台服务器上，电脑和手机都能打开。
典型的一天是这样：

- 早上 8 点，Telegram 收到早报：今天的日程、到期的 Issue、昨晚服务器有没有告警、天气。
- 上班时打开面板，在项目看板上挑一个 Issue，点“交给编码助手”。家里电脑上的代理用 Claude Code 在对应仓库里开一个 worktree 干活。
- 每隔一小时收到喝水提醒，在手机通知上点“喝了”就算打卡。
- 下午收到告警：tokyo-1 磁盘用了 92%。点进去开终端清理日志。
- 编码任务跑完，面板推送通知。你看 diff，点“提交并建 PR”。
- 晚上在面板里点一下关掉客厅的灯，顺手记一条笔记。

## 已确认的决定

| 事项 | 结论 |
| --- | --- |
| 部署 | 面板和 API 在一台服务器上。Windows 本机和各台 Linux 装代理，代理主动连服务器 |
| 后端 | Go。数据库 SQLite |
| 编码执行器 | Claude Code 和 Codex CLI 都支持，建任务时选 |
| 项目管理 | 自建，可选和 Linear 双向同步 |
| 通知渠道 | 站内、Web Push、Telegram、Bark、Server酱 |
| 登录 | 单用户，密码登录，两步验证可选，高危操作要 5 分钟内再验证一次 |

## 模块和验收标准

编号在所有文档和任务卡里通用。每个模块的细节在 `specs/Mx.md`。

### M0 基础（已完成）

- 首次打开走初始化：设用户名密码，扫码绑定 TOTP。
- 登录要用户名、密码、验证码。连续失败 5 次，这个 IP 锁 15 分钟。
- 配对设备、吊销设备这类操作要求 5 分钟内验证过 TOTP。
- 所有写操作记审计日志，设置页能翻看。
- 站内通知中心：未读红点、全部已读、点击跳转。
- 设备页能看到代理在线状态。

### M1 今日（首页）

- 版式参考初版的“今日”：问候、一排概要卡片、今日待办、日程、习惯、最近动态。
- 卡片可以隐藏和排序，布局保存在服务端。
- 首屏在 1 秒内出来。单个卡片出错不影响别的卡片。

### M2 服务器

- 列表显示每台服务器的在线状态、CPU、内存、磁盘、负载，数据 10 秒刷新一次。
- 详情页有 1 小时、24 小时、7 天的指标曲线。
- 进程列表可排序，可结束进程（要二次验证）。
- systemd 服务列表，可启动、停止、重启、看最近日志。
- Web 终端，基于 xterm.js，窗口大小变化会同步。
- 上传和下载文件，单个文件最大 1 GB。
- 没装代理的服务器可以只登记 SSH 信息，提供终端和执行命令。
- 告警规则：CPU、内存、磁盘、离线超过 N 分钟，触发后发通知。

### M3 本机

- 和 M2 一样看指标、进程、Windows 服务、PowerShell 终端、传文件。
- 剪贴板：把手机上的文字发到电脑剪贴板，也能取回电脑剪贴板。
- 快捷操作：锁屏、睡眠、关机、打开指定程序或网址。关机要二次验证。
- 本机离线时页面明确提示，并显示最后在线时间。

### M4 编码任务

- 登记本机仓库：代理上报它能访问的仓库目录，你在面板里挑选。
- 新建任务：选仓库、执行器（Claude Code 或 Codex）、基础分支，写需求。也可以从 Issue 一键发起。
- 每个任务在独立的 git worktree 和分支里跑，互不影响。
- 实时看输出。可以中途取消。超时自动停。同时运行的任务数有上限。
- 完成后看改动文件和 diff。然后选择：提交、提交并推送、建 PR（用 GitHub 集成）、丢弃。
- 完成、失败、需要你决定时都发通知。

### M5 项目

- 项目列表。每个项目有 Issue，编号形如 `XC-12`。
- Issue 字段：标题、Markdown 描述、状态、优先级、标签、截止日期、里程碑、关联 PR 和编码任务。
- 看板视图可拖动改状态。列表视图可排序、分组、过滤。
- 键盘操作：`C` 新建，`J/K` 上下移动，`E` 编辑，数字键改状态。
- 可选 Linear 同步（M13 负责）。

### M6 笔记

- Markdown 笔记，支持标签和置顶。
- 全文搜索，用 SQLite FTS5，中文也能搜到。
- 快速记录：命令面板里直接输入一句话存成笔记。
- 笔记可以一键转成 Issue 或提醒。

### M7 提醒与通知

- 提醒可以是一次性的，也可以重复（每天、每周几、每月几号，底层用 RRULE）。
- 到点后按规则推送到各渠道。渠道：站内、Web Push、Telegram、Bark、Server酱。
- 按事件类型选渠道，比如服务器告警走 Telegram 和 Bark，习惯提醒只走 Web Push。
- 免打扰时段，紧急级别的通知不受限制。
- Telegram 消息带按钮：完成、10 分钟后再提醒。点按钮能回写结果。
- 每个渠道有“发送测试消息”按钮。

### M8 习惯与健康

- 习惯：名称、每日目标（比如 8 杯水）、单位、提醒方式。
- 间隔提醒：在工作时段内每 N 分钟提醒一次，达标后当天不再提醒。
- 打卡入口：网页按钮、通知按钮、Telegram 按钮、HA 实体（比如一个物理按钮）。
- 统计：连续天数、7 天和 30 天完成率、每天的打卡次数。
- 健身：每周计划（周一胸、周三背），当天推送计划，记录组数、次数、重量。

### M9 Home Assistant

- 设置里填 HA 地址和长期令牌，能测试连接。
- 实体列表可按域过滤、搜索、收藏。
- 开关、灯、场景、脚本可以直接操作。
- 通过 HA WebSocket 订阅状态变化，界面实时更新。
- HA 状态变化作为事件发布，自动化模块可以用它触发。

### M10 运维监控

- 脚本库：保存常用命令，可以指定在哪台机器跑，执行前确认，执行结果留档。
- 网站监控：定时请求 URL，记录状态码和耗时，连续失败发告警。
- SSL 证书到期检查，剩 14 天和 3 天各提醒一次。
- 域名到期检查（RDAP），同样提前提醒。
- 订阅和续费：服务器、域名、SaaS 的金额、周期、下次续费日，提前提醒。

### M11 个人生活

- 日历：订阅 ICS 链接或 CalDAV，显示日视图和周视图。先只读。
- 每日早报：每天定时生成，内容包括天气、今日日程、到期的 Issue 和提醒、昨天的告警、习惯情况。推送到选定渠道，也能在面板里看历史。
- 番茄钟：开始、暂停、结束，可以关联一个 Issue，记录专注时长。

### M12 AI 助手与自动化

- 全局浮窗，任何页面右下角都能打开，不在侧边栏里。
- 助手能读、写、删面板里所有非隐藏的内容：项目、Issue、笔记、提醒、习惯、云盘文件，也能查服务器、控制 HA、发起编码任务。
- 能按一句话完成一串操作，比如给一个项目排好期，拆成带截止日期的 Issue。
- 读和写直接执行。删除和危险操作先显示“要执行什么”，你点确认才执行。
- 对话记录保存在服务端。
- 自动化规则：触发器（定时、指标阈值、事件、HA 状态、Webhook）加条件加动作（通知、跑脚本、调 HA 服务、建 Issue、问 AI）。
- 每次运行留记录，能看到哪步成功哪步失败。

### M13 开发者集成

- 配置 GitHub 令牌后，显示你关注的仓库的 PR、CI 状态、Issue。
- PR 和 Issue、编码任务互相关联。CI 失败发通知。
- Linear 同步：选择要同步的团队和项目，双向同步标题、状态、优先级、描述。以最后修改时间为准。

### M14 云盘

- 上传、下载、文件夹、改名、移动、回收站、预览图片和文档。
- 同步到 S3 兼容的存储做备份。

### 隐藏内容

- 连点 Logo 5 次，输入隐藏密码后才能看到隐藏的笔记和文件。其余时间在任何地方都看不到，AI 助手也看不到。

### 全局

- 命令面板（⌘K / Ctrl+K）：跳转页面、执行模块命令、快速记录。
- 手机上能正常用，所有页面在 390px 宽度下不横向滚动（表格除外，表格自己横向滚动）。
- 可以作为 PWA 安装到手机桌面，收 Web Push。
- 深色和浅色主题。中文为默认语言，保留英文。
