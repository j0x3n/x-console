# B80 切换页面后保留位置

用户 2026-10-01 提的：现在切换页面就会清掉原来的页面，这样省内存。能不能像 X 一样记住上次看到的位置，不管是列表还是内容，切回来还在原处。

只改前端。

## 做法

不把整页留在内存里（页面多了会卡），而是记住三样东西，回来时恢复：

1. **每个模块最后看的地址**：点左栏的一级菜单，回到这个模块上次停留的地址（比如上次在 `/notes/12?tag=work`，点“笔记”就回到这里），不是模块首页。已经在这个模块里时再点一下，回到模块首页（和 X 点“首页”回顶部一样）。记在 `sessionStorage`，关掉标签页就忘掉。
2. **滚动位置**：
   - 页面主体的滚动位置，按完整地址（路径 + 查询参数）记。
   - 页面里自己滚动的区域（笔记列表、笔记正文、邮件列表、云盘列表、看板的横向滚动、日志）用 `useKeepScroll(ref, key)` 记，`key` 写模块名加用途，比如 `notes.list`。
   - 回来时等内容渲染出来再恢复：内容高度够了就滚过去，最多等 2 秒（数据加载慢时）。
   - 用户回来后自己先滚了，就不再恢复。
   - 浏览器前进后退也恢复（原来浏览器自己的恢复对页面内的滚动区域不起作用）。
3. **数据**：TanStack Query 的缓存保留时间（`gcTime`）从 5 分钟改成 30 分钟，切回来先显示缓存，再在后台刷新，不会闪“加载中”。

页面内的一些状态本来就在地址栏里（筛选、标签页、选中的项），自然会保留。只在组件里的状态（比如展开了哪一行）这一版不保留。

## 前端改动

- 新文件 `hooks/useKeepScroll.ts`：`useKeepScroll(ref, key)`、`useMainScrollRestore()`（在 `Layout` 里调用一次）。位置存在内存里的 `Map`，同时写 `sessionStorage`（刷新页面也能恢复）。
- `components/layout/Sidebar.tsx`：一级菜单的链接用 `lastPathFor(item.path)`。`Layout` 每次路由变化时记下当前地址属于哪个模块。
- `api/query.ts`：`gcTime` 改成 30 分钟。
- 各模块的滚动区域加上 `useKeepScroll`：笔记（列表、正文）、邮件（列表、正文）、云盘（列表）、项目（看板横向、列表）、Agent（任务列表）、提醒、日志查看器。

基础代码的改动记到接口变更记录。

## 验收

- 笔记列表往下滚到第 50 条，打开第 50 条看到一半，切到服务器页再点“笔记”：还是第 50 条打开着，列表和正文都在原来的位置。
- 在笔记页里再点一次“笔记”，回到笔记首页。
- 云盘进到一个子文件夹滚到底，切走再回来，还在那个文件夹的底部。
- 刷新页面后，滚动位置也能恢复。
