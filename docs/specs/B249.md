# B249 切换模块时保留正在做的事

用户 2026-10-18 在 X Console 看板提出（XC-60）：每个模块可能要同时用，多标签页好还是保存状态好。用户同意先做保存状态，不做多标签页。

## 现在的情况

- B80 记了两样，存在内存和 sessionStorage：每个模块最后看的地址（含查询参数），和滚动位置。
- 所以已经写进地址的状态切回来还在：邮件的邮箱、未读、打开的信；项目的看板、筛选；仓库页的标签和仓库；云盘的文件夹。
- 切走时页面整个卸载，没写进地址的都丢：
  - 终端：服务器页和电脑页的终端切到别的模块就断开，正在跑的命令跟着停。这是最影响“同时用”的一条。
  - 没提交的输入：卡片评论、添加卡片的标题、邮件搜索框、Agent 对话框里写了一半的话。
  - 展开和选中：列表里展开的行、详情里切到的子标签（比如卡片详情的“评论 / 活动记录”）。

## 要什么

### 1. 终端切走时问要不要留着（2026-10-19 用户定）

- 终端连着的时候离开服务器页或电脑页（换模块、换服务器、关掉终端页签都算），先弹窗问：
  - 标题“终端还连着”，说明“留在后台的终端不会断开，正在跑的命令接着跑。”
  - 按钮从左到右：“断开”（断开再走）、“留在后台”（主按钮，走了不断开）。
  - 下面一个勾选框“以后都这样，不再问”。勾上后记进偏好设置，设置 → 通用里可以改回来。
  - 点遮罩或按 Esc 等于不走，留在当前页。
  - 只有终端真的连着时才问。没连上、已经断开的不问。
- 留在后台的终端：连接和屏幕内容都留着，切回来接着用。
- 最多同时留 4 个。第 5 个要留时，关掉最早不看的那个，并提示“已断开 xxx 的终端，后台最多留 4 个”。
- 后台超过 30 分钟没看的终端自动断开，服务端的会话本来也有超时。

### 1b. 顶栏的“后台”按钮

- 顶栏右上角，放在音乐、便签、番茄钟、AI 前面，用 `TopbarActions.tsx` 加一行。图标 `Layers`，右上角显示数量，和左栏图标上的数字一样（10 以上只有点）。
- 数量 = 后台留着的终端 + 正在跑的 Agent 任务（`queued`、`running`）。数量是 0 时按钮不显示。
- 点开是一个下拉面板（手机上从底部弹出，和 `MoreMenu` 一样），分两组：
  - **终端**：每行是服务器或电脑的名字、终端标题、在后台多久了（“12 分钟”）。正在跑命令的行前面一个转圈的小图标。
  - **Agent 任务**：每行是任务标题、仓库、状态（排队中、运行中），还有已经跑了多久。
  - 点整行跳回去：终端回到那台机器的终端页签，Agent 任务回到 `/coding/<id>`。面板随即关掉。
  - 每行最后一个 ×：终端是断开，Agent 任务是取消（`POST /coding/tasks/{id}/cancel`）。两种都先用 `confirmAction` 确认，标题写清是哪台机器或哪个任务。取消任务沿用 Agent 页现有的二次验证规则。
  - 某一组是空的就不显示这一组。两组都空时按钮本身不显示，面板也不会开着。
- Agent 任务的列表用 `features/coding` 现有的任务查询，靠事件刷新，不新加轮询。
- 左栏服务器、电脑图标上的小点不做了，统一看顶栏这个按钮。

### 2. 写了一半的输入不丢

- 公共 Hook `useDraft(key)`：和 `useState` 一样用，内容存在内存和 sessionStorage，按 key 记，提交成功后清掉。关掉标签页就忘掉，和 B80 一样。
- 先用在：卡片评论框、添加卡片输入框、Agent 对话输入框、邮件搜索框、笔记页的新建标题框（笔记正文本来有自动保存，不用）。

### 3. 展开和子标签

- 公共 Hook `useKeptState(key, initial)`：存法同上，不清。
- 先用在：卡片详情的“评论 / 活动记录”标签、服务器详情的子标签、Agent 运行记录展开的那一条。

## 怎么做

- 终端：把终端组件挂到 `GlobalPanels`（共享文件，只加行）里的一个常驻容器，服务器页和电脑页只放一个占位元素，按会话 id 把终端移到占位元素里显示；离开页面时移回隐藏容器，不卸载。改动在 `features/servers`，`GlobalPanels.tsx` 只加一行。
- 离开前的弹窗用 react-router 的 `useBlocker`（应用用的是 `createBrowserRouter`，菜谱编辑页已经这样用过）。选了“断开”或者不留时照旧卸载。
- 后台终端的列表放一个全局 store（zustand，和 `auth/elevation.ts` 一样），终端模块写，顶栏按钮读。
- 顶栏按钮和面板放 `features/servers/BackgroundButton.tsx`。它要读 Agent 任务，只用 `features/coding/api.ts` 导出的查询，不改 coding 模块的文件。
- “以后都这样”存进现有的偏好设置（和 `navPins` 同一处），加一个字段 `terminalLeave: "ask" | "keep" | "close"`，默认 `ask`。偏好设置定义在 `api/modules/core.yaml`（`navPins` 旁边），后端在 `backend/internal/server/core/`，前端同步在 `web/src/hooks/usePreferencesSync.ts`。这些都是基础代码，要交给后端模型做：只加一个可选字段，向后兼容，在 `docs/api-changes.md` 记一笔。
- `useDraft` 和 `useKeptState` 放在 `web/src/hooks/`，和 `useKeepScroll` 共用存取代码。这是基础代码，提交信息写理由，`docs/api-changes.md` 记一笔。

## 验收

- 前端测试：`useDraft` 提交后清空、刷新后还在；`useKeptState` 切走再回来还在；终端切走再回来是同一个连接（假 WebSocket 计数），超过 4 个关掉最早的。
- 前端测试：终端连着时离开会弹窗，选“断开”连接关掉，选“留在后台”连接还在；勾了“不再问”下次直接按选的做；终端没连着时不弹。
- 前端测试：顶栏按钮的数量是后台终端加运行中的 Agent 任务，0 时不显示；点行跳到对的地址；点 × 先确认，确认后断开或调用取消接口。
- 端到端第一部分加一步：卡片评论写一半，切到笔记再回来，内容还在。
- 截图服务器页、项目页，以及打开“后台”面板的样子，1360 和 390 宽。

## 用户定了的

- 2026-10-19：切走时先问要不要留，留了的终端和运行中的 Agent 任务一起显示在顶栏右上角的“后台”按钮里，能跳回去，也能 × 关掉。具体样子由 Claude 定，就是上面写的。
- 最多留几个、多久断开，用户没另外说，按建议的 4 个、30 分钟做。
