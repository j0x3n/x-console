# B249 切换模块时保留正在做的事

用户 2026-10-18 在 X Console 看板提出（XC-60）：每个模块可能要同时用，多标签页好还是保存状态好。用户同意先做保存状态，不做多标签页。

## 现在的情况

- B80 记了两样，存在内存和 sessionStorage：每个模块最后看的地址（含查询参数），和滚动位置。
- 所以已经写进地址的状态切回来还在：邮件的邮箱、未读、打开的信；项目的看板、筛选；仓库页的标签和仓库；云盘的文件夹。
- 切走时页面整个卸载，没写进地址的都丢：
  - 终端：服务器页和电脑页的终端切到别的模块就断开，正在跑的命令跟着停。这是最影响“同时用”的一条。
  - 没提交的输入：卡片评论、添加卡片的标题、邮件搜索框、Agent 对话框里写了一半的话。
  - 展开和选中：列表里展开的行、详情里切到的子标签（比如卡片详情的“评论 / 活动记录”）。

## 要什么

### 1. 终端切走不断开

- 终端连着的时候切到别的模块，连接和屏幕内容都留着，切回来接着用。
- 最多同时留 4 个终端。超过时关掉最早不看的那个，并提示一句。
- 离开超过 30 分钟没看的终端自动断开（服务端的会话本来也有超时）。
- 页面上方提示条不加。左栏服务器和电脑图标上，有终端在后台连着时显示一个小点，悬停写“有 N 个终端在后台”。

### 2. 写了一半的输入不丢

- 公共 Hook `useDraft(key)`：和 `useState` 一样用，内容存在内存和 sessionStorage，按 key 记，提交成功后清掉。关掉标签页就忘掉，和 B80 一样。
- 先用在：卡片评论框、添加卡片输入框、Agent 对话输入框、邮件搜索框、笔记页的新建标题框（笔记正文本来有自动保存，不用）。

### 3. 展开和子标签

- 公共 Hook `useKeptState(key, initial)`：存法同上，不清。
- 先用在：卡片详情的“评论 / 活动记录”标签、服务器详情的子标签、Agent 运行记录展开的那一条。

## 怎么做

- 终端：把终端组件挂到 `GlobalPanels`（共享文件，只加行）里的一个常驻容器，服务器页和电脑页只放一个占位元素，按会话 id 把终端移到占位元素里显示；离开页面时移回隐藏容器，不卸载。改动在 `features/servers`，`GlobalPanels.tsx` 只加一行。
- `useDraft` 和 `useKeptState` 放在 `web/src/hooks/`，和 `useKeepScroll` 共用存取代码。这是基础代码，提交信息写理由，`docs/api-changes.md` 记一笔。

## 验收

- 前端测试：`useDraft` 提交后清空、刷新后还在；`useKeptState` 切走再回来还在；终端切走再回来是同一个连接（假 WebSocket 计数），超过 4 个关掉最早的。
- 端到端第一部分加一步：卡片评论写一半，切到笔记再回来，内容还在。
- 截图服务器页和项目页 1360 和 390 宽。

## 要用户定的

- 终端最多留几个、多久自动断开（上面写的 4 个、30 分钟是建议）。
