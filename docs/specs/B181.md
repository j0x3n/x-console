# B181 设置页重新排版

2026-10-13 用户提的：设置弹窗里很多页有大块空白，卡片的布局和里面的内容都重新整理。

## 问题

1. 两列卡片高矮不齐，矮的那边空一大块（我的状态、登录与验证、AI、Git、存储、备份、音乐、维护）。
2. 宽度不统一：早报、邮件只占左边一部分，稍后阅读、Home Assistant 只占半边。
3. 很少看的说明和命令一直全部展开（iPhone 快捷指令步骤、路由器准备、卸载命令、MCP 接入配置）。
4. 空状态一个大图标占一百多像素高。
5. 只有一行字的“同步状态”“状态”也单独占一张卡片。
6. 放错地方：称呼在登录与验证里；早报的保存按钮在卡片外面；AI 页的“本月用量”和下面的用量详情重复。
7. 通知页太长。

## 怎么做

- 单列分区：设置弹窗里 `settings-grid` 改成单列，每张卡片占满宽度。写法见 `docs/07-design.md` 的“设置类页面”。
- 空状态、出错提示在设置弹窗里压成一行。
- 收起：iPhone 快捷指令步骤、来源说明、卸载和更新、路由器准备、稍后阅读的高级选项。远程访问的三段接入代码改成切换显示。
- 状态并进标题：Home Assistant、Linear、路由器、和风天气的标题旁显示状态标签。没配置时 Git、Linear、Home Assistant 的状态卡片不显示。
- 合成一行：称呼、推测睡觉、免打扰（开关、时间、作息入口）、每月免费 CI 分钟数、两步验证（按钮在标题行）。
- 通知：四个推送渠道一行一个，显示是否配置，点“展开”再填。每一类通知两列排。作息入口并进免打扰。
- 早报：三张卡片合成一张，左边名称右边内容，保存在卡片右下角，早报历史的入口放在左下角。
- 表单两列：S3（存储和备份共用）、Home Assistant、Linear、路由器、和风天气、稍后阅读的 Cookie、AI 模型。登录密码三列。
- 维护：版本卡片和存储占用上下排，版本信息两组一行。AI 用量这段时间没有调用时，不再列出四张空卡片。

## 验收

- 17 页在 1360px 下没有两列留下的空白，在 390px 下没有横向溢出。
- 相关模块的测试都通过。
