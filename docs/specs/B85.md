# B85 卡片右键菜单（参考 Trello）

用户 2026-10-02 提的：

- 参考 Trello，卡片支持右键菜单，可以分配、设置颜色、设置到期时间，以及标签、移动、归档等常见操作。
- 卡片详情里「编辑描述」按钮和描述文本挤在一起，要分开显示。
- 卡片详情里评论按钮紧贴评论输入框，要留出间距。

## 菜单里有什么

在看板上右键一张卡片（手机上长按）弹出菜单，和 Trello 的“快速编辑”一样：

| 项 | 做什么 |
| --- | --- |
| 打开卡片 | 打开详情 |
| 分配 | 子菜单：我、每个 Agent（勾选表示已是成员）。选 Agent 时问“只加为成员”还是“让它开始做”（开始做走 B86 的分配） |
| 标签 | 子菜单：项目的标签，点一下加上或去掉 |
| 颜色 | 一排色块（`CardColor`），再点一次当前颜色就去掉。卡片顶部显示一条这个颜色 |
| 到期时间 | 子菜单：今天、明天、下周一、选日期时间、清除 |
| 移动 | 子菜单：同一看板的其他列表；“移到别的看板…” 打开已有的移动弹窗 |
| 复制 | 复制卡片（已有接口） |
| 复制链接 | 复制卡片地址 |
| 归档 | 归档卡片（已有接口），提示里给“撤销” |

- 菜单用公共的 `MoreMenu` 的样式，位置在鼠标处；超出屏幕时往回挪。Esc 关闭。
- 手机上长按 500 毫秒弹出，从底部弹出，和 `MoreMenu` 一样。

## 契约（已改）

- `Issue.color`、`UpdateIssue.color`：`CardColor`，空字符串表示不设。

## 后端（Claude 做了，2026-10-02）

- 迁移 `20261002000100_m5_b85_card_color.sql` 给 issues 加 `color TEXT NOT NULL DEFAULT ''`。
- `PATCH /issues/{key}` 收 `color`，只接受枚举里的值，空字符串表示去掉。卡片返回时总带 `color`（没设时是空字符串），前端据此判断接口已上线。
- 改颜色时记一条活动 `color`，卡片详情里显示“改了颜色”。复制卡片时颜色一起复制。
- 测试：`TestCardColor`。
