# B35 GitHub 仓库下拉多选，同步加快

需求见 `docs/tasks.md` 的“B35 GitHub 仓库下拉多选，同步加快”。这里写做法。

## 前端（已完成）

2026-09-29 做完，分支 `claude/project-thread-o3tsew`。

- 设置 → GitHub 的“关注的仓库”（`features/github/RepoPicker.tsx`）：已选的显示成标签，点叉去掉。下面是搜索框和仓库列表（按名字和说明搜索，私有的有锁的图标，已选的不再出现），点一下加上，回车加第一个。列表里没有、但输入的是 `owner/name` 格式时，可以“按名字添加”。最多 50 个。旁边的刷新按钮调 `refresh=true`，下面写“N 个仓库 · 列表更新于 X 分钟前”。
- 没有令牌、接口没上线（404、501）或者取列表失败时，退回原来的文本框（一行一个）。失败的原因写在文本框下面。
- 同步状态卡片：剩余请求显示成“412 / 5000”；有 `syncIntervalSeconds` 时显示同步间隔，5 分钟时加一句“剩余额度不多，已经放慢”。
- “立即同步”按钮和转圈原来就有（设置页和 GitHub 页都有），这次没改。

## 契约

`api/modules/github.yaml`：

- `GET /github/available-repos?refresh=`：`{fetchedAt, repos: [{fullName, private, description?, pushedAt?}]}`。没有令牌回 412。`modules/github/pending.go` 先回 501。
- `GitHubStatus` 加 `rateLimitLimit`、`syncIntervalSeconds`（都是可选的）。

## 后端（已完成）

都在 `modules/github/`。

### 1. 仓库列表 `repos.go`

- 用现有的 `restClient` 调 `GET /user/repos?per_page=100&sort=pushed&affiliation=owner,collaborator,organization_member`，按 `Link` 头的 `rel="next"` 一页页取完，最多取 20 页（2000 个），多的不要。
- 只留 `full_name`、`private`、`description`（截到 200 字）、`pushed_at`。
- 缓存在内存里 10 分钟（`sync.Mutex` 加一个结构体，存结果和时间）。`refresh=true` 时不看缓存。令牌或 API 地址改了清掉缓存。
- 没有令牌回 412 `github_not_configured`（和 `/github/sync` 一样）。令牌不对回 GitHub 的错误信息。
- 细粒度令牌只返回授权过的仓库，这是对的，不用特殊处理。

### 2. 同步间隔

- `module.go` 的 `syncInterval` 改成 1 分钟。`Scheduler.Every` 按 1 分钟跑，每次进来先看要不要跳过：剩余额度 `remaining < limit / 10` 时，距离上次同步不到 5 分钟就跳过。额度重置（`X-RateLimit-Reset` 过了）后恢复每分钟。
- `restClient` 记下 `X-RateLimit-Limit`（现在只记了 `Remaining` 和 `Reset`）。
- `GET /github/status` 返回 `rateLimitLimit` 和现在的 `syncIntervalSeconds`（60 或 300）。
- ETag 缓存已经有了（`client.go`），304 不算进额度。确认同步里所有 GET 都走这个客户端。

### 3. PR 分页

- `sync.go` 分别分页读取打开和关闭的 PR，每种最多 20 页。关闭的 PR 只留 `closed_at` 在最近 7 天的。分开读取，避免旧关闭记录挤掉打开的 PR。
- 表和接口增加 `state`：`open`、`closed`、`merged`。没拉到的旧记录按原有做法删除。
- 做完把 `docs/tasks.md`“已知问题”里“GitHub 每个仓库只拉第一页（100 个 PR）”那半句删掉。

### 4. 测试

- 用现有的 `fakegithub_test.go`：
  - `/user/repos` 分 3 页，全部取到；缓存 10 分钟内不再请求，`refresh=true` 会请求。
  - 同一个请求第二次带 `If-None-Match`，假服务器回 304，额度不减。
  - 剩余额度设成 400（总额 5000）时，1 分钟后不同步，5 分钟后同步。
  - PR 有 150 个打开的，全部拉到；8 天前关闭的不拉。
