# B167 检查和构建提速

用户 2026-10-12 确认，直接在 develop 做。

## 要求

- 部署调用 CI 时 race=false 必须生效。PR、手动 CI 默认保留 race。
- 版本号准确，服务端和四平台代理都保留当前提交号。
- 镜像先编译不含提交号的程序，随后使用同一层内的 Go 缓存链接当前版本。编译层可通过现有 GitHub Actions 镜像缓存保存，不能只依赖新 runner 上会丢失的缓存挂载。
- 代理阶段只复制代理源码、协议公共包和 Go 依赖。服务端或前端变更不使代理编译层失效。包含 linux/amd64、linux/arm64、windows/amd64、windows/arm64，Windows 保留 windowsgui。
- Actions 下载代理复用镜像里的程序，不再额外编译。
- 独立浏览器入口自动创建临时数据库，起 Go 服务与 Vite，执行现有天气提醒流程。不构建完整前端，不编译代理，不连接真实天气服务。
- 页面脚本异常或页面显示错误时立即报告。失败保留页面错误、截图和近期进程日志，临时进程和数据库必须清理。
- 快速检查按当前未推送改动范围运行。支持只检查工作区新改动；前端脚本有变化时检查语法及 Node 测试，不因 scripts 目录变化安装全部依赖。

## 验收

- actionlint 通过，race 配置有针对性回归检查。
- 本机构建服务端与代理阶段。连续两次使用不同版本号构建，编译层命中缓存。linux amd64 程序 version 返回第二次版本，四平台代理及 SHA256SUMS 存在。
- 独立浏览器流程完整通过。故意制造页面错误时快速失败并输出原因，清理成功。
- 新脚本的单元测试和快速检查通过。记录实际耗时，不把本机结果当作 Actions 提速数据。
