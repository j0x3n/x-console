# B20 页面按钮移到顶栏，侧边栏可以折叠

用户要求（2026-09-28）：各页面自己的功能按钮全部移到顶栏。顶栏就是现在“快速记录、通知”那一行。页面按钮和全局按钮要明显分开。左侧剩下的副标题等内容，由审查者定放在哪里。另外把侧边栏的折叠按钮做出来。

这个任务改基础代码（`web/src/app`、`components/layout`、`components/ui/PageHeading`），也改几乎所有页面。先做它，后面的界面任务都按新结构写，避免返工。

## 现在的情况

- 每页顶部是 `PageHeading`：左边一行灰字概况（`subtitle`），右边按钮（`aside`）。比如今日页的“调整布局”，项目页的“新建项目”“新建 Issue”，提醒页的“新建”。
- 顶栏 `Topbar` 左边是小标题（可点击跳转），右边是 `TopbarActions`（快速记录、番茄钟、安装应用）、通知、个人菜单。
- 侧边栏没有折叠按钮。

## 要什么

### 顶栏分成三段

```
[☰] 今日 · 3 个待办今天到期        [调整布局] [+ 新建]  │  [快速记录] [番茄钟] [🔔] [头像]
 ↑ 小标题 + 概况灰字                 ↑ 页面按钮             ↑ 竖线分隔   ↑ 全局按钮
```

1. **左段**：折叠按钮、小标题、概况。
   - 概况就是原来 `PageHeading` 的 `subtitle`，放在小标题后面，12.5px `--xc-muted`，中间用“·”隔开，一行放不下时省略号。
   - 详情页的状态点（`usePageStatus`）位置不变。
   - 宽度小于 1100px 时不显示概况。概要卡片里已经有同样的信息。
2. **中段：页面按钮**。靠右，紧挨着分隔线。
   - 主要按钮（`xc-btn primary small`）放在最右边，其他是普通按钮或图标按钮。
   - 超过 3 个时，多出来的收进一个“更多”（`MoreMenu`）。
3. **分隔**：页面按钮和全局按钮之间一条 1px `--xc-border-strong` 竖线，高 18px，左右各 8px 间距。页面没有按钮时不显示竖线。
4. **右段：全局按钮**。原样不动。全局按钮统一用 `ghost` 图标按钮，页面按钮用带边框的 `small` 按钮。两组按钮样子不同，一眼能分开。

### 页面怎么用

- 新增 `components/layout/PageActions.tsx`：页面里写 `<PageActions>...按钮...</PageActions>`，通过 portal 渲染到顶栏的 `#page-actions` 位置。页面卸载时自动清掉。
- `PageHeading` 的 `subtitle` 改为写进 `stores/page-title.ts`，由顶栏显示。`aside` 改为内部转成 `PageActions`。这样老页面不用逐个改也能工作，但本任务要把所有页面过一遍，确认位置和样子对。
- 页面内部的工具栏（搜索、筛选、视图切换）**不动**，还在页面里。只有“做一件事”的按钮（新建、调整布局、导入、同步）移到顶栏。
- 弹窗、详情页右侧属性栏里的按钮不动。

### 手机（宽度小于 720px）

- 概况不显示。
- 页面按钮只留主要按钮，显示成图标。其他按钮收进“更多”。
- 全局按钮里快速记录、番茄钟收进个人菜单，只留通知和头像。
- 顶栏不能换行，不能横向滚动。

### 侧边栏折叠

- 顶栏最左边加折叠按钮（`PanelLeftClose` / `PanelLeftOpen` 图标）。
- 桌面：点一下侧边栏收成 56px 宽，只显示图标，鼠标悬停显示名称提示。二级菜单不显示。再点展开。状态存在 `localStorage`（`xc.sidebar.collapsed`），读写都包 try/catch。
- 手机：侧边栏本来就是抽屉，按钮用来打开抽屉。
- 快捷键 `⌘B` / `Ctrl+B` 切换，注册到命令面板，名称“折叠侧边栏”。
