# B87 Agent 通知和“待你决定”

用户 2026-10-02 提的：

- agent 收到任务、开始任务、需要我决定、已提 PR、完成任务、失败或中断时都发通知，每类通知都能单独开关。
- 确认今日页「待你决定」是否包含 agent 的权限请求和问题，没有就加上。

## 现状（2026-10-02 查的）

- 今日页“待你决定”只有两类：做完等审查的编码任务（`review`）、逾期的卡片。
- Agent 现在不会停下来问人：CLI 类型用 `acceptEdits` 或 `bypassPermissions` 跑，内置类型按访问级别直接调工具。AI 助手会话里有“等确认的动作”（`ai_pending_actions`），但只在助手面板里能看到。

## 要做的

### 权限请求和问题

- 内置类型：调到需要确认的工具时（删除、高危操作，和助手会话的规则一样）不直接执行，记一条权限请求，执行状态变成 `waiting`，等你批准或拒绝后继续。
- 两种类型都给 Agent 一个“问用户”的工具（内置类型是工具；CLI 类型在提示里说明：要问问题时把问题写到工作目录的 `.xc-question.md` 并停下，代理读到后上报）。问题可以带几个选项。回答后继续执行（CLI 类型带着回答重新跑一次 `--resume` 或新会话）。
- `GET /ai-agents/decisions` 列出所有还没处理的：Agent 的权限请求和问题，加上 AI 助手会话里等确认的动作。
- `POST /ai-agents/decisions/{id}`：批准、拒绝或回答。

### 通知

| 类别 | 什么时候 | 默认 |
| --- | --- | --- |
| 收到任务 | 卡片分配给 Agent，排上队 | 关 |
| 开始任务 | 开始执行 | 关 |
| 需要你决定 | 权限请求、问题、编码任务做完等审查 | 开 |
| 已提 PR | 自动或手动提了 PR | 开 |
| 完成任务 | 执行完成 | 开 |
| 失败或中断 | 失败、超时、被中断 | 开 |

- 通知 kind 用 `ai_agent.received`、`ai_agent.started`、`ai_agent.decision`、`ai_agent.pr_opened`、`ai_agent.done`、`ai_agent.failed`，发到哪里照“设置 → 通知”的规则。
- “需要你决定”的推送带按钮：权限请求是“批准”“拒绝”；问题只有“打开”。
- 通知标题写 Agent 名和卡片编号，比如“后端助手 · XC-12 已提 PR”，正文一句话。
- 开关：`GET/PUT /ai-agents/notify`。
