# B30 一条命令添加服务器，“本机”改名“电脑”，Windows 客户端

用户要求（2026-09-28）：

- 服务器怎么通过一条命令添加内网的服务器？
- 监听脚本（代理）资源占用够低吗？
- “本机”改为“电脑”，也是运行一个 Windows 客户端就自动连上面板。

## 现在的情况

- 加一台服务器要：在设置里生成配对码，自己编译代理，复制到服务器，手动 `pair`，再装 systemd 服务。步骤多，要有 Go 环境。
- 代理是**主动连面板**的（WebSocket）。内网机器只要能访问面板地址就能接入，不用开端口，不用内网穿透。
- Windows 有 `deploy/install-agent-windows.ps1`，同样要自己编译。
- 镜像里只有面板所在平台的一个代理（B1 自动安装本机代理用）。
- 代理资源占用：设计上平时 30 秒采一次概要，没人看详情时不传详细数据。没有实测过。

## 要什么

### 面板提供代理下载

- 镜像构建时编译 4 个代理：`linux/amd64`、`linux/arm64`、`windows/amd64`、`windows/arm64`，放在镜像的 `/usr/share/x-console/agents/` 下，同时生成 `SHA256SUMS`。
- 新接口（不需要登录，但要带有效的一次性配对码）：
  - `GET /api/v1/agent/install.sh?code=XXXX`：Linux 安装脚本。
  - `GET /api/v1/agent/install.ps1?code=XXXX`：Windows 安装脚本。
  - `GET /api/v1/agent/download/{os}/{arch}?code=XXXX`：代理文件。
  - 配对码无效或过期时回 404，不暴露是否存在。按 IP 限流（每分钟 10 次）。
- 脚本内容由面板按请求生成，写好面板地址（`XC_PUBLIC_URL`）和配对码。

### Linux：一条命令

设置 → 设备 → “添加服务器”，填名称，点“生成”，显示：

```bash
curl -fsSL https://console.example.com/api/v1/agent/install.sh?code=ABCD-EFGH | sudo sh
```

脚本做的事：

1. 判断架构（`uname -m`），下载对应代理，校验 SHA256。
2. 装到 `/usr/local/bin/x-console-agent`，配对，写 `/etc/x-console-agent/config.json`（权限 600）。
3. 装 systemd 服务并启动。没有 systemd 时给出手动启动命令并退出非零。
4. 打印“已连接到面板”。重复执行时覆盖升级，不重复配对（已有配置时跳过配对，除非带 `--repair`）。

- 页面上的命令框有“复制”按钮。配对码 15 分钟有效，只能用一次。弹窗等待期间实时显示“等待连接… / 已连接”，连上后自动跳到这台服务器。
- 同时给一个卸载命令：`curl -fsSL .../agent/uninstall.sh | sudo sh`（不需要配对码，只删本机文件和服务，面板上的记录由用户在界面上删）。
- 内网说明写在弹窗里一句话：“机器能访问面板地址就行，不用开端口。”
- 面板只能内网访问、服务器在外面时，不在本任务范围。

### “本机”改名“电脑”

- 侧边栏、左上角标题、命令面板、空状态里的“本机”全部改成“电脑”。英文键 `This PC` 改为 `Computer`，中文“电脑”，注意全局词典不能冲突。路由 `/pc` 不变。
- 可以接入多台电脑。只有一台时直接进详情；多台时先显示列表（和服务器列表同一个样子）。

### Windows 客户端

- 设置 → 设备 → “添加电脑”，填名称，点“生成”，显示两种方式：
  1. PowerShell 一条命令：`irm "https://console.example.com/api/v1/agent/install.ps1?code=ABCD-EFGH" | iex`
  2. “下载安装程序”：下载一个 `x-console-agent-setup-ABCD-EFGH.exe`。安装程序就是代理本身，双击运行时从文件名读配对码，自动配对并装好开机启动。文件名里没有配对码时，弹一个小窗口让用户输入面板地址和配对码。
- 两种方式都装到 `%LOCALAPPDATA%\x-console-agent\`，用任务计划程序在登录时启动（沿用 `install-agent-windows.ps1` 的做法，跑在用户会话里，剪贴板、锁屏这些功能才能用）。
- 系统托盘图标：显示连接状态（已连接、正在重连、已吊销），右键菜单：打开面板、暂停连接、查看日志、退出。托盘用 Go 实现，不引入 cgo（比如 `fyne.io/systray` 的纯 Go 分支，或 Windows API 直接调用），选型写进提交说明。
- 面板吊销这台电脑后，客户端停止重连，托盘显示“已被面板移除”。
- 客户端自动更新：连上面板时比对版本，面板上的代理更新就下载新版本替换并重启。可以在托盘里关掉自动更新。Linux 代理同样支持，默认开启。

### 资源占用

- 实测并写进 `docs/06-deploy.md`：代理空闲时（没人看详情）常驻内存、平均 CPU；打开详情 1 秒刷新时的 CPU。
- 目标：空闲时常驻内存不超过 30 MB，平均 CPU 不超过 0.5%（单核）；1 秒刷新时平均 CPU 不超过 2%。达不到就查原因再优化，比如采样时少读文件、复用缓冲区。
- systemd 服务文件加 `MemoryMax=128M`、`CPUQuota=20%`、`Nice=10`，防止代理出问题时影响业务。

## 验收

- 一台干净的 Debian（amd64）和一台树莓派或 arm64 云主机，各执行一条命令，1 分钟内出现在服务器列表。
- 重复执行命令只升级，不产生第二条记录。用过的配对码再执行，回 404。
- 在一台 Windows 上分别用 PowerShell 命令和安装程序各装一次，重启电脑后自动连上；托盘状态正确；面板上吊销后不再重连。Windows 部分 CI 测不了，用户验收时在自己电脑上试，结果记进 `docs/tasks.md`。
- 资源占用的实测数字写进文档。
- 安装脚本有 shellcheck，CI 里跑。
