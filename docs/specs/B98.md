# B98 界面改版：Clean 风格，图标栏加二级菜单

用户 2026-10-05 定的：

- 整个后台换成 clean 风格。先出了首页、项目页、左栏的设计稿，用户看过后确认。
- 左栏用“方案 B”：最左边一条窄图标栏，右边是当前模块的二级菜单。理由是模块以后还会一直加。
- 主题色不要现在的褐色（ember），换掉。默认改成靛蓝。
- 项目的二级菜单加上“我的 Issue / 今天到期 / 已逾期”这类视图。
- 首页（今日）没有二级菜单，只显示图标栏。
- 用户额度有限，改版分成几个任务，一次做一个。每个任务做完都能单独上线，不会出现做了一半的页面。

这份规格是 B98 到 B102 共用的。值以这里为准。B98 做完后，第一到第三节的内容合并进 `docs/07-design.md`，以后写界面只看那篇。

- 删掉各主题色里改底色的 `--xc-bg`、`--xc-panel`（现在 violet 等会把底色调成带颜色的灰）。clean 风格底色统一用上面的灰。

### 字体

- 英文和数字：Geist；编号、时间、快捷键：Geist Mono。用 npm 包 `@fontsource-variable/geist` 和 `@fontsource-variable/geist-mono`，跟着前端一起打包。**不要用 Google Fonts 链接**，国内加载不了。
- 中文用系统字体：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`，接在 Geist 后面。
- 字号不变（见 07-design 第四节）。概要卡片里的数字改成 24px、600、`letter-spacing: -0.02em`，所有页面一样。

### 圆角和间距

- `--xc-radius` 8px（按钮、输入框、菜单项），`--xc-radius-lg` 10px（卡片、看板列）。
- 不用阴影。只有弹窗和下拉菜单用 `--xc-shadow`。
- 页面内边距 24px（手机 16px），区块之间 20px，卡片内边距 12px 16px。

## 三、左栏：图标栏加二级菜单（B99）

参考 `docs/design/clean/ProjectsB.dc.html` 和 `MainB.dc.html` 的左边部分。

### 图标栏

- 宽 64px，底色 `--xc-panel`，右边 1px 边框。从上到下：
  1. Logo：36px，10px 圆角，主题色底，白色“X”。点了回今日。
  2. 搜索按钮（打开命令面板，⌘K）。
  3. 分组：主要（今日、项目、Agent、仓库）、个人（笔记、邮件、提醒、习惯、云盘、日程）、设备（服务器、电脑、监控）、集成（智能家居、路由器、自动化）。组之间是一条 22px 宽的短横线，不写组名。
  4. 底部：设置按钮，下面是头像（32px 圆，主题色浅底，首字母）。点头像弹出现在的个人菜单（夜间模式、主题色、语言、安装、退出）。
- 每个图标按钮 40 × 36px，图标 18px，9px 圆角。悬停灰底；当前模块用主题色浅底、主题色图标。
- 鼠标悬停和键盘聚焦时，右边出现模块名提示（深色小气泡）。按钮要有 `aria-label`。
- 以后加模块只在 `app/nav.ts` 加一行，图标栏自动出现。

### 现在左栏上的东西搬到哪

| 现在的登记 | 改版后 |
| --- | --- |
| `registerNavBadge`（B76 数量） | 图标右上角：1 到 9 显示数字（16px 圆，白边），10 以上显示 8px 圆点。悬停提示里写具体数字 |
| `registerNavIcon`（B88 今日图标跟天气、B86 Agent 工作中动画） | 换的是图标栏上的图标，动画照旧 |
| `registerNavStatus`（B93 路由器 WAN 和速率） | 路由器没有二级菜单。图标右上角用绿点或红点表示 WAN 是否在线，速率写进悬停提示 |
| `registerNavAction`（B72 笔记“+”、B86 Agent“+”） | 放到二级菜单标题栏的右边 |
| `registerNavChildren`（各模块二级菜单） | 放进二级菜单，见下 |

### 二级菜单

- 宽 228px，白底，右边 1px 边框。只有登记过二级菜单的模块才显示。今日、监控、智能家居、路由器、自动化、邮件（邮件页自己有文件夹栏）没有二级菜单，内容区直接接在图标栏后面。
- 结构：标题栏（模块名 15px 600，右边是登记的操作按钮），下面可以有搜索框，再下面是分组的菜单项。分组之间 1px 分隔线，组名 11.5px 灰。
- 菜单项高 34px，图标 16px 或 8px 的颜色方块，右边是数量（12px 灰，等宽数字）。选中：主题色浅底、主题色文字。
- 新的登记方式：`registerNavPanel(path, { component, search?: true })`。B99 先做一个兼容：模块没登记 `registerNavPanel` 时，把它现有的 `registerNavChildren` 组件放进二级菜单，去掉 5 条的上限（`NAV_CHILD_LIMIT` 只在旧的折叠模式里用）。这样 B99 做完所有模块都能用，各模块的二级菜单再一个一个改成新样子（B101、B102）。
- ⌘B 收起或展开二级菜单（现在是收起整个侧边栏）。图标栏在桌面上一直显示。收起状态记在本地。
- 宽度小于 720px：顶栏左边的菜单按钮打开抽屉，抽屉里是图标栏加二级菜单，最大宽度 `100vw - 48px`。点了菜单项关掉抽屉。
- 页面左上角的标题（`PageHeading`、`usePageCrumb`）和二级菜单的模块名重复没关系，先不改。

- “我的项目”列出全部没归档的项目，不再限 5 条。数量是未完成的 Issue 数。

### 视图（新增，只改前端）

- 路由：`/projects/views/:view`，`view` 是 `mine`、`today`、`overdue`、`week`。数据都用现有的 `useMyIssues()`，在前端按 `logic.ts` 的 `dueState` 筛，不加新接口。
- 页面：顶栏写视图名和数量；工具栏是搜索、分组（按项目 / 按状态 / 不分组）；主体用现有的 `IssueList`，显示项目标识。空的时候写“今天没有到期的 Issue”这类话，带“去看全部”按钮。
- 项目列表页（`/projects`）的“我的未完成 Issue”区块保留，标题右边加“查看全部”链到 `mine` 视图。
- 端到端测试补一条：打开“已逾期”视图，能看到造好的逾期 Issue。

### 页面样式

- 项目列表：一排 5 格概要（未完成那格带分段条和图例），工具栏（进行中 / 已归档切换、搜索、网格和列表切换），项目卡片（标识方块、名称、更新时间、描述两行、进度条和数量），下面是“我的未完成 Issue”。
- 看板：工具栏（看板 / 列表切换、筛选按钮、搜索、分组），列底色 `--xc-surface-2`、10px 圆角，卡片白底 1px 边框。卡片里：编号、优先级、标题、标签、截止时间、检查清单进度。看板在自己的容器里横向滚动。

## 验收标准（每个任务都要）

- 跑 AGENTS.md 里的全部检查。跑 `npm run shots`，1360px 和 390px、深色和浅色都看，没有横向溢出和报错。
- 对照设计稿看截图：颜色、圆角、字号、间距和第一、二节一致。PR 或提交说明里附改动页面的截图。
- 没有在页面里写死颜色（`grep -rn "#[0-9a-fA-F]\{3,6\}" web/src/features` 新增的行要能说明理由）。
- B98 额外：`docs/07-design.md` 合并了第一到第三节，旧的 ember 相关说明删掉。
- B99 额外：所有一级菜单都能进，现有二级菜单、数量、图标动画、路由器状态、笔记和 Agent 的“+”都还在。键盘能用 Tab 走完图标栏。

## 分次做的规则

- 一个任务一个提交，做完就推送到 `develop`，不要攒着。会话随时可能断，没推送的改动会丢。
- 一个任务一次做不完：先把能用的部分提交推送（页面不能是坏的），在 `docs/handoff.md` 最上面写清楚做到哪、下一步做什么、有什么没验证。
- 下次开新对话时说“继续做 B99”这样的话就行。接手的人先读 `docs/handoff.md`，再读这份规格。
