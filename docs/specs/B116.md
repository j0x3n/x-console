# B116 电脑时间去向统计

用户 2026-10-10 让按《功能扩展建议》的顺序做，这是第二条（建议里的第 1 条）。来源是 `/mnt/project-files/x-console-suggestions/功能扩展建议.md`。

## 为什么要加

面板记的是“做完了什么”（提交、卡片、Agent 任务），不知道“时间花在哪”。番茄钟要手动点开始，大部分时间没有记录。你觉得今天写了一天代码，统计出来可能编码只有 3 小时，刷网页 4 小时。

## 要什么

- Windows 代理每分钟记一次前台程序和窗口标题。
- 服务端按规则分成类别：编码、AI 工具、通讯、网页、娱乐、办公、其他。
- 今日页有一张“电脑时间”卡片，显示今天各类别的小时数。
- 新页面 `/screentime`：看日、周、月的总时长、各类别占比、每天的柱状图、用得最多的程序。
- 设置：总开关，每台电脑单独开关，是否保存窗口标题，分类规则，清空数据。
- 整个模块可以在设置里加进隐藏内容（和证件档案一样，默认不隐藏）。

## 隐私

- 窗口标题常带私人内容（邮件主题、文档名、网页标题）。默认**不保存**标题：代理把标题发给服务端，服务端用它分类，然后丢掉，只存程序名和类别。
- 设置里“保存窗口标题”打开后才存，用来以后改规则时重新分类，并且 30 天后自动清掉标题，只留程序名。
- 记录范围只有 Windows 桌面代理。锁屏、离开电脑超过 5 分钟的时间不算。
- “清空数据”要提升权限，删除全部记录。
- 记录只存在你自己的服务器上。

## 代理（Windows）

- 新包 `internal/agent/screentime`。能力 `CapScreenTime = "screentime"`，只有 Windows 声明。
- 每 15 秒取一次前台窗口：进程可执行文件名（比如 `Code.exe`）、窗口标题、空闲秒数、是否锁屏。复用 `presence.Get` 的空闲和锁屏判断。
- 每个自然分钟结束时，在这一分钟里“有人在用”（没锁屏、空闲不到 5 分钟）的采样中取出现次数最多的程序，发一次事件 `screentime.sample`。这一分钟没有有效采样就不发。代理离线时的记录丢掉，不补发。
- 协议文件 `pkg/protocol/methods_screentime.go`，只加不改：
  ```go
  const (
      CapScreenTime     = "screentime"
      EventScreenSample = "screentime.sample"
  )
  type ScreenSample struct {
      Minute int64  `json:"minute"` // Unix 分钟数（秒数除以 60）
      App    string `json:"app"`
      Title  string `json:"title,omitempty"`
  }
  ```
- 取不到前台窗口（比如在安全桌面）、取不到进程名时不发。

## 服务端

新模块 `screentime`，迁移 `20261010000100_m16_b116_screentime.sql`，只加不删。

- 表 `screen_minutes(host_id, minute, app, category, title)`，主键 `(host_id, minute)`，同一分钟重复上报覆盖。表 `screen_rules(id, field, pattern, category, position, created_at)`。
- 收到 `screentime.sample`：检查总开关和这台电脑的开关，分类，写入。分钟数比服务器时间早一天以上或晚 5 分钟以上的丢掉。
- 分类顺序：自己的规则（按添加顺序，先匹配先用）→ 内置规则 → 其他。规则的 `field` 是 `app`（程序名相等，不分大小写）或 `title`（标题包含，不分大小写）。
- 内置规则：
  - 编码：Code、Cursor、Windsurf、devenv、idea64、pycharm64、goland64、webstorm64、clion64、rider64、sublime_text、notepad++、WindowsTerminal、wt、powershell、pwsh、cmd、mintty、git-bash、wsl。
  - AI 工具：Claude、ChatGPT、Codex、Copilot 这些程序。
  - 通讯：WeChat、Weixin、QQ、Telegram、Slack、Discord、Teams、ms-teams、Zoom、Feishu、Lark、DingTalk、Outlook、Thunderbird。
  - 办公：WINWORD、EXCEL、POWERPNT、ONENOTE、wps、Notion、Obsidian、Acrobat、AcroRd32、SumatraPDF。
  - 娱乐：Steam、Spotify、vlc、PotPlayer、cloudmusic、QQMusic、EpicGamesLauncher、Battle.net、Netflix。
  - 浏览器（chrome、msedge、firefox、brave、opera、vivaldi、arc、iexplore）看标题：含 Claude、ChatGPT、Gemini、Copilot、DeepSeek、Grok、Kimi、豆包、通义、Perplexity 的算 AI 工具；含 YouTube、bilibili、哔哩哔哩、Netflix、Twitch、抖音、爱奇艺、优酷、腾讯视频、Disney+ 的算娱乐；含 GitHub、Stack Overflow、MDN、GitLab、pkg.go.dev、npm 的算编码；含 Gmail、Outlook、飞书、Slack 的算通讯；其余算网页。
  - 资源管理器、锁屏、任务管理器等系统程序算其他。
- 改规则后，已存的记录里：程序名规则按程序名重新分类；标题规则只对还留着标题的记录重新分类。
- 每天凌晨清理：记录保留 400 天，标题保留 30 天。

接口见 `api/modules/screentime.yaml`：

- `GET /screentime/summary?range=day|week|month&date=YYYY-MM-DD&hostId=`：时间范围、总分钟、各类别分钟、用得最多的 10 个程序、每天的各类别分钟（周、月）。日期按服务器时区，周从周一开始。
- `GET /screentime/settings`、`PUT /screentime/settings`：总开关、保存标题、关闭的电脑；返回里带每台电脑的名称、是否在线、是否支持。
- `GET /screentime/rules`、`POST /screentime/rules`、`DELETE /screentime/rules/{id}`。
- `DELETE /screentime/data`：清空，要提升权限。
- 动作目录 `screentime.summary`（只读）：AI 能问“今天编码多久”。
- 事件 `screentime.` 不发（每分钟一次太频繁），前端每分钟刷新。

## 界面

- 左栏“设备”组加“时间去向”，没有二级菜单。
- 页面：顶栏右侧“设置”；概要卡片（总时长、编码、AI 工具、娱乐）；工具栏左边日、周、月切换和前后翻，右边电脑选择（超过一台时）；主体：各类别占比横条列表；周、月视图多一张每天的堆叠柱状图；用得最多的程序列表。
- 没有数据时写明原因：没有 Windows 代理、已关闭、刚开始记录。
- 今日页卡片“电脑时间”：今天总时长，下面各类别的小时数和横条。没有任何记录时不出现。

## 验收

- Windows 电脑上开着代理，一小时后页面上有这一小时的记录，类别合理。
- 锁屏、走开 5 分钟以上的时间不算。
- 默认不保存标题：数据库里 `title` 列全是空。打开“保存窗口标题”后才有。
- 浏览器里开 YouTube 标签算娱乐，开 Claude 网页算 AI 工具。
- 加一条规则“程序名 Foo.exe 算办公”，以前的 Foo.exe 记录跟着变。
- 隐藏内容锁着时，左栏和接口都看不到这个模块。
- 手机（390px）整页不横向滚动。

## 实现记录

- 代理：`backend/internal/agent/screentime/`。每 15 秒取一次前台窗口（Windows 用 `GetForegroundWindow`），每个自然分钟结束时发出现最多的那个程序。锁屏、空闲 5 分钟以上、取不到窗口的采样不算。协议在 `pkg/protocol/methods_screentime.go`。
- 服务端：`backend/internal/server/modules/screentime/`。`module.go` 收样本、设置、规则、清空，`classify.go` 分类，`summary.go` 汇总，`actions.go` AI 动作 `screentime.summary`。迁移 `20261010000100_m16_b116_screentime.sql`。
- 前端：`web/src/features/screentime/`。页面 `ScreenTimePage.tsx`，设置弹窗 `SettingsDialog.tsx`，今日页卡片 `TodayScreenTimeCard.tsx`。今天没有记录时今日页不显示这张卡片。
- 和规格的出入：
  - 清理任务每小时跑一次（不是每天凌晨），做的事一样：记录保留 400 天，标题保留 30 天。
  - 选“全部电脑”时，同一分钟两台电脑都在用会算两分钟，总时长可能超过一天的 24 小时。
  - 删规则或加规则后，只有还留着标题的记录会按标题规则重新分类。标题已丢掉的浏览器记录保留原来的类别。
  - 样本只收一天以内的，所以不能补传昨天以前的数据。
- 没有在真实 Windows 电脑上验证：`GetForegroundWindow` 那一段只做了 Windows 交叉编译和 `go vet`。端到端测试用的是 Linux 代理，只走“没有能记录的电脑”的页面和设置。
