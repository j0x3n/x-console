# B61 AI 记忆

用户 2026-10-01 提的：面板 AI 加记忆功能，和 Agent 共用，但 Agent 只能读。用户确认远程 AI（MCP）不给读。

前后端都待做。

## 要什么

- 一条记忆是一段短文字，比如“我的主路由是 OpenWrt，地址 192.168.1.1”“周报每周五下午写”。
- 面板 AI 每次对话都带上全部记忆。用户说“记住……”“以后……”时，面板 AI 存一条；也能改、能删。
- Agent 读得到，写不了：编码 Agent（B47 的 `modules/aiagents`）、机器会话（B33 的机器 Agent）开始干活时带上记忆，但它们的工具里没有记忆的写入工具。
- 远程 AI（MCP，`modules/mcp`）看不到记忆，工具列表里也没有。
- 设置 → AI 里能看到全部记忆，手动增删改，也能整个关掉（关掉后谁都不带记忆，已有的不删）。
- 隐藏内容锁定时，记忆里不能提到被隐藏的东西：记忆不分隐藏不隐藏，所以 AI 在锁定状态下存记忆时，规则和存笔记一样，不要把隐藏笔记的内容写进记忆（提示词里写清楚，见下）。

## 契约（待写，新增 `api/modules/ai.yaml` 里的路径）

- `GET /ai/memories`：`{enabled: boolean, items: Memory[], usedChars: integer, limitChars: integer}`。
- `POST /ai/memories`：`{text}`，回 `Memory`。
- `PATCH /ai/memories/{memoryId}`：`{text}`，回 `Memory`。
- `DELETE /ai/memories/{memoryId}`：204。
- `PUT /ai/memories/enabled`：`{enabled}`。
- `Memory`：`id`、`text`（1 到 500 字）、`source`（`user` 手动加的，`ai` 面板 AI 加的）、`createdAt`、`updatedAt`。
- 总字数上限 `limitChars` 4000。新增或修改后超过上限时回 400，文字“记忆总共最多 4000 字，先删掉一些”。

   开关存设置键 `ai.memory_enabled`，默认 true。

2. 接口：照上面的契约，放在 `modules/ai/memory.go`。审计记 `ai.memory.create`、`ai.memory.update`、`ai.memory.delete`。

3. 给其他模块用的读接口：在 `contracts` 里加

   ```go
   // Memories gives the AI memory to agents, read only.
   type Memories interface {
       // Prompt returns the memory as a block for a system prompt, or "" when
       // memory is off or empty.
       Prompt(ctx context.Context) string
   }
   ```

   ai 模块实现并注册（照 `contracts.LLM` 的注册方式），在 `docs/tasks.md` 的“接口变更记录”里记一笔。`Prompt` 的格式：

   ```
   ## 关于用户的记忆（只读参考，可能过时，和用户这次说的冲突时以用户为准）
   - 我的主路由是 OpenWrt，地址 192.168.1.1
   - ……
   ```

4. 面板 AI（`modules/ai/worker.go` 的 `systemPrompt` 组装处）：
   - 系统提示词后面加上 `Prompt(ctx)`。
   - 加三个动作给面板 AI 用（注册到动作目录，`Effect: Write`）：`memory.save {text}`、`memory.update {id, text}`、`memory.delete {id}`（删除算删除操作，按 B60 的权限档要确认）。列表时 `Prompt` 里每条前面带上 `[id]`，方便 AI 改和删。
   - 提示词加一段规则：用户明确要求“记住”或者说了以后长期适用的偏好时才存；不存一次性的事、密码、令牌、验证码；不存隐藏笔记和隐藏文件里的内容；存之前先看有没有相近的，有就更新那条。
5. Agent 只读：
   - `modules/aiagents/work.go` 组装 `system` 的地方，后面加上 `Prompt(ctx)`。
   - 机器会话（B33，`modules/ai/host_handlers.go` 和 `hostagent` 包里组装系统提示词的地方）同样加上。
   - 这两处的工具列表里不能有 `memory.*`。按动作名前缀过滤。
6. MCP：`modules/mcp` 列工具和执行工具时排除 `memory.*`，也不调用 `Prompt`。
7. 测试：
   - 增删改查、4000 字上限、关掉后 `Prompt` 返回空。
   - 面板 AI 的系统提示词里有记忆；编码 Agent 和机器会话的系统提示词里也有，但工具列表里没有 `memory.*`。
   - MCP 的工具列表里没有 `memory.*`，调用 `memory.save` 回“没有这个工具”。
