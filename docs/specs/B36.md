# B36 项目：二级分类、检查清单、截止到分钟、粘贴图片、工具栏合并

用户要求（2026-09-28）：

1. 项目内支持二级分类。
2. Issue 编辑时可以加子功能勾选框，和 Trello 的检查清单一样。
3. 截止日期精确到分钟，到期时弹出站内通知。
4. 内容里可以粘贴图片。站内所有文件分类放在一个目录下方便备份（B24 已经定了目录）。
5. 看板上方的名称缩写、显示方式、分组这些，都合并到搜索那一行。

## 1. 二级分类

用户原话是“项目内支持二级分类”。按下面理解，验收时和用户确认：**一个项目里的 Issue 可以归到分类下，分类最多两级**。比如项目“X Console”下有“后端 / 服务器”“后端 / 云盘”“前端 / 设置页”。

- 新表 `project_categories(id, project_id, parent_id, name, position)`。`parent_id` 为空是一级，一级下面可以有二级，不能再往下。
- `issues` 加列 `category_id`，可以为空。
- 项目设置里管理分类：新建、改名、拖动排序、删除（删除时里面的 Issue 变成“未分类”，二次确认）。
- 侧边栏里项目的二级菜单显示一级分类（`registerNavChildren`，最多 5 条）。
- 看板和列表的工具栏加“分类”筛选，选一级时包含它下面的二级。
- “分组”下拉加一项“按分类分组”。
- Issue 卡片上显示分类名（小字，`一级 / 二级`）。
- 新建和编辑 Issue 时可以选分类，下拉按两级缩进显示。

如果用户的意思是“项目列表分组”（项目本身分两级），改成：`projects` 加 `group_id`，项目列表按分组显示。开工前先确认。

## 2. 检查清单

- 一个 Issue 可以有多个检查清单，每个清单有标题和若干条目。条目：文字、是否完成、顺序。
- 新表 `issue_checklists(id, issue_id, title, position)`、`issue_checklist_items(id, checklist_id, text, done, position, done_at)`。
- Issue 详情里，描述下面显示清单：
  - 标题旁边显示进度 `3/5` 和一条进度条。
  - 勾选条目立即保存。点文字可以编辑，回车保存并新建下一条。拖动排序。
  - “隐藏已完成的条目”开关。
  - 清单和条目都可以删除，删除清单要二次确认。
- 看板卡片上显示总进度 `☑ 3/5`，全部完成时变成 `ok` 颜色。
- Issue 的“更多”菜单里有“添加检查清单”。
- 条目可以“转成 Issue”：新建一个 Issue，标题用条目文字，原条目删掉。
- 事件：`issue.checklist_changed`，前端据此刷新。

## 3. 截止时间精确到分钟

- `issues` 加列 `due_at`（UTC 时间，可以为空）。原 `due_date` 先保留（迁移只加不删）：迁移时把已有的 `due_date` 写成当天 23:59（服务器时区）的 `due_at`。接口里新增 `dueAt`，`dueDate` 标记为废弃，下个版本删。
- 编辑界面：日期加时间（`datetime-local`），可以只选日期（这时时间默认 23:59）。
- 列表和卡片上：今天到期的显示“今天 18:00”；已过期的用 `danger` 颜色，写“已过期 2 小时”。
- 到期提醒：
  - 每分钟检查一次，到期且没完成的 Issue 发一条通知（`issue.due`，站内和已开的推送渠道都发），每条 Issue 只发一次；改了截止时间后重新算。
  - Issue 里可以选“提前提醒”：不提醒、到期时（默认）、提前 15 分钟、1 小时、1 天。
  - 通知点开跳到这个 Issue。
  - 站内通知的弹出和声音走已有的通知中心，不单独做。
- 排序“截止日期”和筛选“今天到期 / 7 天内 / 已过期”改用 `due_at`。

## 4. 粘贴图片

- 把笔记已有的粘贴、拖入图片功能挪进公共的 `components/markdown/MarkdownEditor`（“已知问题”里有这一条）。所有用这个编辑框的地方都能贴图：项目描述、Issue 描述和评论、日程备注、提醒备注、Agent 任务。
- 公共上传接口：`POST /files/upload?scope=projects`（或者各模块自己的附件接口，二选一，选定后写进 `docs/05-frontend.md`）。文件存到 B24 的 `files/projects/<issueId>/` 下。
- 图片上传时先显示占位 `![上传中…]()`，成功后换成真实地址；失败时提示并删掉占位。
- 图片地址用站内相对路径，要登录才能访问。
- Issue 删除时，它的图片一起删掉。
- 单张不超过 20 MB，大图自动生成缩略图显示，点开看原图。

## 5. 工具栏合并

现在看板上方一行是：项目缩写标签、看板/列表切换、分组、排序、快捷键提示；下面还有一行搜索和筛选。合并成一行：

```
[🔍 搜索 Issue]  [状态▾] [优先级▾] [分类▾] [标签▾]      [分组▾] [排序▾] [看板|列表]
```

- 项目缩写标签去掉，左上角标题已经有项目名。
- 快捷键提示去掉，放到“更多”菜单里的“快捷键”一项，或者按 `?` 弹出。
- 用公共的 `Toolbar`（`start` 放搜索和筛选，`end` 放分组、排序和视图切换）。窄屏自动变两行。
- “新建 Issue”按 B20 放在顶栏。

## 验收

- 分类：建两级分类，Issue 归类后按分类筛选和分组都对；删一级分类后它下面的 Issue 变成未分类。
- 检查清单：加两个清单共 5 条，勾 3 条，卡片显示 `3/5`；刷新后顺序和状态都对；条目转 Issue 成功。
- 截止时间：设成 2 分钟后，到点收到一条通知，只收到一次；改成 5 分钟后再收到一次。旧数据的 `due_date` 迁移后显示为当天 23:59。
- 粘贴图片：在 Issue 描述和评论里各贴一张截图，保存后刷新能看到；文件在 `data/files/projects/` 下；删 Issue 后文件没了。
- 工具栏：1360px 一行放下；390px 两行，没有横向滚动。
- 新功能各补一条端到端测试（AGENTS.md 要求）。
