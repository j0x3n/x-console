# B242 笔记导出图片

用户 2026-10-17 提出。把笔记导出成一张长图，主要用来发微信。

## 要什么

- 笔记编辑器的“更多”菜单里加“导出图片”，放在“链接分享”下面。隐藏笔记也能导出。
- 点了先弹出导出设置，下面是预览，确认后再导出。

### 导出设置

- 范围：“整篇”或“选中的部分”。
  - 打开弹窗前选中了内容，默认选“选中的部分”；没选中时这一项是灰的。
  - 编辑模式：取输入框里选中的那段 Markdown 原文，照常渲染。
  - 阅读模式：取页面上选中的那部分渲染结果。
- 图片里放哪些内容，每项一个勾选框：
  - 标题，默认勾选。
  - 日期，默认勾选。用最后修改时间，格式 `2026-10-17`。
  - 标签，默认不勾。
  - 隐藏块的内容，默认不勾。不勾时隐藏块整个不出现，连“已隐藏”那一行也不出现。
  - 底部的“X Console”字样，默认不勾。
- 勾选结果存在浏览器本地（`localStorage`），下次打开还是上次的选择。范围不记。
- 改了任何一项，预览马上跟着变。

### 图片的样子

- 背景色用笔记自己设的颜色（`noteColors`）。没设颜色就是白底。
- 不管界面是不是深色模式，图片一律用浅色那套颜色。
- 排版宽度 400 CSS 像素，四周留 24 像素空白。按 2.7 倍导出，图片宽 1080 像素，适合手机看。
- 正文样式和分享页一样，用公共的 `components/markdown/Markdown` 渲染。
- 代码块在图片里自动换行，不出现横向滚动条。表格宽度不超过 400，单元格里的字换行。
- 图片附件照常显示。外链图片读不到时，原位置显示灰色方块和“图片无法导出”，导出后提示“有 N 张图片没导出”。
- 视频和音频显示成一行字：“视频：文件名”“音频：文件名”。
- 链接显示成普通的带下划线文字，不加网址。

### 太长时

- 所有平台都按总像素不超过 1600 万算（iOS Safari 的 canvas 上限）。
- 超过时自动降低倍数，最低 1.5 倍。降到 1.5 倍还放不下，提示“内容太长，选一部分再导出”，不导出。

### 导出以后

- 电脑上：按钮“保存图片”直接下载 PNG，另有“复制图片”写进剪贴板，可以直接粘贴到微信电脑版。浏览器不支持写图片到剪贴板时不显示这个按钮。
- 手机上：浏览器支持分享文件（`navigator.canShare({ files })`）时，按钮是“分享”，调出系统分享面板，可以选微信或存到相册。不支持时退回“保存图片”。
- 文件名：`笔记标题-20261017.png`。标题为空时用“笔记”。文件名里不能用的字符换成 `-`。

## 怎么做

- 只改前端：`web/src/features/notes/` 和 `web/package.json`。不改后端、不加迁移、不改接口定义。
- 加一个依赖 `modern-screenshot`，锁定精确版本。它把一块 DOM 画到 canvas 上。
- 导出时在页面外（屏幕可见区域以外，不用 `display: none`）渲染一份专门的排版，截这一份，不截编辑器本身。
- 截图前等字体加载完（`document.fonts.ready`），等所有图片加载完或失败。
- 新文件建议：`ImageExportDialog.tsx`（弹窗和预览）、`imageExport.ts`（选项读写、选中内容截取、倍数计算、文件名，这些是纯函数，单独测）。
- 界面按 `docs/07-design.md`，弹窗用现有的公共弹窗组件。

## 不做

- 服务器端生成图片。
- 分享页（访客）导出图片。
- 水印、二维码。
- 导出 PDF。

## 验收

- 单元测试：选项存取和默认值；编辑模式下取选中的 Markdown；倍数计算（正常、降倍、太长拒绝）；文件名处理。
- 前端组件测试：没选中内容时“选中的部分”是灰的；取消“标题”后预览里没有标题；不勾“隐藏块的内容”时预览里没有隐藏块。
- 端到端（第一部分）：新建一篇带标题和正文的笔记，打开“导出图片”，点“保存图片”，拿到的文件是 PNG，宽 1080 像素。
- 截图自查：导出弹窗在 1360 和 390 宽各截一张，按 `docs/07-design.md` 第七节检查。
