# B114 路由器改成脚本主动上报

用户 2026-10-09 提的：路由器的连接状态能不能改成脚本主动上报，不再依赖代理。

## 为什么要加

B65 的连接方式有两种。面板直连路由器，或者让家里装了代理的电脑转发。面板在外网时只能选第二种，那台电脑关机，路由器页就没有数据。

新增第三种：路由器自己跑一个脚本，每分钟把状态发给面板。面板不访问路由器，不需要代理，也不需要在路由器上开 ubus 的网页接口和建账号。

直连和代理两种方式不删，还能用。

## 做法

- 路由器上放 `/usr/bin/xc-report.sh`，cron 每分钟跑一次。脚本用 `ubus call` 读 `system board`、`system info`、`network.interface dump`、`network.device status`，再读 `/tmp/dhcp.leases` 和 `/proc/net/arp`，拼成一份纯文本，POST 给面板。
- 纯文本按 `#xc:<名字>` 开头的行分段，段名是 `time`（路由器当前的 Unix 时间）、`board`、`info`、`interfaces`、`devices`、`leases`、`arp`。ubus 的输出本来就是 JSON，租约和 ARP 是原始文件。这样脚本里不用做 JSON 转义，面板复用 B65、B93 已有的解析。
- 脚本用 `curl`，没有 curl 时用 OpenWrt 自带的 `uclient-fetch`。
- 面板的接口：`POST /router/report`，不需要登录，用 `Authorization: Bearer <令牌>` 校验。令牌是 32 字节随机数，面板只存 sha256，比较时用常量时间。
- `POST /router/push/token`：要提升权限。生成新令牌，切到 push 模式，清掉旧的 ubus 地址、账号、密码和代理设置。回复里有令牌和填好地址、令牌的完整安装命令。令牌只出现这一次，丢了就重新生成，旧令牌马上失效。审计记 `router.push.token`。
- 保存一个路由器地址（`PUT /router/config`）会退出 push 模式并作废令牌。删除设置（地址留空）也一样。`PUT /router/config` 不能直接填 `mode=push`。
- 上报地址用 `XC_PUBLIC_URL`，没配置时从请求的 Host 推出来。

## 面板怎么用上报的数据

- 状态、接口、在线设备都来自最近一次上报，字段和直连时一样，`GET /router/status` 多一个 `source`（`ubus` 或 `push`）。
- 速率按相邻两次上报的 WAN 网卡计数算（平均一分钟），不是实时的。流量表照常每分钟存一段，和直连一样，计数变小按新值算，隔了超过 5 分钟的不存。
- 租约到期时间按路由器自己的时钟算，路由器时间和面板差几分钟也不影响。
- 在线时长（`onlineSince`）仍是面板第一次连续看到它的时间。

## 离线判断和通知

- 超过 3 分钟没收到上报，判路由器离线，推一次“家里的路由器不上报了”。下一次收到上报时推“家里网络恢复了”，写上断了多久。
- 上报里 WAN 口是 down，照旧 2 分钟后推“WAN 口掉线了”。
- 面板重启后，给路由器一整个周期（3 分钟）再判离线，免得重启就误报。
- 离线期间路由器页显示“已经 N 分钟没收到路由器的上报，上一次在 HH:MM”（502 `router_unreachable`），从没收到过上报时提示去执行安装命令。

## 限制

- 不能从面板重启接口和重启路由器（409 `router_push_mode`），页面也不显示这两个按钮。要重启请在路由器上操作。
- 刷新频率选 1 秒没有意义，数据一分钟才更新一次。
- 路由器要能访问面板的地址。面板用 https 时，路由器没有 curl 就要装 `ca-bundle` 和 `libustream-mbedtls`，不然 `uclient-fetch` 连不上。

## 验收

- 设置 → 路由器，连接方式选“路由器主动上报”，点“生成上报令牌”，在路由器上粘贴命令，最后一行显示“已上报一次”。
- 路由器页一分钟内有数据：WAN、接口、在线设备，速率在第二次上报后出现。
- 拔掉路由器电源或网线，约 3 分钟后收到通知；接回去收到恢复通知。
- 重新生成令牌后，旧脚本上报返回 401。

## 实现（2026-10-09，Claude）

- 后端：`router/report.go`（接口、令牌、解析、离线判断）、`router/report.sh`（脚本，`go:embed`，`@URL@`、`@TOKEN@` 在生成安装命令时替换）。`status.go` 把状态拼装和设备合并拆成函数，直连和上报共用。没有新迁移，令牌哈希存在设置表的 `router.push_hash`。
- 前端：设置 → 路由器的连接方式多一项，选它后显示令牌区域；路由器页在 `source=push` 时不显示重启接口和重启路由器。
- 测试：`router/push_test.go`（令牌、鉴权、状态、速率、设备、流量、离线和恢复、切换回直连），`RouterPage.test.tsx` 加了界面用例。
- 没有在真实 OpenWrt 上跑过。脚本在这里只用假的 `ubus` 和 `curl` 验证了拼出来的内容，`uclient-fetch` 的参数按 OpenWrt 文档写。
