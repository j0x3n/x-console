# B51 域名到期：WHOIS 兜底，手动填日期

用户 2026-10-01 问：为什么 `xcc.im` 提示“RDAP 查不到这个域名”。

原因：`.im` 的注册局没有提供 RDAP 服务，IANA 的 RDAP 目录里没有它。`rdap.org` 找不到对应服务就回 404。不少国家域名都是这样。现在 `checks.go` 的 `probeDomain` 只走 RDAP。

## 前端（已完成）

- 编辑 `domain` 监控时多一个“到期日期（手动）”。填了就传 `manualExpiresAt`，清空就传 `clearManualExpiry: true`。说明写“只在 RDAP 和 WHOIS 都查不到时用”。
- 详情里显示“查询来源”：RDAP、WHOIS 或手动填写（`expirySource`）。查不到时提示可以手动填日期。
- 证书和域名列表里查不到的项显示“域名 查不到”。

## 契约（已改）

`api/modules/monitoring.yaml`：

- `Monitor` 加 `expirySource`（`rdap | whois | manual`）和 `manualExpiresAt`（date）。
- `MonitorPatch` 加 `manualExpiresAt`（date）和 `clearManualExpiry`（boolean）。
- `MonitorResultDetail` 加 `source`（`rdap | whois | manual`）。

### 2. WHOIS 查询

新文件 `whois.go`：

- 找 WHOIS 服务器：TCP 连 `whois.iana.org:43`，发 `<顶级域>\r\n`（比如 `im\r\n`），在返回里找 `whois:` 开头的行，取后面的主机名。按顶级域缓存在内存里 24 小时。找不到就当这个后缀不支持 WHOIS。
- 查域名：TCP 连 `<服务器>:43`，发 `<域名>\r\n`，读到对方关闭连接，最多 64 KB，整次超时 10 秒。返回里有 `Whois server:` 或 `Registrar WHOIS Server:` 指向另一台服务器时（`.com`、`.net` 这类），再查一次那台，以第二次的结果为准。
- 解析到期时间：逐行看，冒号前的名字不区分大小写，认这些：`Registry Expiry Date`、`Registrar Registration Expiration Date`、`Expiry Date`、`Expiration Date`、`Expiration Time`、`Expires On`、`Expires`、`paid-till`、`Valid Until`、`Renewal Date`。冒号后的值按这些格式依次试：`time.RFC3339`、`2006-01-02T15:04:05Z`、`2006-01-02 15:04:05`、`2006-01-02`、`2006.01.02`、`2006/01/02`、`02/01/2006 15:04:05`、`02/01/2006`、`02-Jan-2006`、`January 2 2006`。日在前的写法（`02/01/2006`）按日在前解析，`.im` 就是这种。
- 注册商：`Registrar:` 那一行的值。
- 服务地址可以在设置里覆盖，键 `monitoring.whois_iana`（默认 `whois.iana.org:43`），方便测试指向本地假服务。
- 拨号用 `net.Dialer{Timeout: 10 * time.Second}`，读写都设 deadline。不走 HTTP 代理。

### 3. 接到 probeDomain

`probeDomain` 改成三步：

1. 先查 RDAP（现在的代码）。拿到到期时间就 `source = "rdap"`。
2. RDAP 回 404、或者返回里没有到期时间，再查 WHOIS。拿到就 `source = "whois"`。RDAP 是网络错误时也试一次 WHOIS。
3. 都没拿到，监控有 `manual_expires_at` 时用它（当天 23:59:59，按 `m.loc()` 时区），`source = "manual"`，算成功。没有就失败，错误写“RDAP 和 WHOIS 都查不到这个域名，可以手动填到期日期”。

- `probeResult` 加 `Source`，记录检查结果时写进 `monitors.expiry_source` 和结果的 `detail.source`。
- `toAPIMonitor` 填 `ExpirySource`（空字符串时不填）和 `ManualExpiresAt`。
- `UpdateMonitor`：`manualExpiresAt` 只对 `domain` 有效，别的类型回 `httpx.Invalid("只有域名监控能手动填到期日期")`。`clearManualExpiry` 为 true 时清空。改了手动日期后立刻检查一次，让列表马上更新。
- 测试：`net.Listen("tcp", "127.0.0.1:0")` 起两个假 WHOIS 服务（一个当 IANA，一个当注册局）。覆盖：RDAP 404 时走 WHOIS 拿到日期；`dd/mm/yyyy` 格式按日在前；两段跳转；WHOIS 也没有、有手动日期时用手动日期；都没有时报错文字对。

### 4. 服务器网络

服务器要能连外网 TCP 43 端口。部署文档 `docs/06-deploy.md` 的防火墙说明里加一句。

## 验收

- `xcc.im` 能查到到期日期，详情里查询来源是 WHOIS。
- 在编辑里给一个查不到的域名填手动日期，列表显示剩余天数，来源是“手动填写”。清空后又变回“查不到”。
