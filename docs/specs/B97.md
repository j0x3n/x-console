# B97 个人计划：训练、日常习惯、饮食和英语学习

用户 2026-10-03 要求把 `个人提示计划.standalone.html` 的全部内容加入项目。前后端都由 Codex 完成。

## 要什么

- 习惯模块内增加个人计划入口。保留训练、日常习惯、饮食、英语学习、身体记录、设置和完整原文。
- 动作库含原文件的 38 个基础动作和 28 个补充动作。保留图解、中英文名、分类、器械、肌群、训练量、休息时间、准备、步骤、错误、简化和进阶条件。
- 保留 9 个力量模板、3 个手动选择的阶段、基础阶段的每周 A/B 交替、恢复日、有氧日和 9 个走跑级别。阶段不自动升级。
- 从动作库选择动作加入每周计划和自由训练。次数区间、秒、米和每侧说明完整保存。历史训练保存快照。
- 日常、饮食、英语及体态的打卡模板可以选择加入现有习惯。同一模板重复添加不创建第二个习惯。归档和删除后的状态清晰。
- 勾选模板打卡直接写入现有 `habit_logs`。今天页和统计共用这些记录。撤销只删除个人计划创建的那一条，不删除手动记录。
- 体重、腰围、睡眠、步数、精力、腰部反应、饮食记录、训练笔记和英语表达按日期存到服务端。展示真实体重均值和历史，不补零。
- 跟练可以逐组勾选。保存训练写入现有训练记录并自动打卡。重复保存更新同一训练，避免重复打卡。
- 支持原 HTML 的版本 1 JSON 备份和本项目的 JSON 备份导入、导出。导入前完整校验，事务内合并，失败不留部分数据。静态内容随项目发布，不要求上传原 HTML。
- 保留原文件的饮食说明、外卖检查、备餐、调整规则、护眼和工位说明、英语学习方法、词表安排、复习和原文来源。使用原页面修订内容，不重新制定医疗或饮食建议。

## 怎么做

- 模块范围：`habits`，接口在 `api/modules/habits.yaml`。提取的结构化内容嵌入后端，只有登录后才能读取。图解作为压缩后的 WebP 随前端发布。
- 个人设置和按日记录使用已有 `settings` 表。键为 `habits.personal_profile` 与 `habits.personal_day.YYYY-MM-DD`。不增加迁移，不改现有表结构。
- 设置里维护模板到习惯的 ID。按日记录维护自身产生的打卡 ID 和训练 ID。读取时核对原记录是否存在，外部撤销和删除立即生效。
- 所有读改写在 `BeginTx` 事务内进行。导入最多 2 MB。拒绝无效日期、未知模板、无效组数键和越界数值。
- `WorkoutItem` 兼容增加可选 `exerciseId` 和 `prescription`。既有动作名称、组数、次数、重量和备注照常工作。
- 页面使用现有 `PageHeading`、`StatStrip`、`Toolbar`、`Dialog`、`Markdown` 和表单样式。健身页替换占位。习惯导航增加个人计划入口。
- 简单计时器保留组间休息、护眼、英语学习和走跑分段。计时明确提示需要页面打开。
- 对外动作接入现有动作目录。新内容的读取与习惯模块使用相同权限。
