# B203 习惯页显示今天练什么

2026-10-14 用户提的：“跑步、健身，我腰突还想薄肌，能不能也给到具体动作。”

## 现状

个人计划（B97）本来就是按腰突写的，带增肌的分阶段力量课、9 级走跑交替、66 个动作（每个动作有图解、准备、步骤、常见错误、降级和进阶）。问题是它藏在“个人计划 → 跟练”里，习惯页上看不到，跑步和力量训练两个习惯也没连到它。

## 做法

- 习惯“今天”页顶部加“今天练什么”卡片，只用前端已有的接口（`/habits/library`、`/habits/personal/profile`、`/habits/schedule`）：
  - 按个人计划的阶段和星期取今天的课：力量课、有氧日（按走跑级别）或恢复日。
  - 列出动作和量，点动作弹出动作详情（图解、步骤、准备、常见错误）。
  - “开始跟练”进 `/habits/plan?section=training&date=今天`。
  - 底部固定一句腰部安全提醒：只做到不痛的范围；新出现腿麻、腿痛往下窜或无力就停下看医生；会阴发麻、大小便控制不了马上急诊。和计划里“保留的边界”一致。
  - 写明“按个人计划”，因为下面的“健身”模块按另一套“每周计划”显示。
- 不改计划内容。阶段、起始日期、走跑级别在“个人计划 → 计划设置”里改。

## 没做

- 把“每周计划”和“个人计划”合成一套。两套并存会让人困惑，要合并得先问用户留哪个。记在已知问题。

## 验收

- 习惯页打开就能看到今天的课和动作，手机上不溢出。
- 点动作能看到要领，点“开始跟练”进跟练清单。
