# B41 报错统一显示：控制台打印、界面常驻、可以复制

用户 2026-09-30 提出：任何报错都要在控制台打印，同时在界面上显示；报错提示不要自动消失；内容太长可以不显示完整，但要能复制完整内容。

## 现状

- `hooks/useToast.ts` 只有一条提示，5 秒后自动消失，报错和成功提示一样处理。新的提示会顶掉旧的。
- 接口报错只有 `{code, message}`，没有请求编号，看到报错也没法去服务器日志里找对应的记录。
- 手机上看不到浏览器控制台，页面报错（渲染出错、未处理的 Promise）用户完全不知道。

## 要什么

### 前端

- 新增 `lib/errors.ts`：`reportError(error, { title?, silent? })`。所有报错都走它：
  - 用 `console.error("[X Console]", title, detail)` 打印完整对象，包括原始错误和调用栈。
  - 往报错列表里加一条，界面显示。`silent: true` 时只打印，不显示。
- `api/client.ts` 遇到非 2xx 时抛 `ApiError`：请求方法、路径、HTTP 状态、`code`、`message`、`requestId`、响应正文（最多 4 KB）、时间。
- 自动上报，不需要每个页面自己写：
  - React Query 的 `QueryCache` 和 `MutationCache` 的 `onError` 调 `reportError`。个别请求可以用 `meta: { silentError: true }` 关掉，比如轮询状态、探测接口是否上线（回 501 的那些）。
  - `window.onerror`、`unhandledrejection`、React 的错误边界。
  - 现有的 `toast({ tone: "error" })` 调用改成走 `reportError`，调用方不用改（在 `toast` 里转过去）。
- 不算报错、不弹提示的情况：401（跳登录页）、用户主动取消的请求（`AbortError`）、WebSocket 断线（已有黄点提示）。
- 去重：10 秒内同一个路径、同一个 `code` 的报错只显示一条，右上角显示次数 `×3`。

### 报错提示的样子

- 报错提示不自动消失，只能手动关。成功提示还是 5 秒消失。
- 最多同时显示 3 条，新的在上面。超过 3 条时最下面一行写“还有 N 条报错”，点开看全部，旁边有“全部关闭”。
- 每条：标题（比如“保存笔记失败”，没传标题时用“请求失败”），下面是 `message`，最多两行，超出用省略号。
- 按钮：“复制”和关闭。复制成功后按钮文字变成“已复制” 2 秒。
- 点正文可以展开，展开后最多显示 12 行，里面可以滚动。
- 复制的内容是纯文本，格式固定，方便直接贴给 AI 或发到 Issue：

  ```
  保存笔记失败
  时间：2026-09-30 14:03:22
  请求：PATCH /api/v1/notes/12
  状态：500 internal
  信息：database is locked
  请求编号：01J9…
  页面：/notes/12
  浏览器：Mozilla/5.0 (iPhone; …)
  响应：{"code":"internal","message":"database is locked"}
  调用栈：
  …
  ```

- 位置：桌面在右下角。手机在底部，宽度占满（左右各留 12px），避开安全区。样式按 `docs/07-design.md`，用 `danger` 颜色的图标，不要整条红底。
- 设置 → 通用加一个“最近的报错”列表，保留本次打开页面以来的最近 50 条，每条可以复制，可以一键复制全部。

### 后端

- `httpx` 加请求编号中间件：每个请求生成一个编号（ULID），写到响应头 `X-Request-Id`，报错的 JSON 加 `requestId` 字段。服务器日志里记录报错时带上这个编号。这是基础代码改动，要向后兼容，记到“接口变更记录”。
- 新接口 `POST /client-errors`：前端把显示过的报错（去重后）发给服务器，写进服务器日志，级别 `warn`，带上请求编号。手机上看不到控制台，靠它在系统日志（B29）里查。每个会话每分钟最多 30 条，超出直接丢掉。正文最多 8 KB。

## 验收

- 单元测试：报错不自动消失；成功提示 5 秒消失；超过 3 条折叠；10 秒内重复的合并计数；复制的文本包含上面列出的字段；401 和取消的请求不显示。
- 后端测试：报错响应带 `X-Request-Id` 和 `requestId`，两者一致；`/client-errors` 限流。
- 端到端：用 Playwright 拦截一个接口改成回 500，页面上出现报错提示，点“复制”后剪贴板里有请求编号；控制台有 `[X Console]` 开头的输出。
- 1360px 和 390px 截图：多条报错叠放不挡住页面主要按钮，没有横向溢出。
