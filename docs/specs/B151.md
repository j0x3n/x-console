# B151 云盘 MCP：AI 上传、下载、分享文件，和音乐动作

用户 2026-10-10 要求：云盘要支持 MCP，AI 能自动上传歌曲等文件。

## 现状（2026-10-10 查代码确认）

- MCP 接口（B43）把动作注册表按协议暴露，令牌只对 `/api/v1/mcp` 有效。
- 云盘已有 8 个动作：`drive.list`、`drive.search`、`drive.read_text`、`drive.create_folder`、`drive.write_text`、`drive.move`、`drive.rename`、`drive.delete`。
- 这些动作都不能传二进制文件。`drive.write_text` 只能写不超过 1 MB 的文本。
- MCP 请求体上限是 1 MB（`mcp/rpc.go` 的 `maxBody`）。一首 mp3 通常 3 到 10 MB，base64 之后更大，所以不能把歌放进工具参数里。
- 令牌不能访问普通 REST 接口，所以 AI 不能直接调云盘的上传接口。

所以要加新的上传办法，不能只是多注册几个动作。

## 三种上传办法

AI 按自己的环境选：

| 动作 | 适用 | 说明 |
| --- | --- | --- |
| `drive.upload_from_url` | AI 有下载链接 | 服务器自己去下载，不经过 MCP 请求体 |
| `drive.create_upload_link` | AI 在电脑上有命令行（Claude Code、Codex CLI 等）和本地文件 | 返回一次性上传地址，AI 用 `curl -T 文件 地址` 上传 |
| `drive.upload_base64` | 小文件（封面图、`.lrc` 之外的二进制） | 文件内容放在参数里，限 600 KB |

没有命令行也没有下载链接的 AI（比如纯聊天客户端），只能传 600 KB 以内的小文件，歌曲传不了。这是协议限制，不是实现问题，要在工具说明里写明，AI 才不会反复尝试。

### 共同规则

- 都不能覆盖已有文件。同名时默认返回 409 和说明，参数 `onConflict: "rename"` 时自动改成 `名字 (1).扩展名`。
- 目录用 `parentId` 或 `parentPath`（例如 `/音乐/周杰伦`）。给 `parentPath` 时目录不存在就自动创建，参数 `createParents` 默认 true。
- 文件名走云盘现有的 `validName`。
- 大小限制和容量检查用云盘现有的规则。另有设置键 `drive.mcp_max_upload`，默认 1 GB，限制单个文件。
- 隐藏目录里的内容一律不可见、不可写，和其他云盘动作一致。
- 审计日志的 actor 写 `token:<令牌名>`，记录文件名、大小和来源（URL 的域名，不带查询参数，因为链接里常有私密令牌）。
- 上传完成后发和普通上传一样的 `drive_item.created` 事件，所以音乐目录里的歌会自动入库（B146）。
- 令牌权限：上传算写，`write` 和 `write_delete` 令牌能用，`read` 令牌不能。

### `drive.upload_from_url`

参数：`url`、`parentId` 或 `parentPath`、`name`（可选）、`onConflict`。

- 只允许 `http` 和 `https`，端口只允许 80 和 443。
- 防止服务器被用来访问内网（SSRF）：
  - 先解析域名，再用解析出的 IP 连接，不再二次解析。
  - 拒绝回环、私有、链路本地（含 `169.254.169.254`）、运营商级 NAT（100.64.0.0/10）、唯一本地（fc00::/7）、未指定地址。
  - 重定向最多 5 次，每次都重新检查，不允许从公网跳到内网。
  - 不带本服务的任何凭据，不转发 Cookie 和 Authorization。
- 限制：连接超时 10 秒，无数据超时 60 秒，总大小受 `drive.mcp_max_upload` 限制。有 `Content-Length` 时先检查，没有时边下载边计数，超出就中止并删除临时文件。
- 文件名：用参数 `name`；没有就用 `Content-Disposition`；再没有就用 URL 路径的最后一段。
- 用云盘现有的任务机制（`drive/tasks.go`）异步下载。动作最多等 20 秒，完成就直接返回文件信息，否则返回 `taskId`。
- 新增只读动作 `drive.task_status`（参数 `taskId`），返回进度、已下载字节、完成后的文件信息或错误。

### `drive.create_upload_link`

参数：`parentId` 或 `parentPath`、`name`、`size`（可选，已知时填）、`onConflict`。

- 返回 `uploadUrl`、`expiresAt`、`maxSize`、一句 curl 示例。
- 新表 `drive_upload_links`：id、token_hash、parent_id、name、on_conflict、max_size、expires_at、used_at、created_by（令牌名）、created_at。令牌用 32 字节随机数，库里只存 SHA-256。
- 一次性：上传开始后立即标记已用，不论成功失败都不能再用。10 分钟有效。
- 公开入口 `PUT /api/v1/drive/upload-links/{token}`，请求体就是文件内容，不用 multipart。这个路径不需要登录，靠令牌校验。做法照 `share_public.go`：令牌无效、过期、已用统一回 404，不区分原因。
- 同一 IP 的失败次数限速，复用 `auth/ratelimit.go`。
- 文件名和目录在创建链接时固定，上传的人不能改。
- 请求体超过 `maxSize` 就中止，回 413，并删除临时文件。
- 成功回 201 和文件信息。
- 过期的链接记录每天清理一次。

### `drive.upload_base64`

参数：`name`、`dataBase64`、`parentId` 或 `parentPath`、`onConflict`。解码后不超过 600 KB（MCP 请求体 1 MB 减去 base64 膨胀和其他字段）。MCP 请求体上限不改。

## 其他云盘动作

补齐 AI 整理文件常用的操作：

| 动作 | 级别 | 说明 |
| --- | --- | --- |
| `drive.resolve_path` | 读 | 路径转条目 ID，找不到返回空 |
| `drive.info` | 读 | 大小、类型、路径、修改时间、有没有分享、音乐标签（B146 做完后） |
| `drive.copy` | 写 | 复制文件或文件夹到另一个目录 |
| `drive.create_download_link` | 读 | 一次性下载地址，10 分钟有效，给有命令行的 AI 用 `curl` 下载二进制文件。机制和上传链接对称，表 `drive_download_links` |
| `drive.share_list` | 读 | 某个条目的分享（不返回提取码）|
| `drive.share_revoke` | 写，破坏性 | 撤销分享。只有 `write_delete` 令牌能用 |

- `drive.delete` 已有，只移到回收站，仍然只给 `write_delete` 令牌。
- 全部动作的 `Description` 写清楚：参数格式、哪些会失败、怎么处理 409、给下一步建议。外部 AI 只能看到这段文字。

## 音乐动作（依赖 B146、B148）

AI 上传歌之后常见的下一步。这些在服务端执行，不涉及浏览器播放：

| 动作 | 级别 | 说明 |
| --- | --- | --- |
| `music.search` | 读 | 按歌名、歌手、专辑、歌词搜曲库 |
| `music.scan` | 写 | 重新扫描音乐目录 |
| `music.match` | 写 | 对指定歌曲或全部缺歌词封面的歌运行在线匹配，返回任务 ID |
| `music.pending` | 读 | 待确认的歌和候选 |
| `music.playlist_create` | 写 | 新建播放列表并加歌 |
| `music.playlist_add` | 写 | 往播放列表加歌 |

- 不提供播放、暂停、切歌的动作。播放在浏览器里，服务端不能替它出声。这一条替换 [B146-B150](B146-B150.md) 里“AI 助手和 MCP 的音乐动作”那一条范围外说明。
- 隐藏目录里的歌不出现。

## 内置 AI 助手

动作注册表是共用的，内置助手（AI 浮窗）自动也能用这些动作。`create_upload_link` 和 `create_download_link` 只对 MCP 有意义，注册时标 `MCPOnly`，不给内置助手。注册表里没有这个标记就加一个小字段，向后兼容，记入“接口变更记录”。

## 设置页

设置 → 远程访问（B43）里加两处：

- 接入说明里加一段“让 AI 上传歌曲”的示例：如何告诉 AI“把这些链接里的歌传到云盘的音乐目录”，以及有命令行时它会怎么用上传链接。
- 令牌的模块选择里，云盘和音乐是两个独立的模块，要分别勾选。

## 测试

- 后端集成测试放外部测试包：
  - 三种上传的成功、同名 409、`onConflict: rename`、`parentPath` 自动建目录、容量和大小限制。
  - 上传链接：一次性、过期、已用、无效令牌都回 404，请求体超限回 413 并清理临时文件，失败后也不能重用。
  - `upload_from_url`：用 `httptest` 假服务器测成功、重定向、超大文件中止、无 `Content-Length`。SSRF 测试：回环、私有地址、`169.254.169.254`、域名解析到内网、公网重定向到内网，全部被拒。测试里需要连本机假服务器时，用 `export_test.go` 注入放行的拨号函数，不在正式代码里加开关。
  - 令牌权限：`read` 令牌看不到上传动作，`write` 令牌看不到 `drive.share_revoke`，`tools/list` 里没有 `MCPOnly` 以外的泄漏。
  - 隐藏目录对所有新动作不可见。
  - 审计日志里的来源不含 URL 查询参数。
- 端到端：用 MCP 令牌，经 `tools/call` 创建上传链接，用 PUT 传一个小 mp3，云盘里出现，音乐目录自动入库（B146 之后）。

## 验收

- 有命令行的 AI 能用上传链接把本地的歌传到云盘指定目录，目录不存在会自动创建。
- 给一个下载链接，服务器能下载并存进云盘，大文件不会卡住 MCP 调用（返回任务 ID，之后能查进度）。
- 指向内网地址的链接被拒绝，错误信息不泄露内网信息。
- 上传链接用过一次或过了 10 分钟就不能再用。
- 没有命令行也没有链接的 AI，能传 600 KB 以内的小文件，传大文件时得到说明，不报晦涩的错。
- 令牌权限和模块过滤正确，隐藏目录的内容不会被 AI 读到或写入。
- 全部后端和前端检查通过，`git diff` 生成文件为空。

## 实现说明（2026-10-11）

- **没有 `drive.share_create`**。界面里创建公开分享要用户先验证密码（`auth.RequireElevated`），MCP 令牌不能提权。为了让 AI 能建分享而绕开这个检查，等于让一个令牌不经密码就能把文件公开，所以不做。要分享时 AI 告诉用户去云盘页建。`drive.share_list` 和 `drive.share_revoke` 保留，列表结果里去掉提取码。
- `drive.upload_from_url` 在 20 秒内没下完就返回 `{state:"running", taskId}`，之后用 `drive.task_status` 查。任务种类 `download`。
- 上传和下载链接只存令牌的 SHA-256，10 分钟，用一次，所有失败都回 404。迁移 `20261011000500_m29_b151_drive_links.sql`。
- 音乐动作在 `modules/music/actions.go`，调用和网页相同的处理函数。`music.match` 不带 `trackId` 时在后台跑，立即返回，不返回任务 ID（匹配进度在 `music.match_progress` 事件里，AI 用 `music.pending` 和 `music.search` 看结果）。不能通过动作确认候选，确认留给用户在音乐页做。
- 测试：`drive/mcp_actions_test.go`，`music/actions_test.go`。端到端里没有补这一条，见 `docs/tasks.md` 的已知问题。
