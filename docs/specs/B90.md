# B90 天气修正

用户 2026-10-02 提的：

- 天气文字显示毛毛雨，但图标还是多云，天气状态和图标的对应关系要修正。
- 天气地区选江苏东海后，数据和和风天气官方的不一样。
- 空气质量放到湿度后面。
- 正在降雨等实时天气要显示出来，并显示还要下多久。

## 原因（2026-10-02 查的）

- 图标：今日页天气条的图标写死成“多云”（`CloudSun`），没按天气选。
- 数据不一样：`GET /weather` 的实况和今天的预报一直用 Open-Meteo（模型数据），按经纬度查。和风天气只用在预警、分钟降水、空气质量这些扩展信息上。和风官方 App 显示的是它自己的实况。
- “湿度”：天气条上的“水滴 30%”是今天的降水概率，不是湿度。

## 怎么做

- **图标**（前端）：按天气选图标，见 B88。
- **数据来源**（后端）：配了和风天气时，`/weather` 改用和风天气：
  - 位置先用 GeoAPI 查到和风的城市 ID（按早报设置里的地名和经纬度，取第一个结果，缓存起来），再用城市 ID 查 `/v7/weather/now` 和 `/v7/weather/3d`。这样和官方 App 是同一个站点的数据。
  - `summary` 用和风的 `text`，`icon` 用和风的图标代码，`weatherCode` 按和风代码换成最接近的 WMO 代码（旧前端还能用），`humidity` 用和风的湿度，`precipitationChance` 用 3 天预报里今天的数据（没有就用逐小时预报的最大值）。
  - 没配和风天气时照旧用 Open-Meteo，加上 `relative_humidity_2m` 和 `is_day`。
  - 返回 `source`，前端在天气详情里写“数据来自和风天气 / Open-Meteo”。
- **湿度和空气质量**（前端）：天气条的顺序改成：地点、温度、天气、最高最低、湿度、空气质量、降水概率、降水提醒。降水概率换成雨伞图标，悬停写“今天降水概率”。
- **正在下雨**（前端）：用分钟降水算：
  - 现在有降水：显示“正在下雨，约 25 分钟后停”；两小时内都不停时显示“正在下雨，两小时内不会停”。
  - 现在没有、两小时内有：“20 分钟后有雨”（已有）。
  - 天气详情里分钟降水图上方写同样的话。

## 契约（已改）

## 后端实现（Codex，2026-10-02）

- 实况和今天高低温使用城市 ID 查询 v7 接口。湿度、文字和图标直接取和风数据。日预报没有降水概率时，取今天逐小时概率的最大值。
- 保留十分钟缓存和手动刷新一分钟间隔。城市 ID 复用设置缓存。实况或日预报失败时记录日志并退回 Open-Meteo。
- 使用 [城市实况文档](https://dev.qweather.com/docs/api/weather/weather-now-webapi-v7/) 和 [城市小时预报文档](https://dev.qweather.com/docs/api/weather/weather-hourly-forecast-webapi-v7/) 核对字段。官方已提示 v7 将弃用，后续迁移到 v1 需另开任务。当前按本任务要求继续用城市站点。
