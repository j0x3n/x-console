# B88 今日页：图标、布局、昵称、时间和天气的位置

用户 2026-10-02 提的：

- 一级导航「今日」的图标和首页右上角的天气图标同步。
- 首页「网络」下方的内容用和其他部分同样的卡片样式展示。
- 首页调整布局时，中间的卡片拖不到左边，各列之间要能自由拖动。
- 首页「早上好，x」里的昵称要能在设置里修改。
- 首页问候语后的时间和天气移到顶部早报左侧，把空间留给长名言。

## 怎么做（只改前端，昵称要后端存）

- **图标**：天气条和左栏“今日”都按当前天气选图标（晴、少云、多云、阴、雾、毛毛雨、雨、雪、雷雨、冰雹；晚上晴和少云用月亮）。有和风天气的 `icon` 时按它选，没有时按 WMO `weatherCode`。没设置天气时左栏用原来的太阳。
- **网络卡片**：路由器的几项（WAN、在线设备、速率）放进和其他卡片一样的行样式（`today-row`），不再是单独的一块。
- **拖动**：调整布局时，卡片可以拖到任意一列的任意位置，也可以拖到某一列的空白处（放到这一列最后）。现在的布局数据只有“主列”和“侧列”，侧列按列数平均分。改成每张卡片记自己在第几列（`column` 加 `side2`、`side3` 这类值不改接口：前端把列号存在 `LayoutCard.column`，旧数据照常读）。具体做法看前端提交。
- **昵称**：设置 → 账号（安全页）加“称呼”输入框，存到 `/me/preferences` 的 `nickname`。空时用登录名。接口没上线时存在本地。
- **时间和天气的位置**：问候语那一行只留问候语和每日一句（B89）。时间和天气挪到顶栏右边，“早报”按钮的左边。手机上时间不显示，天气只留图标和温度。

## 契约（已改）

- `core.yaml` 的 `Preferences` 加 `nickname`。

## 后端（待做，Codex）

- `me/preferences` 读写 `nickname`（最多 20 个字），没存过时不返回或为空。整份替换时缺的字段用默认值，不要把前端没传的新字段清掉以外的东西。

## 验收

- 天气是小雨时，天气条和左栏“今日”都是雨的图标。
- 调整布局时，主列的卡片能拖到右边任意一列，右边的也能拖回主列。
- 设置里改了称呼，今日页马上变。
