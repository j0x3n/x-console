# B72 笔记：滚动、双击编辑、外链分享、快速新建、浮窗

用户 2026-10-01 提的：

- 笔记编辑时不能上下滚动。
- 双击笔记内容进入编辑。
- 笔记能分享成外链。外链打开只有笔记内容。外链可以加密码，输对了才加载内容。
- 左栏“笔记”的折叠箭头左边加一个“+”，点了直接新建笔记。
- 笔记不管在编辑还是阅读，都能点右上角的按钮变成浮窗，然后去别的页面接着操作。

## 1. 滚动（前端）

编辑模式下正文的文本框按内容长高，滚动交给外面的 `.notes-editor-scroll`。查到的原因和改法写在提交里。验收：一篇长笔记在编辑、分栏、阅读三种模式下，鼠标滚轮和触摸板都能上下滚，手机上也能滚。

## 2. 双击进入编辑（前端）

- 阅读模式下双击正文或标题，进入编辑，光标放到双击的位置附近（按渲染后文字在原文里找到的位置；找不到就放到末尾）。
- 双击链接、图片、勾选框、代码块的复制按钮时不进入编辑。
- 选中文字后不会误触发：只有两次点击在同一处、中间没有拖动才算双击。
- 预览模式下双击也切回编辑。

## 3. 外链分享

### 界面

- 笔记右上角“更多”菜单加“分享”，打开分享弹窗：
  - 没分享时：有效期（1 天、7 天、30 天、永久，默认 7 天）、“设置密码”勾选框和密码输入框（4 到 32 位），“创建链接”按钮。
  - 已分享时：显示链接和“复制”按钮、有效期、有没有密码、打开次数、最后一次打开的时间；可以改密码、改有效期、“停止分享”（要确认）。
- 已分享的笔记，列表那一行和编辑区标题旁有一个小链接图标。
- 外链 `https://<面板>/n/<token>`，不用登录：
  - 只有笔记标题、正文（渲染后的 Markdown，图片能看）、更新时间。没有左栏、顶栏和任何按钮，底部一行小字“通过 X Console 分享”。
  - 有密码时先显示密码框，输对了才去取内容。密码对了服务端发一个 12 小时的访问令牌，存在 `sessionStorage`。
  - 深浅色跟随系统。手机上正常显示。
  - 链接失效（过期、停止分享、笔记删了或隐藏了、归档不影响）显示“这个链接已经失效”。
- 隐藏笔记不能分享（菜单里不显示“分享”）。笔记被设为隐藏时，后端自动停止分享。

### 契约（`api/modules/notes.yaml`，已改）

- `GET /notes/{noteId}/share`：这条笔记的分享，没有时 404。
- `PUT /notes/{noteId}/share`：创建或修改。请求 `NoteShareInput = { expiresIn: 1d|7d|30d|never, password?: string, clearPassword?: boolean }`。`password` 不传表示不改。要提升权限（和云盘分享一样）。
- `DELETE /notes/{noteId}/share`：停止分享。
- `NoteShare = { token, url, expiresAt?, hasPassword, visits, lastVisitAt?, createdAt }`。
- `Note`、`NoteSummary` 加 `shared`（布尔）。
- 公开接口（`security: []`）：
  - `GET /public/notes/{token}?t=<访问令牌>`：返回 `PublicNote = { title, body, updatedAt }`。有密码又没带对令牌时回 401，错误码 `note_password_required`。正文里的附件地址 `/api/v1/notes/attachments/<id>` 换成 `/api/v1/public/notes/<token>/files/<id>`（带上 `?t=`）。
  - `POST /public/notes/{token}/unlock`：请求 `{ password }`，返回 `{ access, expiresAt }`。
  - `GET /public/notes/{token}/files/{attachmentId}?t=`：这条笔记的附件，只能取正文里引用了的，`Content-Disposition: inline`，图片可以带 `thumb=1` 取缩略图。

### 后端（待做）

1. 表 `note_shares`：`note_id`（唯一，外键级联删除）、`token`（22 位随机，唯一）、`password_hash`（argon2id 或 bcrypt，可空）、`expires_at`、`visits`、`last_visit_at`、`created_at`。
2. 公开路径登记到 notes 模块的 `PublicPaths`（参照 `drive/module.go`）：`/public/notes/`。
3. 校验：token 不存在、过期、笔记已删或隐藏都回 404。密码错误按 IP 限流：每分钟 5 次，连错 10 次锁 15 分钟（参照云盘分享的提取码）。访问令牌是 HMAC 签名（token + 过期时间），不用存库。
4. `visits` 在 `GET /public/notes/{token}` 成功时加一，同一个浏览器 30 分钟内只算一次（看访问令牌或 IP + UA 的哈希）。
5. 笔记设为隐藏时删掉分享。删除笔记级联删除。
6. 写审计：创建、修改、停止分享。
7. 测试：无密码直接读；有密码先 401，解锁后能读；错密码限流；过期 404；隐藏后 404；附件只能取正文里引用的；图片地址被换成公开地址。

### 前端路由

`app/App.tsx`：路径是 `/n/<token>` 时渲染笔记分享页，和 `/s/<token>` 一样不经过登录检查（基础代码，记到接口变更记录）。

## 4. 左栏“+”快速新建（前端）

- 侧边栏一级菜单支持模块登记一个行内按钮：`registerNavAction("/notes", { icon, label, run })`，显示在折叠箭头左边，鼠标移到这一行时才出现（手机上一直显示）。
- 笔记登记“新建笔记”：点了新建一条空笔记并打开编辑。
- 侧边栏折叠时不显示。

## 5. 浮窗（前端）

- 编辑区右上角加一个按钮“在浮窗中打开”（图标 `PictureInPicture2`）。点了以后：
  - 这条笔记在右下角的浮窗里打开，笔记页的右边回到空白。
  - 浮窗可以拖动标题栏换位置、拖右下角改大小、最小化成一条标题、关闭。位置和大小记在 `localStorage`。
  - 浮窗里阅读和编辑都能用，和笔记页里一样自动保存。
  - 换页面时浮窗还在（挂在 `GlobalPanels` 里）。
  - 最多同时开 3 个浮窗，再开时关掉最早的。
  - 浮窗标题栏有“回到笔记页”按钮，点了在笔记页打开这条，并关掉浮窗。
- 手机上浮窗占满屏幕，和打开一个弹窗一样，有关闭按钮。
- 浮窗打开的笔记在列表里也能点开，两边是同一份数据，后保存的覆盖前面的（和现在两个标签页同时编辑一样）。

## 验收

- 长笔记编辑时能滚动。
- 阅读模式下双击一段文字进入编辑，光标在那段附近。
- 创建带密码的外链，无痕窗口打开先要密码，输对了只看到笔记内容和图片。
- 点左栏“笔记”旁边的“+”，直接打开一条新笔记。
- 浮窗里开一条笔记，切到服务器页，浮窗还在，能接着写，内容会保存。
