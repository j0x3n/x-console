# B264 首页代理流量模块

用户要求将本机 traffic-stats 接入 Console 今日首页，不做 iframe。

- 首页默认增加可移动、可隐藏代理流量卡片。显示账号今日、本月上下行、近期速率和活动隧道。
- GET /api/v1/dashboard/traffic 沿用 Console 会话认证，无公开接口。
- 固定读取 DataDir/naive-traffic.json。由本机独立采集器原子写入。限制 1 MiB，不接受用户路径、URL或凭据。不含账号密码。
- 显示超过35秒未更新为暂无近期采样。完整页保留独立登录。
- 不改流量限速、账号或现有记录。
- GitHub CI 编译测试，本机不编译。部署需确认，不直接推main。

验收：匿名接口拒绝，登录可读；5账号和今日/月计量正确；手机无横向溢出；旧首页布局保留；暂停采集显示过期；原统计页继续可用。
