# B37 提醒页汇总其他模块的提醒

需求见 `docs/tasks.md` 的“B37 提醒页汇总其他模块的提醒”。这里写做法。

## 前端（已完成）

2026-09-29 做完，分支 `claude/project-thread-o3tsew`。

- 提醒页“今天”和“即将到来”里，自己的提醒和其他模块的到期事项按时间混排（`features/reminders/external.ts` 的 `mergeEntries`）。“即将到来”照旧按日期分组。
- 其他模块的条目：前面是来源标签（订阅、证书、域名、Issue，不认识的来源用服务端给的 `sourceLabel`），标题点了跳到来源页面，下面是时间。过期没处理的有“已过期”标记，来源里已经处理的划掉。只读，没有完成、稍后提醒、编辑、删除。
- 标签页右边有开关“显示其他模块”，默认打开，记在这个浏览器里（`localStorage` 的 `xc.reminders.external`）。
- 页头和概要卡片的“今天”“即将到来”数字加上没处理的条目，“下一个提醒”也算上以后的条目。
- 接口没上线（404、501）时当作没有，页面和原来一样。

## 契约

`api/modules/reminders.yaml`：

- `GET /reminders/external?range=today|upcoming`：`{items: ExternalReminder[]}`，按时间排序。
- `ExternalReminder`：`id`（在来源里唯一，比如 `subscription:12`）、`source`（`subscription | certificate | domain | issue | other`）、`sourceLabel`（中文）、`title`、`at`、`link`、`done`。
- `modules/reminders/pending.go` 先回 501。

## 后端（待做，给开发者）

### 1. 接口定义 `contracts`

```go
// ExternalReminder 是别的模块的一条到期事项，提醒页只读显示。
type ExternalReminder struct {
    ID          string    // 在来源里唯一，比如 "subscription:12"
    Source      string    // subscription、certificate、domain、issue
    SourceLabel string    // 中文标签
    Title       string
    At          time.Time
    Link        string    // 面板里的路径
    Done        bool
}

// ReminderSource 由有到期事项的模块提供，可以有多个。
// Upcoming 返回 [from, until) 之间到期的，以及 from 之前到期还没处理的。
type ReminderSource interface {
    Upcoming(ctx context.Context, from, until time.Time) ([]ExternalReminder, error)
}
```

- 注册表键用前缀 `reminders.sources.`，每个模块一个：`reminders.sources.monitoring`、`reminders.sources.projects`。提醒模块用 `module.All[contracts.ReminderSource]` 取全部。
- 在 `docs/tasks.md` 的“接口变更记录”记一笔。

### 2. 提醒模块 `external.go`

- `today`：`from` 是服务器时区今天 0 点，`until` 是明天 0 点。加上今天以前到期、`Done` 为 false 的。
- `upcoming`：`from` 是明天 0 点，`until` 是 30 天后。
- 每个来源单独调用，超时 3 秒。一个来源出错只记日志，跳过它，其他的照常返回。
- 合并后按 `At` 排序。`source` 不在枚举里的写成 `other`。

### 3. 监控模块实现

- 订阅续费：用现有的 `Renewals.Upcoming` 的查询，`Source: "subscription"`，`Link: "/monitoring/subscriptions"`，标题“<名称> 续费”。
- 证书到期、域名到期：从现有的检查结果里取到期时间，`Source: "certificate"`、`"domain"`，标题“<域名> 证书到期”“<域名> 域名到期”，链接到监控页对应的标签。
- 已经续费（到期时间变到了以后）的自然不在范围里，不用特殊处理。`Done` 一律 false。

### 4. 项目模块实现

- 等 B36 的 `due_at` 做完。查 `due_at` 在范围里、状态不是 done 或 canceled、项目没归档的 Issue。今天以前到期的也返回（已过期）。
- `Source: "issue"`，`Title: "XC-12 <标题>"`，`Link: "/projects/XC/12"`，`Done: false`。
- 和 B36 到期提醒共用一个查询函数。

### 5. 测试

- 提醒模块：注册两个假的来源，一个返回数据，一个返回错误，接口只返回好的那个；`today` 包括昨天到期没处理的；`upcoming` 不包括 31 天后的。
- 监控：建一个 3 天后续费的订阅，`upcoming` 里能看到。
- 项目：建一个明天截止的 Issue，`upcoming` 里能看到；改成完成后不见了。
- 端到端：`web/scripts/e2e.mjs` 加一条：建 3 天后续费的订阅，提醒页“即将到来”里有，点了跳到订阅页；关掉开关后不显示。
