# B75 云盘分享页

用户 2026-10-01 提的：云盘分享出去的是一个页面，不是下载链接。浏览器能看的文件都直接预览，页面上有下载按钮。可以设置密码。要记录下载次数。

## 现状

B31 已经有分享页 `/s/<token>`：单个文件时图片、视频、音频、PDF 能预览；文件夹只能列出来，点文件直接下载。提取码只能是 4 到 8 位字母数字。分享管理里有访问次数和下载次数。

## 要改的

### 分享页

- 单个文件：浏览器能看的都在页面里预览。
  - 图片、视频、音频、PDF：照旧。
  - 文本、代码、日志、JSON、CSV、Markdown：用云盘查看器里的只读文本视图（等宽、行号、按扩展名高亮；Markdown 渲染成文档，右上角可以切换看源码）。超过 2 MB 只显示前 2 MB，底部写“文件太大，只显示了开头，完整内容请下载”。
  - 别的类型：大图标、文件名、大小，下面“这个文件不能在浏览器里预览”。
  - 页面顶部一行：文件名、大小、更新时间、过期时间、剩余下载次数；右边“下载”主按钮。
- 文件夹：
  - 列表里点文件夹进入，点文件在页面里打开预览（和单个文件一样的预览区，顶部有“返回列表”、“上一个”“下一个”），每行末尾一个下载图标按钮。
  - 顶部“全部下载”打包。
  - 图片多的文件夹可以切换成网格视图（缩略图）。
- 预览不算下载，不扣下载次数。点“下载”才算。
- 有密码时先显示密码框（原来叫“提取码”，界面上改叫“密码”）。
- 手机上预览区占满宽度。

### 分享弹窗和管理

- “提取码”改叫“密码”。可以自己填，4 到 32 位，任意字符；也可以点“随机生成”出一个 6 位的。
- 已有的链接列表每行显示：打开次数、下载次数（有上限时写“3 / 10”）、最后访问时间。
- 点一条链接可以展开最近 20 次下载记录：时间、IP 的前两段（比如 `203.0.*.*`）、浏览器（从 User-Agent 解析）、下载的文件名（文件夹分享时）。

## 契约（`api/modules/drive.yaml`，已改）

- `DriveShareInput.code` 的规则从 `^[A-Za-z0-9]{4,8}$` 放宽到 4 到 32 个字符（`minLength: 4, maxLength: 32`）。
- `GET /public/shares/{token}/content` 加参数 `preview`（布尔）：为 true 时 `Content-Disposition: inline`，不算下载次数，不受下载次数上限限制（次数用完时预览也不给，回 410）。可以带 `Range`。原来的 `inline` 参数保留，意思同 `preview`。
- 新接口 `GET /drive/shares/{shareId}/downloads`：最近 20 次下载，`DriveShareDownload = { at, ip, userAgent, itemName? }`，`ip` 已经打码。
- `PublicShareItem` 加 `thumbnail`（布尔，有缩略图时为 true），新接口 `GET /public/shares/{token}/thumbnail?item=&t=` 取缩略图，不算下载。

## 后端（待做）

1. 提取码改成任意 4 到 32 字符。存法照旧（加密存，主人能看到）。
2. `preview=true`（或旧的 `inline=1`）不计下载次数。下载次数只在不带 `preview` 的请求、而且是从头开始的请求（没有 `Range` 或 `Range` 从 0 开始）时加一，避免断点续传重复计数（现在的逻辑如果已经这样就不用改）。
3. 新表 `drive_share_downloads`：`share_id`、`at`、`ip`（存完整的，接口返回时打码）、`user_agent`、`item_id`。每个分享只保留最近 100 条。
4. 缩略图接口：复用云盘已有的缩略图，校验条目在分享范围内。
5. 测试：预览不扣次数；下载扣次数；续传不重复扣；下载记录打码；缩略图越权（分享范围外的条目）回 404。

## 验收

- 分享一个 Markdown 文件，打开链接看到渲染好的内容和“下载”按钮。
- 分享一个文件夹，点里面的图片在页面里看大图，能左右切换。
- 设一个 10 位的密码，打开链接要先输密码。
- 预览三次、下载一次，分享管理里下载次数是 1，下载记录里有一条。
