# B84 看板绑定 Git 仓库，同步 Issue

用户 2026-10-02 提的：

- 看板可以绑定 Git 仓库，同步仓库的 Issue；看板里新建的 Issue 仍然保存在看板里。

## 怎么做

- 一个看板绑一个仓库，一个仓库只能绑一个看板。仓库从“设置 → Git 与 GitHub”里的账号选（GitHub 和 Forgejo 都行），和 Agent 选仓库用同一个选择器。
- 入口：看板右上角“更多”菜单 →“绑定仓库”。绑定后看板标题旁边显示仓库名，点了去仓库页。
- 同步方向：
  - 仓库 → 看板：打开的 Issue 建成卡片，放进看板里状态是“待办”的列表（没有就第一个列表）。标题、正文、标签名、开关状态跟着仓库变。仓库里关掉的 Issue，卡片移到“完成”列表；重新打开的移回“待办”。
  - 看板 → 仓库：同步来的卡片改标题、正文，或者移到“完成”或“已取消”，回写到仓库（改 Issue、关闭 Issue）。移回别的列表时重新打开。
  - 看板里新建的卡片只存在看板里，不建到仓库。
  - 评论不同步。卡片详情里给一个“在仓库里打开”的链接（`Issue.externalUrl`）。
- 什么时候同步：绑定时同步一次；之后收到仓库回调（B47 的 Git 连接回调）时同步这一个 Issue；另外每 10 分钟全量对一次。手动“马上同步”按钮。
- 解除绑定：同步来的卡片留下，变成普通卡片。
- 同步来的卡片 `externalSource` 是 `github` 或 `forgejo`，`externalId` 是 `owner/name#编号`。同一个 Issue 不重复建卡片。

## 契约（已改）

`api/modules/projects.yaml`：

- `Board.repo`（`BoardRepo`）：绑定的仓库、同步开关、上次同步时间和错误、同步来的卡片数。
- `PUT /boards/{boardId}/repo`：绑定或改同步开关。仓库已经绑了别的看板时回 409。
- `DELETE /boards/{boardId}/repo`：解除绑定。
- `POST /boards/{boardId}/repo/sync`：马上同步一次。
- `Issue.externalUrl`：仓库里的地址。

## 前端（Claude）

- 看板“更多”菜单加“绑定仓库”，弹窗里选账号和仓库、勾“同步 Issue”；已绑定时显示上次同步时间、错误、“马上同步”和“解除绑定”。
- 看板标题旁边显示仓库名。同步来的卡片在卡片上显示一个小的仓库图标，详情里有“在仓库里打开”。
- 接口回 404 或 501 时弹窗里显示“还没上线”。

## 验收

- 绑定一个有 3 个打开 Issue 的仓库，看板里多出 3 张卡片。
- 在仓库里关掉一个，几秒内（有回调）或 10 分钟内卡片移到“完成”。
- 在看板里把同步来的卡片移到“完成”，仓库里的 Issue 被关掉。
- 看板里新建的卡片不出现在仓库里。
