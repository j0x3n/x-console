# B96 习惯推荐模板和 AI 的提醒参数

用户 2026-10-02 提的：

- 习惯页加默认推荐模板，比如喝水、休息眼睛、定时起立，可以预填后修改保存，不重复创建；补齐 AI 创建和更新习惯时的提醒参数。

## 怎么做

- **推荐模板（前端）**：习惯页（今天视图）上方加一排“推荐”：喝水、护眼、起来活动、吃药（B83 的模板）。
  - 还没建过的模板：点了打开新建弹窗，模板的值已经填好，改完保存。
  - 已经建过的（`Habit.template` 相同、没归档）：显示“已添加”，点了打开那个习惯的编辑弹窗，不再新建。
  - 全部建过时这一排不显示。
- **AI 的提醒参数（后端，Codex）**：AI 工具和 MCP 的“创建习惯”“更新习惯”要能传全部提醒参数：`remindMode`、`remindIntervalMinutes`、`remindWindow`、`remindTimes`、`remindWhen`、`activeHostIds`、`remindOnHost`、`template`、`dailyTarget`、`unit`、`icon`。参数说明写清楚每个值的意思和格式（比如 `remindWindow` 是 `09:00-21:00`）。按模板建时，没传的参数用模板的默认值；同一个模板已经有习惯时，不新建，返回已有的那个并说明。

## 验收

- 习惯页点“喝水”，弹窗里已经填好；保存后“喝水”变成“已添加”，再点打开的是编辑。
- 对 AI 说“每 45 分钟提醒我起来活动，只在用电脑时”，建出来的习惯提醒参数正确。
