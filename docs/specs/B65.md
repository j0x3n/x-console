## 为什么放在集成里

- 路由器内存小，CPU 架构杂（MIPS、ARM），装代理不划算，现在的代理也只编译了 amd64 和 arm64。
- 路由器上关心的是它特有的东西：在线设备、WAN 口 IP 和流量、各接口状态、重启网络接口。这些用 OpenWrt 自带的 ubus 接口就能拿到，路由器上不用装东西。

## 路由器上要做的准备（写进设置页的说明）

1. 装 `uhttpd-mod-ubus`（LuCI 一般已经带了），让 `http://<路由器>/ubus` 能访问。
2. 新建一个只读用户给面板用，或者直接用 root（不推荐）。用 rpcd 的 ACL 限制这个用户只能调下面列的几个方法，重启网络接口要单独允许 `network.interface.*` 的 `up`、`down`。
3. 面板服务器要能访问到路由器。面板在国外服务器上，访问不到家里的路由器时，有两个办法：
   - 让家里的电脑（已经装了代理）转发：B65 第二步做，代理加一个“HTTP 转发到局域网地址”的能力。
   - 或者用户自己做内网穿透、WireGuard。
   第一步只做面板直连，设置页说清楚要能访问到。

## 用到的 ubus 方法

请求格式：`POST http://<路由器>/ubus`，JSON-RPC 2.0：`{"jsonrpc":"2.0","id":1,"method":"call","params":[<session>,"<对象>","<方法>",{参数}]}`。先用 `session login`（`params: ["00000000000000000000000000000000","session","login",{"username":"..","password":".."}]`）拿到 `ubus_rpc_session`，有效期默认 300 秒，过期重新登录。

| 用途 | 对象和方法 | 用到的字段 |
| --- | --- | --- |
| 系统信息 | `system board`、`system info` | 型号、固件版本、运行时间、内存、负载 |
| 接口状态 | `network.interface dump` | 每个接口的 up、IPv4/IPv6 地址、运行时间。WAN 口取 `interface` 为 wan 的 |
| 流量 | `network.device status` | 每个网卡的收发字节数。面板每分钟取一次，自己算速率 |
| 在线设备 | `luci-rpc getHostHints`，以及 `luci-rpc getDHCPLeases` | MAC、IP、主机名、租约到期时间 |
| 无线客户端（可选） | `hostapd.<接口> get_clients` | 信号强度、速率 |
| 重启接口 | `network.interface.<名字> down` 再 `up` | 要单独授权 |
| 重启路由器 | `system reboot` | 高危，要提升权限 |

具体字段以路由器上实际返回为准，先用 `ubus call` 在路由器上看一遍。

## 后端（待做）

- 新模块 `backend/internal/server/modules/router/`，契约 `api/modules/router.yaml`，注册进 `app/modules.go`。
- 配置：`GET/PUT /router/config`：地址、用户名、密码（加密存，不返回）。保存时先登录一次验证。
- `GET /router/status`：系统信息、各接口、WAN 口 IP 和运行时间、当前上下行速率。
- `GET /router/clients`：在线设备列表（合并 DHCP 租约和 host hints，按 IP 排序）。
- `GET /router/traffic?range=24h|7d`：WAN 口流量历史。后台每分钟采一次存表（迁移建表 `router_traffic`：时间、收、发字节数），只留 30 天。
- `POST /router/interfaces/{name}/restart`：要提升权限。`POST /router/reboot`：要提升权限并二次确认。审计都要记。
- 告警：WAN 口掉线超过 2 分钟、恢复时，各推一次通知。
- 测试：用 `httptest` 假一个 ubus 服务（登录、session 过期后重新登录、各方法的返回）。
