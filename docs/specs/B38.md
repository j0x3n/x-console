# B38 浏览器全屏与安全区适配

## 要什么

Safari 标签页和添加到主屏幕后的应用都使用设备可用区域。兼容 Chrome、Edge、Firefox 和其他使用 WebKit 或 Chromium 的浏览器。页面背景延伸到系统边缘，文字和操作避开刘海、圆角和底部手势区域。

浏览器工具栏的透明度和自动收起由浏览器决定。普通网页不能强制隐藏浏览器工具栏。主屏幕应用使用独立窗口模式。

## 怎么做

- viewport 开启 viewport-fit=cover，支持浏览器调整软键盘后的内容高度，保留用户缩放。
- 统一动态视口高度，旧浏览器使用 innerHeight 回退。浮层使用 VisualViewport 的实际可见高度和偏移，避开软键盘。
- 手机普通页面使用文档滚动。桌面保留内部滚动。笔记编辑器保留独立滚动，并扣除安全区高度。
- 外壳、登录、公开分享页、侧边栏、弹窗、命令面板、AI 浮窗和云盘查看器统一使用安全区。支持横屏的左右安全区。
- 浏览器 theme-color 使用当前界面背景，响应主题、主题色和手机尺寸变化。首屏主题色也按已保存的偏好设置。
- 保留 manifest 的 standalone 模式。识别独立窗口和 fullscreen 显示模式。安装帮助说明从主屏幕图标启动。
- 公共适配集中在 styles/browser.css 和浏览器视口 Hook。共享样式改动向后兼容，记录到任务看板的接口变更记录。

## 验收

- Chromium、Firefox 和 WebKit 打开登录、今日、笔记、云盘、设置及公开分享页，没有报错和整页横向溢出。
- 1360px、390px 和手机横屏检查。手机普通页面能滚动，桌面内部滚动正常。侧边栏导航、个人菜单、主题切换、命令面板和弹窗可用。
- 调整窗口高度后，编辑器和浮层跟随可见区域。模拟上下左右安全区后，操作按钮保持可见。
- 添加到主屏幕后使用独立窗口。实际 iOS 工具栏透明效果和软键盘需要真机复核。
- 前端全部检查、后端项目要求的检查和全页面截图通过。

## 本地复查

先启动隔离数据的服务端和生产前端，跑 `npm run shots -- --base <地址>` 初始化测试账号。安装浏览器引擎：`npx playwright-core install chromium firefox webkit`。设置 `XC_BROWSER_BASE` 后运行 `npm run browser:check`。已有账号通过 `XC_SHOTS_USER`、`XC_SHOTS_PASSWORD` 指定。测试会创建笔记和上传文本文件，请使用隔离数据。

脚本检查全部共用外壳的页面、公开分享错误页、手机导航、主题切换、笔记保存、文件预览、AI 浮窗和模拟软键盘。安全区与主屏幕模式使用模拟值。iOS 实际浏览器栏、添加到主屏幕和键盘仍需真机复核。
