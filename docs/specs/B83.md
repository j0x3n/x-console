# B83 健康提醒和作息

## 后端实现说明（2026-10-02）

后端由 Codex 完成。作息、提醒条件、主机选择、系统通知和下一次提醒接口均已接入。前端仍由 Claude 接入。

- 旧习惯默认使用 window。作息默认周一至周五、12:00 起床、03:30 睡觉、空闲 5 分钟。首次初始化使用服务端时区。前端保存时传浏览器 IANA 时区。习惯进度、统计、训练记录和提醒统一使用保存的作息时区。
- active 只接受真实可见的主机。任意选中主机在用时计时。unknown 在线时按规格回退。锁屏、关屏或离线时停止提醒。错过提醒后重新计时。GET 的下一次提醒只读，不推进连续使用计时。
- 每分钟调度，并在代理状态上报时重算。固定时间只在对应分钟发送。推迟只影响本次，打卡和成功发送后清除推迟。旧通知的 skip 动作继续兼容。
- presence 样本保存在内存，超过 90 秒没有上报时按 unknown 处理。旧代理在线时也是 unknown。相同状态的心跳保持 since。隐藏模块的电脑不出现在习惯状态、选择和通知里。
- Windows 会话 0 返回 unknown，系统通知能力按当前会话提供。用户会话代理每 2 秒采样，30 秒心跳，并在输入、锁屏或状态变化时上报。Windows 不主动改变屏幕电源状态，拿不到 displayOff 时省略该字段。
- 系统通知使用固定程序和结构化参数。Windows 文本经 XML 转义后通过环境变量传递。macOS 和 Linux 的通知文本作为参数传递。未知能力和离线代理会跳过。
- 四种模板只提供默认值，显式输入优先。空主机选择的护眼和活动模板返回校验错误。
- 已通过 Linux 相关 race、全量 go vet、Windows 代理构建和 vet。真实浏览器检查了旧习惯创建、打卡和撤销、作息与模板 API、Windows 在线离线状态，以及习惯、统计、健身、今日和电脑共享页面。桌面 1360px 与手机 390px 均检查。macOS/Linux 桌面会话和系统通知实际弹窗仍需对应设备验收。

前端需接入作息弹窗、健康模板、电脑状态、下一次提醒和系统通知选择。订阅 habit.presence、host.presence、habit.schedule 更新对应数据。现有页面的兼容检查已通过。

用户 2026-10-01 提的：

- 想要习惯那样的提醒，比如喝水、休息眼睛、站起来。
- 能不能根据工作电脑的状态（可以选哪台电脑）来提醒：亮屏时才提醒，或者更合适的判断方式。因为电脑一直不关，AI 可能一直在上面干活，不能只看开没开机。
- 能设置自己的工作日和作息。比如一般凌晨三四点睡，12 点起床。

## 判断“人在用电脑”

只看亮屏不够：电脑不关、AI 在跑任务时屏幕可能也亮着。改成看“人有没有在操作”：

- 代理报告这台电脑的**空闲时间**：距离上一次键盘或鼠标操作过了多久。AI 在后台跑命令不会动键盘鼠标，所以不算。
  - Windows：`GetLastInputInfo`。代理以服务方式运行在会话 0 时拿不到用户会话的输入时间，要用 B30 已有的“用户登录后运行”的任务计划方式（代理跑在用户会话里）。拿不到时报 `unknown`。
  - macOS：`ioreg -c IOHIDSystem` 的 `HIDIdleTime`。
  - Linux 桌面：有 X11 时用 `XScreenSaverQueryInfo`（`xprintidle`），Wayland 下用 `org.freedesktop.ScreenSaver.GetSessionIdleTime`（D-Bus），都拿不到时报 `unknown`。
- 同时报**锁屏**和**显示器是否关闭**（能拿到就报，拿不到不报）。
- “在用”的定义：在线、没锁屏、空闲时间小于 N 分钟（默认 5 分钟，可以改）。
- 拿不到空闲时间（`unknown`）的电脑，退回到“在线就算在用”，并在界面上写清楚。

## 作息

设置在“习惯”页右上角“作息”按钮里（也在 设置 → 通知 里有入口）：

- 工作日：周一到周日七个勾选，默认周一到周五。
- 起床时间、睡觉时间：比如 12:00 起床、03:30 睡。睡觉时间早于起床时间时表示跨到第二天（03:30 是第二天凌晨）。
- 工作时间（可选）：比如 14:00 到 23:00，只在工作日。
- 休息日也按起床和睡觉时间算“醒着”。
- 时区用浏览器当前时区，保存时一起存。

## 提醒怎么用这些

习惯的提醒（`remindMode: interval`）加一个“什么时候提醒”：

| 选项 | 意思 |
| --- | --- |
| 时间窗内（原来的） | 在 `remindWindow` 里按间隔提醒 |
| 醒着的时候 | 起床到睡觉之间按间隔提醒，跨午夜也行（解决“时间窗不能跨午夜”的旧问题） |
| 工作时间 | 工作日的工作时间里 |
| 在用电脑时 | 选一台或几台电脑，其中任意一台“在用”时才提醒；间隔按“连续在用”的时间算：连续用了 45 分钟提醒“起来活动一下”，离开超过 5 分钟就重新计时 |

“在用电脑时”可以和“醒着的时候”或“工作时间”同时勾（两个条件都满足才提醒）。

- 提醒到了但人不在电脑前：不补发，等下次。
- 提醒发到哪里：照“设置 → 通知”的规则。另外加一个选项“发到这台电脑”：通过代理在电脑上弹系统通知（代理已有打开程序的能力，加一个 `notify.show` 方法：Windows 用 toast，macOS 用 `osascript display notification`，Linux 用 `notify-send`）。
- 提醒里有“完成”和“推迟 10 分钟”两个按钮（浏览器推送已支持按钮）。点“完成”算打卡一次。

### 现成的模板

新建习惯弹窗顶部一排模板，点了自动填好：

- 喝水：每 60 分钟，醒着的时候，目标每天 8 杯。
- 护眼：每 20 分钟（20-20-20 规则：看 6 米外 20 秒），在用电脑时。
- 起来活动：连续用电脑 45 分钟，在用电脑时。
- 吃药：固定时间 09:00、21:00。

## 契约（已改）

- `habits.yaml`：
  - 新接口 `GET /habits/schedule`、`PUT /habits/schedule`：`Schedule = { workDays: int[] (1=周一…7=周日), wakeTime, sleepTime, workStart?, workEnd?, timezone, idleMinutes }`。
  - `Habit`、`HabitInput`、`HabitPatch` 加 `remindWhen: string[]`（`window`、`awake`、`work`、`active`，默认 `[window]`）、`activeHostIds: string[]`、`remindOnHost: boolean`、`template?: string`。
  - `Habit` 加 `nextRemindAt?`（服务端算出的下一次提醒时间，“在用电脑时”的给预计值）。
  - 新接口 `GET /habits/presence`：`HostPresence[] = { hostId, name, state: active|idle|locked|offline|unknown, idleSeconds?, since }`。状态变化时发事件 `habit.presence`。
- `hosts.yaml`：`HostDetail` 加 `presence?: HostPresence`。
