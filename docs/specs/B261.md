# B261 QQ 邮箱标题与正文恢复

用户 2026-10-26 反馈 QQ 邮箱邮件列表全是无主题，有些正文也为空，并要求重新获取受影响邮件。

- 检查线上返回和实际 IMAP 解析路径。修复后继续兼容 QQ 的 ENVELOPE 问题及阿里邮箱的邮件头请求限制。
- 邮件头缺失、空结果或不完整数据不能静默覆盖已有标题和发件人。
- 正文获取和解析失败不能永久缓存为空正文。正确识别带 Content-ID 的正文部分。
- 通过现有同步入口补回异常邮件的标题、发件人、摘要及正文。保留本地邮件 ID、未读、星标、邮箱 UID 与有效附件。
- 恢复旧邮件时不重复发送新邮件通知。只修复异常记录，不重新创建邮箱、不删除原始邮件。
- 优先复用现有接口。没有确定数据依据时，不声称已恢复线上邮件。
- 补真实协议响应和 MIME 回归测试。代码完成后按项目规则处理上线，线上恢复以实际数据为准。
