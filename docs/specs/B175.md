# B175 新站标、赛博主题、补全主题色

2026-10-13 用户提的。站标和配色是用户在对话里一轮轮挑出来的。

## 要什么

1. **新站标**：LED 像素风的 “X_”。左边是粗像素的 X，右边是两格高的光标，每一格是带缝的圆角小方块，放在浅色圆角方块底上。
   - 页面里的站标（`BrandMark`）跟着主题色：底是主题色的浅色，X 用主题色，光标用辅色。没有辅色的主题，光标和 X 同色。
   - 浏览器图标、安装图标固定用赛博配色（C2）：浅色是淡紫底、粉色 X、紫色光标；深色是深紫底、亮粉 X、亮紫光标。`favicon.svg` 跟着系统深浅色换。
2. **赛博主题色** `cyber`（S1 霓虹粉紫）：和现有的六种主题色并列，在头像菜单里选。和别的主题色不同，它连底色、边框、文字颜色一起换成偏紫的色调。
   - 主色粉色，辅色紫色。深色模式下主要按钮是亮粉底配深色字，保证对比度。
3. **辅色变量**：新增 `--xc-accent-2`、`--xc-accent-2-soft`、`--xc-accent-2-text`。别的主题默认等于主色，所以现有界面不变。
4. **补全主题色**：查出写死颜色、不跟主题走的元素，改成用变量。

## 怎么做

- `api/modules/core.yaml` 的 `Preferences.accent` 枚举加 `cyber`，后端 `core/preferences.go` 的 `accents` 加 `cyber`，重新生成代码。
- 前端：`types/domain.ts`、`stores/preferences-store.ts`、`Sidebar.tsx` 的名字表、`ui.css` 的色块（粉紫对半）、`i18n.ts` 加 “Cyber → 赛博”。
- `tokens.css` 加赛博两段和辅色变量、站标变量。`index.html` 的首屏脚本不用改（它直接写 `data-accent`）。
- `components/ui/BrandMark.tsx` 改成像素站标。`public/favicon.svg` 和 `public/icons/` 下四张图换掉，版本号从 `connect-1` 改成 `led-1`（`index.html`、`manifest.webmanifest`、`sw.js`）。
- 补全主题色：用赛博主题截图，逐页找没跟上的地方，把写死的颜色换成变量。

## 验收

- 头像菜单里能选赛博，刷新后保持；服务端保存和读出 `cyber`。
- 赛博主题下，主要页面截图（1360 和 390）的底色、卡片、边框、文字都是偏紫的色调，没有残留的纯灰块，按钮、选中项、进度条是粉色。
- 其他六种主题看起来和以前一样。
- 浏览器标签、侧栏、登录页、分享页显示新站标。
- 后端偏好测试覆盖 `cyber`。
