# B86 Agent 开发卡片、执行日志、删除和左栏

用户 2026-10-02 提的：

- 卡片可以分配给 agent 开发；没绑定仓库时提示先绑定，绑定后 agent 同步仓库、开发并提 PR。
- agent 执行任务的日志要有地方查看，比如 agent 详情页和对应卡片里。
- agent 现在没有删除入口，要加上删除操作，带二次确认。
- 侧边栏 agent 一级菜单的折叠按钮左侧加一个加号按钮，快速创建 agent。
- 有 agent 在工作时，一级菜单 Agent 图标变成跳动或脉冲动画，二级菜单里工作中的 agent 名称右侧显示加载圈；没有时恢复静态图标。

## 分配给 Agent 开发

- 卡片的“分配给 Agent”弹窗（B47 已有）：
  - CLI 类型（Claude Code、Codex）：默认用卡片所在看板绑定的仓库（B84）。看板没绑定时，弹窗里提示“这个看板还没绑定仓库”，给“去绑定”按钮（打开 B84 的绑定弹窗）。也可以照旧手动选一个已登记的仓库。
  - 勾选“做完自动提 PR”（默认勾上）。
- 后端：
  - `repoId` 不传时用看板绑定的仓库。这个仓库在要跑的机器上还没登记时，按 Git 连接登记并 clone（B47 已有的 `CreateRepo` 按连接登记的流程），登记过就先 `git fetch`。看板也没绑定时回 409，`code` 是 `board_repo_missing`。
  - `openPr`（默认 true）：任务做完（开了自动构建时要构建通过）后自动提交、推送、提 PR，PR 标题用卡片标题，正文写卡片编号和改了什么。PR 地址作为卡片的链接和评论写回卡片，状态变成 `pr_opened`。
  - Agent 不在“允许的仓库”里时，看板绑定的仓库也不能用，回 403 并写清楚原因。

## 执行日志

- 新接口 `GET /ai-agents/runs`（按 Agent 或卡片筛选）、`GET /ai-agents/runs/{runId}/events`、`POST /ai-agents/runs/{runId}/cancel`。
- 两种类型都记：
  - CLI 类型：一次执行对应一个编码任务，带 `taskId`，日志直接用编码任务的输出（已有）。
  - 内置类型：每次调工具、每段输出、出错、等你决定都记一条事件（`AiAgentRunEvent`），执行中发 `ai_agent.run_event` 事件，前端实时追加。
- 保留最近 200 次执行，日志每次最多 5000 条。
- 前端：
  - Agent 详情页：任务列表下面加“执行日志”卡片，选一次执行看日志（默认正在跑的那次，没有就最近一次）。
  - 卡片详情：加“Agent 执行”一节，列出这张卡片的执行记录，点开看日志。执行中可以“中断”。
  - 接口回 404 或 501 时：CLI 类型照样用编码任务的数据显示，内置类型显示“还没上线”。

## 删除、左栏

只改前端：

- 删除：Agent 列表的“更多”菜单已经有删除；详情页右上角加“更多”菜单，里面有删除。都先二次确认，删完回到 Agent 列表。正在跑任务时确认框里写明，后端回 409。
- 左栏“Agent”一行：折叠箭头左边加“+”，点了打开新建 Agent 弹窗。
- 有 Agent 在工作时，左栏“Agent”图标跳动；二级菜单里工作中的 Agent 名称右边显示转圈。没有时恢复静态图标。
