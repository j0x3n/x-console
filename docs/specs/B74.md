# B74 编辑器增强

用户 2026-10-01 提的：笔记和便签都能加列表、勾选框、多媒体、链接、引用、代码块（右侧可以折叠、一键复制，按钮在屏幕内就一直显示）、可以隐藏、设置背景色，还有觉得能加的也加上。

原来已有：标题、粗体、斜体、无序和有序列表、勾选清单、引用、代码块、链接、分隔线、图片、附件。下面是新加的。全部写在公共的 Markdown 解析和渲染里（`components/markdown/`），所有用 Markdown 的地方都能显示。

## 渲染

| 功能 | 写法 | 显示 |
| --- | --- | --- |
| 代码块 | 照旧 ```` ```lang ```` | 顶部一条：语言名、行数、“折叠”、“复制”。超过 20 行默认折叠成 12 行，底部“展开全部”。顶部这条在代码块露在屏幕里时一直贴在可见区域的顶部（`position: sticky`），长代码往下滚也能点复制 |
| 视频、音频 | `![名字](地址)`，地址后缀是 mp4、webm、mov、m4v 或 mp3、m4a、ogg、wav、flac | 显示成播放器，不是图片 |
| 链接卡片 | 一段里只有一个裸网址 | 显示成一行卡片：网站图标、域名、网址。不去抓网页标题（不做服务端抓取） |
| 隐藏块 | `:::hidden 标题` 换行内容换行 `:::` | 折叠起来，只显示一条“已隐藏：标题，点击显示”，点开显示内容 |
| 提示块（背景色） | `:::note`、`:::tip`、`:::warn`、`:::danger`，可以带标题 | 带浅色底色和左边色条的块，图标随类型 |
| 高亮 | `==文字==` | 黄色底的标记 |
| 表格 | 标准的 GFM 表格 | 带边框的表格，窄屏在自己的容器里横向滚动 |
| 行内代码、删除线 | 原来就支持 | 工具条加按钮 |

## 编辑工具条

现在一行十几个按钮。改成两段：常用的直接放，其余的放进“更多”下拉（`+` 图标，标题“插入”）。

- 常用：标题、粗体、斜体、无序列表、勾选清单、引用、代码块、链接、图片。
- “插入”里：有序列表、删除线、高亮、行内代码、表格（插入 3 列 2 行）、视频或音频（选文件上传）、隐藏块、提示块（四种）、分隔线、当前日期时间、附件。
- 手机上工具条一行横向滚动，“插入”放在最前面。

## 背景色

- 笔记和便签都有背景色。可选：默认、红、橙、黄、绿、青、蓝、紫、粉、棕、灰（和 Keep 一样 11 个）。深色主题下用暗一些的同色。颜色只存名字（`red`、`orange` 等），由前端换成具体颜色，所以主题能换。
- 笔记：编辑区右上角“更多”菜单里“背景色”，选了以后编辑区和阅读区的底色变成这个颜色，列表里这一行左边有一条这个颜色的竖线。
- 便签：卡片和弹窗的底色（B73）。

## 契约

只有一个字段：`Note.color`（B73 里一起加的）。其余都是前端。

## 验收

- 一段长代码：默认折叠，展开后往下滚，顶部的“复制”一直看得见，点了复制整段。
- 上传一个 mp4，正文里显示成播放器。
- 写一个 `:::hidden`，阅读时折叠，点开能看。
- 选一个背景色，编辑和阅读都是这个颜色，深色主题也看得清字。
- 表格在手机上不撑破页面。
