# M6 笔记（原名备忘）

状态：已完成。

## 数据

迁移文件：`store/migrations/20260927174400_m6_notes.sql`。

| 表 | 列 |
| --- | --- |
| `notes` | id、title、body（Markdown）、pinned、archived_at、created_at、updated_at |
| `note_tags` | note_id、tag |
| `notes_fts` | FTS5 虚拟表，列 title、body，content=notes，用触发器同步 |

中文分词：FTS5 默认分词器不切中文。用 `trigram` 分词器（`tokenize='trigram'`），三个字以上能匹配。一两个字的查询退回 `LIKE`。

sqlc 能解析建表和触发器，但解析不了 `MATCH`，所以搜索写在 `modules/notes/search.go` 里，用 `database/sql`。

实现说明：

- 标签会去掉前后空格和开头的 `#`，去重，最长 40 个字。
- 写数据的事务用 `BEGIN IMMEDIATE`。多个窗口同时自动保存时会排队，不会报 `SQLITE_BUSY`。

## 接口

契约：`api/modules/notes.yaml`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/notes?q=&tag=&pinned=&archived=&cursor=&limit=` | 返回 NoteSummary（不带正文，带 excerpt）。没有 q 时置顶在前、按更新时间倒序；有 q 时按相关度排序并返回 snippet |
| POST | `/notes` | |
| GET/PATCH/DELETE | `/notes/{noteId}` | PATCH 可改 title、body、pinned、archived、tags（整体替换） |
| GET | `/notes/tags` | 未归档笔记的标签及数量，数量多的在前 |
| POST | `/notes/{noteId}/to-issue` | `{projectId}`，返回 `{issueKey, issueUrl, note}` |
| POST | `/notes/{noteId}/to-reminder` | `{at, rrule?}`，返回 `{reminderId}`。提醒模块没启用时 501 `feature_unavailable` |

搜索规则：

- q 按空白拆成几个词，每个词都要匹配。
- 每个词都在三个字以上时走 FTS5（`bm25`，标题权重 5 倍）；否则全部用 LIKE（通配符会转义），标题命中的排前面。
- snippet 里命中的部分用 U+E000 和 U+E001 包住，前端换成 `<mark>`。
- 默认不搜已归档的笔记，`archived=true` 只搜已归档的。
- 分页游标是偏移量。

转 Issue：用 `contracts.Issues` 建 Issue（标题取笔记标题，没有就取正文第一行；描述是正文），再用 `AttachLink` 挂上 `kind: note, url: /notes/<id>`，最后在笔记末尾追加一行 `关联 Issue：[XC-12 标题](/projects/XC/12)`。

转提醒：`contracts.Reminders.Create`，标题同上，正文取前 200 字纯文本，`Link` 是 `/notes/<id>`。

## 前端 `features/notes`

2026-09-27 B11 重做了列表和编辑器，加了图片和附件，见 [B11.md](B11.md)。下面是最初的做法。

- `/notes/:noteId?`：左边列表（置顶在前、标签筛选、已归档切换、搜索框），右边编辑器。搜索、标签都放在地址栏参数里。手机上两栏切换，编辑器左上角有返回按钮。
- 编辑自动保存：停止输入 800 毫秒后保存，显示“保存中… / 已保存 / 保存失败，稍后会重试”。保存中又有输入时，存完再存一次最新的。切换笔记、页面隐藏时立刻保存，页面关闭时用 keepalive 请求发出最后的内容。`⌘/Ctrl + S` 立刻保存。
- 另一个窗口改了同一条笔记：本地没有未保存的改动时采用新内容。
- Markdown 预览切换（复用 `features/projects/Markdown.tsx`）。
- 快速记录：页头有“快速记录”按钮，写完存成新笔记；命令面板的“快速记录”打开同一个框。
- 笔记菜单：转 Issue、转提醒、置顶、归档、删除。
- 命令面板：“新建笔记”“快速记录”“搜索笔记”。

和原计划不同：命令面板里输入 `> 内容` 直接存笔记没有做。现在的命令面板只按标题过滤固定命令，不能把输入的文字交给命令，要改 `components/command/CommandPalette.tsx`（基础代码）。建议 J 在“命令面板增强”里加上：命令可以声明前缀（比如 `>`），面板把前缀后的文字传给 `run`。

## 验收

- 中文三字词能搜到，两字词也能搜到（走 LIKE）。
- 自动保存不丢字：快速连续输入后刷新，内容完整。
- 转 Issue 后，笔记里出现 Issue 链接，Issue 的关联里也能看到这条笔记。
