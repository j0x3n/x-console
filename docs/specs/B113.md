# B113 通知静音规则：按邮箱、按设备控制外部通知

用户 2026-10-06 提的：手机上已经装了 Gmail，面板里 Gmail 邮箱的新邮件不需要再在手机上通知，其他邮箱照常通知。手机用 Web Push 收面板通知。

用户确认的方案：

- 每个邮箱可以单独选“发到哪里”，在“邮件 → 邮箱设置”里。
- 同时做通用的静音规则列表，放在“设置 → 通知”里，别的通知类型也能用。
- 面板里的通知铃一直发，不能取消，保证不漏邮件。
- 邮箱已有的“推送”开关保留，意思不变：关了就是所有外部渠道都不发。
- 新增的设备或渠道，对已有规则默认接收。

## 规则的样子

一条静音规则 = 通知类型 + 范围 + 目标。

- 通知类型：通配写法，和通知路由一样，比如 `mail.new`、`mail.*`、`github.*`、`*`。
- 范围：可以空。邮件的范围是 `mail:<邮箱编号>`。空表示这个类型的全部通知。
- 目标：
  - 渠道名：`webpush`、`telegram`、`bark`、`serverchan`。整个渠道不发。
  - 一台 Web Push 设备：`webpush:<订阅编号>`。只有这台设备不发。
- 一条通知发送给某个目标前，只要有一条规则的类型、范围、目标都对得上，就跳过这个目标。
- 通知铃（站内通知）不受规则影响。
- 安静时段、通知路由照旧先生效，静音规则在它们之后再过滤。

## 接口（reminders 模块，通知相关的接口都在这里）

`api/modules/reminders.yaml` 加：

- `GET /notify/mutes?scope=`：全部规则，可以只看某个范围。返回 `{items: [{id, kindPattern, scope, target, createdAt}]}`。
- `POST /notify/mutes`：`{kindPattern, scope?, target}`，201。同样的规则已经有回 409。`target` 不是上面几种、渠道名不存在，或 `webpush:<编号>` 的设备不存在，回 400。
- `DELETE /notify/mutes/{id}`：204，不存在回 404。
- `PUT /notify/mutes/scope`：`{kindPattern, scope, targets: []}`，把这个类型加范围下被静音的目标整个换成 `targets`。给邮箱编辑弹窗用，一次保存一个邮箱的全部勾选。
- 不需要提升权限。改动记审计（`notify_mute.create`、`notify_mute.delete`、`notify_mute.replace`）。

## 后端

- 迁移：新表 `notification_mutes`（`id`、`kind_pattern`、`scope`、`target`、`created_at`，`kind_pattern + scope + target` 唯一）。
- `notify.Notification` 加可选字段 `Scope string`。邮件的新邮件通知填 `mail:<邮箱编号>`。
- `reminders` 的路由 `Route` 在选出渠道后，去掉整个被静音的渠道。
- Web Push 渠道发送时，跳过被静音的订阅，也不记成失败。全部订阅都被静音时不算错误。
- 删除一台 Web Push 设备时，一起删掉指向它的规则。
- 邮箱删除时，邮件模块发总线事件 `notify.scope_removed`，载荷 `{scope: "mail:<编号>"}`，`reminders` 收到后删掉这个范围的规则。不跨模块直接读写表。

## 前端

- 邮箱编辑弹窗加一块“通知发到”：
  - 第一行“面板通知铃”，勾上，灰色不能改，写“一直发”。
  - 下面是每个 Web Push 设备（设备名取自 B34 的设备列表，加上次成功时间）、Telegram、Bark、Server酱。没配置的渠道不列。
  - 勾选就是接收，取消勾选就是静音。保存邮箱时一起保存。
  - Gmail 邮箱在这一块上面写一句提示：“手机上装了 Gmail 的话，取消手机那一项就行。”
  - “推送”开关关着时，这一块灰掉，写“这个邮箱的外部通知已整体关闭”。
- 邮箱设置列表里，有静音规则的邮箱显示标签“部分目标已静音”。
- “设置 → 通知”加一张“静音规则”卡片：
  - 列出全部规则：通知类型（常见的显示中文名，比如“邮件”）、范围（邮箱显示成邮箱名）、目标（设备显示设备名）、删除按钮。
  - “添加规则”弹窗：通知类型（全部、邮件、仓库、提醒、监控、Agent 和自定义写法）、范围（类型是邮件时可以选某个邮箱或全部）、目标。
  - 范围里的邮箱已被删除时，标成“已删除的邮箱”，可以删这条规则。

## 验收标准

- Gmail 邮箱静音了手机那台设备：收到这个邮箱的新邮件时，手机收不到推送，电脑浏览器仍收到，通知铃有。
- 另一个邮箱的新邮件，手机照常收到。
- 整个渠道静音（比如 Bark）后，这个范围的通知不发 Bark。
- 邮箱的“推送”开关关着，所有外部渠道都不发（原有行为不变）。
- 删除邮箱后，它的静音规则消失。删除设备后，指向它的规则消失。
- 新订阅的设备对已有邮箱默认接收。
- 重复添加同一条规则回 409，目标不存在回 400。
