# B177 CI 时长卡片只算收费的分钟数

2026-10-13 用户提的。仓库 `j0x3n/x-console` 改成公开以后，GitHub 不再对它的 Actions 收费，但 B109 的卡片把所有仓库的分钟数都加在一起，显示快用完了，其实没占额度。

## 要什么

- “本月 CI 时长”的已用分钟数和按系统的分钟数，只算私有仓库（收费的）。公开仓库的分钟数不算进去，也不计入 80%、100% 的通知。
- 公开仓库用掉的分钟数单独返回，卡片上写一行“公开仓库 N 分钟不收费”，为 0 时不显示。

## 接口

`api/modules/github.yaml` 的 `GitHubActionsUsage` 加必填字段 `publicMinutes`（整数，折算后的分钟数，算法和 `usedMinutes` 一样）。`usedMinutes`、`byOS` 的说明改成“只算私有仓库”。

## 后端（`modules/github/usage.go`）

- 新计费接口的每条用量有 `repositoryName`（`owner/name`）。对出现过的每个仓库调一次 `GET /repos/{owner}/{name}`，`private` 为 `false` 的算公开。
- 查不到（404、403 等）或者没有 `repositoryName` 的，按收费算，宁可多算不要少算。
- 仓库是否公开和用量结果一起缓存（同一个 10 分钟缓存），`refresh=true` 时重新查。同一次统计里每个仓库只查一次。
- 旧接口（`/settings/billing/actions`）本来就只算私有仓库，`publicMinutes` 填 0。
- 通知阈值用新的 `usedMinutes`。

## 前端（`features/github/GitHubPage.tsx`）

- 卡片按系统那一行下面加一行“公开仓库 N 分钟不收费”，N 为 0 不显示。词条放进 `features/github/i18n.ts`。

## 验收

- 测试数据里 `jo/app` 私有、`jo/x-console` 公开：`usedMinutes` 和 `byOS` 只含 `jo/app`，`publicMinutes` 是 `jo/x-console` 的折算分钟数。
- 查仓库返回 404 时那个仓库按收费算。
- 缓存期内不重复查仓库，`refresh=true` 会重新查。
- 卡片在 `publicMinutes` 大于 0 时显示那一行。
