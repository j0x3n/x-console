# B251 外部网盘上传提示（XC-67）

2026-10-19 用户授权继续完成剩余看板任务。外部网盘目前用 fetch 上传，只有内置云盘使用上传队列和拖入提示。

- 复用 `features/drive/upload.ts` 和 `UploadPanel`。外部网盘上传目标增加网盘 ID 和当前目录 ref，仍走现有 PUT content 接口。
- 拖入任意页面区域时显示与内置云盘相同的松开上传提示，松开后显示队列和每个文件的进度。
- 切换目录后已经开始或排队的文件仍传到原目录。上传完成刷新对应网盘列表，失败显示后端错误，不自动覆盖重试。
- 选择文件按钮和拖入走同一条队列。保留最多 3 个并行上传。
- 不改后端、API 定义和迁移。测试覆盖目标编码、原始请求体、进度、失败、并行限制和拖入。
- 截图检查云盘 1360px 和 390px，端到端第一部分补外部网盘上传进度流程。
