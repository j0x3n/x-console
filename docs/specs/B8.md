# B8 Playwright 端到端测试

## 目标

在独立的临时数据目录启动真实 Go 服务端、正式构建的前端和 Linux 代理。用 Chromium 操作页面，覆盖初始化账号、退出后登录、新建项目和 Issue、写笔记、新建提醒、查看在线服务器、打开终端、习惯打卡。浏览器里的演示数据要关闭，测试必须读写真实接口。

## 实现

- `web/scripts/e2e.mjs` 负责构建服务端、代理和前端，由 Go 服务端托管前端。进程、临时目录在成功或失败后清理。
- 测试通过页面操作主流程，并向真实接口核对结果。代理用页面生成的配对码配对，然后以独立进程连接服务端。
- CI 在前端任务通过后安装 Go 和 Chromium，执行 `npm run e2e`。复用前端构建，失败时上传截图及运行日志。
- 新功能交付时在这个脚本里增加一条主流程。

## 验收

- 在干净的 Ubuntu 环境运行 `npm run e2e`，上述流程全部通过。
- 操作未被演示拦截，数据库和代理连接都是真的。
- 故意让任一流程断言失败时命令以非零退出，并保存失败现场。
- 现有后端、前端检查通过。
