# B66 “日历”改名“日程”，早报挪到今日页

用户 2026-10-01 问：日历的二级菜单里有早报、专注，这些也归日历吗？日历这个名字能不能改。

**开工前和用户确认**：按本文的方案做。用户还没回复，2026-10-01 Claude 的建议是这样。

只改前端。

## 现状

- 左栏“日历”（`/calendar`）的二级菜单（`web/src/features/calendar/NavChildren.tsx`）：日程、早报、专注、日历管理，对应路由 `/calendar`、`/calendar/briefs`、`/calendar/focus`、`/calendar/calendars`（`features/calendar/routes.tsx`）。
- 早报是“每天早上把天气、日程、待办汇总推送”，设置在设置 → 早报。专注是番茄钟。

## 做法

1. 左栏的“日历”改名“日程”：`app/nav.ts` 里 `/calendar` 那一行的 label 换一个新的英文键 `Schedule & focus`（中文“日程”），路由的 `handle.title` 一起换。不要直接改 `Calendar` 的中文，别的地方还在用“日历”这个词。
2. 二级菜单改成三项：日历（`/calendar`）、专注（`/calendar/focus`）、日历管理（`/calendar/calendars`）。早报那一项去掉。
3. 早报的历史：
   - 今日页顶栏（`PageHeading` 的 `aside`）加一个按钮“早报”（图标 `Newspaper`），点了打开早报历史。
   - 早报历史页的地址保留 `/calendar/briefs`，旧链接、通知里的链接照样能打开，只是不在左栏出现。打开时左上角显示“今日 / 早报”（`usePageCrumb` 或 `PageHeading` 的 `parents`）。
4. 命令面板里早报相关命令的分组改成“今日”（`features/calendar/routes.tsx` 里 `registerCommands` 的 `group`）。注意 B57 的 `app/modules.ts` 按分组名认模块，“今日”不属于可隐藏模块，这样早报不会跟着日程一起被隐藏，符合预期。
5. 端到端测试和截图脚本里点“日历”的地方改成“日程”（先 `grep -n "日历" web/scripts/*.mjs`）。

## 验收

- 左栏显示“日程”，下面是日历、专注、日历管理。
- 今日页右上角有“早报”按钮，点了能看到早报历史。
- 旧地址 `/calendar/briefs` 还能打开。
