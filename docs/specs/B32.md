# B32 AI 改为 OpenAI 兼容接口，分快速模型和 Agent 模型

用户要求（2026-09-28）：

- AI 设置去掉 Anthropic 支持，改成支持 OpenAI 兼容接口。
- 自动获取接口上的全部模型，再通过 models.dev 同步模型规格。
- 可以设置两个模型：快速模型和 Agent 模型。快速模型给笔记自动加标签、起标题。Agent 模型给 AI 浮窗、自动化、服务器 Agent 标签（B33）用。
- 可以选思考程度。
- “AI 助手”改名“AI”（界面文字，B22 里一起改）。

这个任务替换 B3 / M12 规格里“用 Anthropic 官方 SDK”的部分。改完要把 `docs/specs/M12.md` 里相关段落改掉，写明以本规格为准。

## 接口供应商

- 设置里可以加多个“供应商”：名称、Base URL（比如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`、`https://openrouter.ai/api/v1`、本地的 `http://127.0.0.1:11434/v1`）、API Key（加密存储，可以为空，本地模型不需要）。
- 每个供应商有“测试连接”。
- 调用只用 OpenAI 的 Chat Completions 接口（`POST /chat/completions`，流式 `stream: true`，工具调用 `tools`）。它是各家兼容得最好的格式。不用 Responses 接口。
- Go 端用 `github.com/openai/openai-go`（官方 SDK），设置 `option.WithBaseURL`。写代码前查它当前的用法，不要凭记忆。
- 删除 `anthropic-sdk-go` 依赖和相关代码。已有的 Anthropic 配置在迁移时丢掉，设置页提示“需要重新配置 AI”。
- 数据库迁移只加不删：旧的设置键先不读，下个版本再删。

## 模型列表

- 保存供应商后，调用它的 `GET /models` 拿到全部模型 id，存下来。设置页有“刷新模型列表”按钮。
- 从 `https://models.dev/api.json` 拉模型规格：上下文长度、最大输出、是否支持工具调用、是否支持思考（reasoning）、是否支持图片输入、价格。每天同步一次，存在本地，拉不到时用上次的。写代码前先看一次实际返回的结构。
- 匹配方法：先按“供应商 + 模型 id”精确匹配；供应商对不上（比如自建的中转）时，按模型 id 去掉前缀（`openai/gpt-x` → `gpt-x`）在所有供应商里找。都找不到就显示“规格未知”，用户可以手动填上下文长度和是否支持工具。
- 模型下拉框里每个模型显示：id、上下文长度、是否支持工具和思考（小图标）、每百万 token 的输入输出价格。可以搜索。

## 两个模型

| 用途 | 设置项 | 要求 |
| --- | --- | --- |
| 快速模型 | 供应商 + 模型 | 不需要工具调用。用于笔记自动标签、自动标题、早报润色 |
| Agent 模型 | 供应商 + 模型 + 思考程度 | 必须支持工具调用，不支持的在下拉里标灰。用于 AI 浮窗、自动化、服务器 Agent |

- 思考程度：关闭、低、中、高。对应 Chat Completions 的 `reasoning_effort`（`low`/`medium`/`high`，关闭时不传）。模型不支持思考时这一项标灰。有的兼容接口不认这个参数会报错，报错时自动去掉参数重试一次，并在设置页提示“这个接口不支持思考程度”。
- 快速模型没设置时，用 Agent 模型。

## 笔记自动标签和标题

- 笔记设置里两个开关：“自动起标题”“自动加标签”，默认开，没配 AI 时不显示。
- 触发：笔记停止编辑 10 秒后，且正文超过 50 个字，且（标题为空，或者标签为空）。每条笔记每次内容大改（变化超过 30%）最多触发一次，不反复调用。
- 标题：只在标题为空时填，不覆盖用户写的标题。
- 标签：从已有的标签里选最多 3 个，只有很确定时才新建标签。结果先作为“建议标签”显示在标签栏后面（虚线框），用户点一下才加上。设置里可以改成“直接加上”。
- 隐藏笔记不送给 AI。
- 用 `json_schema` 格式的输出（`response_format`），不支持的接口退回到在提示词里要求 JSON 再解析。

## 其他

- AI 浮窗、自动化里用到模型的地方全部改走新的调用层 `modules/ai/llm`：`Chat(ctx, req) (stream, error)`，屏蔽供应商差异。工具定义从 `d.Actions.List()` 转成 OpenAI 的 function 格式，工具名里的 `.` 换成 `__`（原来就这样）。
- 每次调用记录供应商、模型、输入输出 token、耗时，设置页显示本月用量和按 models.dev 价格估算的费用。
- 更新 `api/modules/ai.yaml`：`AiSettings` 改成供应商列表和两个模型设置。

- 写一条 200 字没标题的笔记，停 10 秒后标题自动出现，标签栏出现建议标签。
- 代码里没有 `anthropic` 字样（`grep -ri anthropic backend web/src` 为空，文档和历史规格除外）。
