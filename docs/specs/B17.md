# B17 健身类习惯

习惯页去掉了单独的“健身”标签，健身放进“今天”页的模块里（前端已做）。新建习惯时可以选“健身”类型。

## 要什么

- `Habit.kind`：`count`（普通，默认）或 `workout`（健身）。接口契约已加（`api/modules/habits.yaml` 的 `HabitKind`），后端现在不认这个字段。
- 健身类习惯不能手动 +1。记一次训练（`POST /workouts/logs`）时，所有没归档的健身类习惯各打卡一次，`source = workout`。
- 删除训练记录时，删掉它带出来的那次打卡。

## 怎么做

1. 迁移 `m?_habits`：`habits` 加 `kind TEXT NOT NULL DEFAULT 'count'`，`habit_logs` 加 `workout_log_id INTEGER`。
2. 创建、修改习惯时保存 `kind`；`kind = workout` 时单位固定为“次”。
3. `POST /habits/{id}/checkin` 对健身类习惯回 400“健身类习惯要记一次训练”。
4. 记训练、删训练在同一个事务里写打卡。

## 验收

- 新建健身类习惯，记一次训练后它显示 1/1，删掉训练后回到 0。
- 普通习惯不受影响。
