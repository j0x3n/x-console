# B55 项目看板：锁定、滚动、拖动、贴图、封面、右栏按钮

用户 2026-10-01 提的：

- 顶部“编辑”旁边加锁定按钮，锁定后不能再加列表、看板。
- 看板默认的滚动条太丑；列表的“…”菜单显示不全（B54 已修）；“添加列表”的虚线框比悬停样式大，也丑。
- 快速添加卡片要能直接粘贴图片，卡片上也能看到图。
- 图片点开不要新窗口，改成页内（B54 已做）。
- 拖动时的背景框丑，也显示不全。用户确认 iOS 上能拖，不加拖放库。
- 卡片详情右栏的按钮有点乱。

## 前端（已完成）

- **锁定**：项目页顶栏最左边一个锁形按钮。锁定后：
  - 看板标签后面的“+”（新建看板）不显示，双击标签不再打开编辑。
  - 看板的“…”菜单只留“已归档的内容”，去掉编辑、复制、归档、删除看板。
  - 列表的“…”菜单去掉列表设置、归档列表、删除列表，留下折叠、移动全部卡片、归档全部卡片。
  - 最右边的“添加列表”不显示。
  - 卡片照常能加、能改、能拖。
  - 状态以 `project.layoutLocked` 为准。后端还没返回这个字段时，记在本机 `localStorage`（`xc.projects.locked.<项目 id>`）。
- **滚动**：滚动条平时透明，鼠标移到看板上才显示。两边还能滚时边缘渐隐。鼠标在看板空白处按住可以左右拖动；竖向滚轮在看板上转成横向滚动（列表本身能上下滚时交给列表）。
- **添加列表**：去掉虚线框，和“添加卡片”同样的样式，悬停才有底色。点开后输入框有浅色底。
- **拖动**：拖动时复制一张干净的卡片当拖动图（带阴影，稍微倾斜），不会带上列表背景，也不会被截掉。目标位置空出一张卡片高度的虚线框，代替原来 2px 的线。目标列表换成浅灰底色，不再加边框。
- **快速添加贴图**：快速添加框可以粘贴、拖入图片，或点右下角的图片按钮选择。图片先上传（`POST /files?scope=projects`），输入框下面显示缩略图，可以移除。点“添加”时图片写进卡片描述。只有图片没写标题时，用第一张图的文件名当标题。上传中“添加”按钮显示“上传中…”。
- **封面**：卡片描述里的第一张图显示在卡片顶部，最高 120px（`logic.ts` 的 `coverImage`，只认 `http(s)://` 和站内 `/` 开头的地址）。
- **右栏按钮**：合成一行：“分配给 Agent”占满，后面是专注图标按钮（`StartFocusButton` 加了 `compact`），最后是“…”菜单：手动建编码任务、复制卡片、归档（或恢复）、删除卡片。
- 端到端测试：快速添加的占位文字改了；加了一段锁定后“添加列表”和“新建看板”消失、解锁后回来。

## 契约（已改）

`api/modules/projects.yaml`：`Project` 和 `UpdateProject` 加 `layoutLocked`（boolean）。

## 后端（待做，给开发者）

都在 `backend/internal/server/modules/projects/`。

1. 迁移 `backend/internal/server/store/migrations/20261001000400_m5_b55_project_layout_lock.sql`：

   ```sql
   -- +goose Up
   ALTER TABLE projects ADD COLUMN layout_locked INTEGER NOT NULL DEFAULT 0;

   -- +goose Down
   -- 迁移只加不删，Down 留空
   ```

2. `queries.sql` 的项目查询和更新带上 `layout_locked`，跑 `go generate ./...`。`Project` 转换时填 `LayoutLocked`，`UpdateProject` 里 `body.LayoutLocked != nil` 才改。
3. 锁定时后端也要拒绝改结构，防止别的入口（MCP、AI 工具）绕过。下面这些操作在项目锁定时回 `409`，错误码 `layout_locked`，文字“看板结构已锁定，先在项目页解锁”：
   - 新建、复制、删除、归档看板；改看板名称和图标。
   - 新建、删除、归档列表；改列表的名称、颜色、状态、WIP 上限、顺序。
   - 不拦：列表折叠（`collapsed`，只影响显示）、卡片的增删改和移动、批量归档列表里的卡片、把一个列表的卡片全部移走。
   - 解锁（`layoutLocked: false`）本身不受限制。
4. 测试：锁定后新建列表回 409；锁定后卡片照常能新建和移动；折叠列表不受影响；解锁后又能新建列表。

## 验收

- 在快速添加框里粘贴一张截图，点添加后卡片顶部显示这张图，点开卡片描述里有这张图，点图片在页内放大。
- 卡片详情右栏只有一行按钮。
