# B10 界面统一

## 用户要什么

- 右侧内容区占满宽度。现在宽屏右边空着一大块。
- 所有页面好看、统一。参考初版（提交 `3215f0f`）的组件和“今日”页。

## 问题

- `web/src/styles/ui.css` 里 `.xc-page` 设了 `max-width: 1280px`。屏幕宽于 1500px 时右边留白。
- 各页的标题、副标题、按钮位置不一致。有的标题加粗，有的不加粗。
- 很多页面只有一个标题加一个列表，没有初版那种概要数字和卡片层次。

## 做法

1. 去掉 `.xc-page` 的最大宽度。正文类页面（设置表单、笔记正文）自己限制行宽，不靠整页限制。
2. `PageHeading` 统一成初版的样子：
   - 大标题 28px，字重 500。
   - 标题下面一行灰色副标题，写这一页的概况，比如“3 台在线，1 台告警”。
   - 右上角放按钮。副标题右侧可以放一个状态点和一句话。
3. 新增两个通用组件，放在 `components/ui/`：
   - `StatStrip`：一排概要卡片，初版“今日”顶部那种。每张卡片有标签、角标、大数字、单位、一行说明，下面可以放迷你图（进度条、环、柱）。
   - `Section`：带标题、数量和右侧操作的分区。
4. 各页面按初版补上层次：
   - 项目：顶部概要（未完成、进行中、今天到期、本周到期、逾期），项目卡片加进度环。进行中单独成卡（B15 用户决定）。
   - 提醒：顶部概要（今天、下一个、即将到来、已完成），列表按日期分组。保留现有四张卡（B15 用户决定）。
   - 习惯：顶部概要（今天完成几项、连续天数）。
   - 服务器、监控、编码任务、GitHub、智能家居：顶部概要，空状态统一。
5. 检查 390px 宽度，不能横向滚动。

## 验收

- 1920px 宽度下所有页面内容铺满，右侧没有大块空白。
- 390px 宽度下没有横向滚动。
- 深色和浅色主题下都正常。
- 所有页面的标题区样式一致。
