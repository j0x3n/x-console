# B76 左栏数量标记，二级菜单选中更明显

用户 2026-10-01 提的：

- 邮件有未读时，在左栏这一行右边、折叠按钮左边，显示一个浅红色圆底的未读数；超过 9 个就只显示一个红点。
- 所有一级菜单都这样，有紧急或者没处理的事情就显示数量。
- 二级菜单选中的样子不好看，也不明显。

只改前端，数据都用现有的接口。

## 数量标记

- 模块在自己的 `routes.tsx` 里登记：`registerNavBadge("/mail", useMailBadge)`。`useMailBadge()` 是一个 Hook，返回 `{ count, tone, title } | null`。`tone` 是 `danger`（浅红底红字，默认）或 `warn`（浅黄底）。
- 侧边栏每一行渲染时调用这个 Hook。为了 Hook 顺序固定，每个一级菜单渲染一个小组件 `NavBadge`，里面调登记的 Hook。
- 显示：
  - 1 到 9：直径 18px 的圆，浅色底，数字 11px。
  - 10 以上：一个 8px 的实心红点（`warn` 时是黄点）。鼠标悬停提示写具体数字和说明，比如“12 封未读”。
  - 放在这一行右边、折叠箭头左边。没有折叠箭头的菜单放在最右边。
  - 侧边栏折叠成图标时，显示在图标右上角，只有点，没有数字。
- 数据：用 TanStack Query，和页面共用缓存；只用模块已经有的查询，不加新接口，不轮询（事件刷新）。

| 菜单 | 数什么 | 颜色 |
| --- | --- | --- |
| 邮件 | 所有账号的未读数（`/mail/summary` 的 `unread`） | 红 |
| 提醒 | 已经过期还没完成的提醒数，加上今天到期的外部事项 | 红 |
| 项目 | 分配给我、已经过期的卡片数 | 红 |
| Agent | 等你决定的任务数（review 状态）+ 失败的任务数 | 黄 |
| 仓库 | 默认分支 CI 失败的仓库数 | 红 |
| 服务器 | 离线的机器数 + 正在告警的数 | 红 |
| 电脑 | 不显示 | |
| 运维监控 | 正在故障的监控数 + 7 天内到期的订阅、证书、域名 | 红 |
| 习惯 | 不显示（不算紧急） | |
| 云盘 | 失败的后台任务数 | 黄 |
| 今日、笔记、日程、智能家居、自动化、路由器 | 不显示（自动化以后可以加“最近失败的运行”） | |

隐藏模块锁定时，它的菜单和标记都不出现（B57 已经处理菜单，标记跟着菜单走）。

## 二级菜单选中

- 选中项：浅强调色底（`--xc-accent-soft`），文字和小字用强调色，字重 500。
- 左边的竖线上，选中项那一段画成 2px 强调色。
- 鼠标悬停还是浅灰底，和选中区分开。

## 验收

- 邮件有 3 封未读时左栏显示 3；有 15 封时只显示红点，悬停写“15 封未读”。
- 读完以后标记消失（事件刷新，不用刷新页面）。
- 二级菜单里当前页一眼能看出来，深浅主题都清楚。
