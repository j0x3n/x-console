# B13 隐藏内容

## 用户要什么

- 有一个不显眼的入口。点它，输入密码，才能看到隐藏的笔记和云盘文件。
- 平时（没解锁时）隐藏的内容在任何地方都看不到：列表、搜索、命令面板、早报、AI 助手。

## 入口和解锁

- 入口：连续点侧边栏左上角的 Logo 3 次（2 秒内）。界面上没有别的提示。
- 弹出一个密码框。输对后进入“隐藏模式”：
  - 页面顶部出现一条细的提示栏：“隐藏内容已显示”，右边有“锁定”按钮。
  - 笔记和云盘多出“隐藏”分类，能看到、编辑、上传隐藏内容。
- 以下情况自动锁定：点“锁定”、15 分钟没有操作、退出登录、关闭页面后重新打开。
- 还没设过隐藏密码时，入口弹出的是“设置隐藏密码”框。密码至少 6 位。
- 在设置的“安全”标签里可以修改隐藏密码（要输入旧的）。忘了密码只能用命令行重置：`x-console-server reset-vault-password`，重置后原来隐藏的内容仍然隐藏。

## 数据

- 笔记表加 `hidden`（0/1）。云盘文件和文件夹也有 `hidden`，文件夹隐藏后里面的内容都算隐藏。
- 隐藏密码用 argon2id 存在设置 `vault.password_hash`。
- 会话表加 `vault_until`。解锁时设成 15 分钟后，每次带着解锁状态的请求往后延。
- 隐藏笔记不写进全文索引。解锁后搜隐藏笔记用 LIKE。

## 后端规则

- `auth` 包加 `VaultUnlocked(ctx) bool`。
- 任何接口在没解锁时：
  - 列表和搜索不返回隐藏内容。
  - 按 id 取隐藏内容返回 404，不要返回 403，不暴露它存在。
- 解锁后，列表接口带 `hidden=true` 只返回隐藏内容。不带时仍然只返回普通内容。两边分开，避免在普通列表里误操作。
- 动作目录（AI 助手、自动化）永远看不到隐藏内容，就算当前会话已解锁。动作执行的 ctx 不带解锁状态。
- 设为隐藏、取消隐藏、解锁、锁定都记审计日志。审计里只记 id，不记标题。
- 早报、通知、事件推送：隐藏内容不出现。事件里隐藏内容只推 `{id, hidden: true}`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/vault/status` | `{configured, unlocked, unlockedUntil}` |
| POST | `/vault/setup` | `{password}`，只在没设过时可用 |
| POST | `/vault/unlock` | `{password}`。失败次数限制和登录一样 |
| POST | `/vault/lock` | |
| POST | `/vault/password` | `{oldPassword, newPassword}` |

笔记和云盘的“设为隐藏”用各自的 PATCH，字段 `hidden`。只有解锁后能改这个字段。

## 验收

- 没解锁时，用接口直接取隐藏笔记的 id 返回 404，搜索搜不到它。
- AI 助手在已解锁的会话里问“列出我的笔记”，结果里没有隐藏笔记。
- 解锁后 15 分钟不操作，再刷新页面，隐藏内容不见了。
- 连续输错密码 5 次后被锁 15 分钟。
