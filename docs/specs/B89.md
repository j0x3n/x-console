# B89 每日一句和便签置顶

用户 2026-10-02 提的：

- 首页问候语后显示每日一句：入口放在笔记下的便签，用「名言」标签的便签做来源，可选固定显示、每次刷新随机、每日随机，固定显示用名言里固定的第一条。
- 便签加入固定功能，固定的排在首位；「名言」便签不显示在全部笔记列表里。

## 怎么做

- **来源**：带“名言”标签的便签（`kind=memo`，`tag=名言`）。
- **设置入口**：笔记 → 便签视图的工具栏加“每日一句”按钮，弹窗里选：不显示、固定显示、每次打开随机、每天随机。存到 `/me/preferences` 的 `quoteMode`，接口没上线时存在本地。
  - 固定显示：用置顶的名言里排第一的那条；没有置顶的就用最新的一条。
  - 每天随机：按日期选，同一天每次打开都一样。
- **显示**：今日页问候语后面，灰字，长了换行（最多三行，超出省略）。点它打开那条便签。没有名言时不显示。
- **便签置顶**：便签视图里已经有置顶按钮（B73），置顶的排在前面。这次把置顶按钮在手机上也一直显示，置顶的便签加一个图钉标记。
- **“全部笔记”不显示名言**：笔记列表的“全部”里不显示带“名言”标签的便签。点“名言”标签、或者在便签视图里照常显示。

## 契约（已改）

- `core.yaml` 的 `Preferences` 加 `quoteMode`。

## 后端（Claude 顺手做了，2026-10-02）

- `me/preferences` 读写 `quoteMode`，只接受四个值。旧数据没有时不返回，前端当成 `off`。

## 和上面不同的地方

- “全部笔记”的列表本来就只列笔记，不列便签。用户说的“全部”按便签视图的总览理解：便签总览里不显示带“名言”标签的，上方给一个“#名言 N”的入口。
- 便签置顶 B73 已经有了（悬停时的图钉按钮，手机上一直显示）。这次加了置顶标记，置顶的排在前面也是原来就有的。

## 验收

- 建三条带“名言”标签的便签，置顶其中一条。选“固定显示”，今日页显示置顶的那条。
- 选“每天随机”，刷新几次都是同一条。
- “全部笔记”里看不到这三条，便签视图和“名言”标签下能看到。
