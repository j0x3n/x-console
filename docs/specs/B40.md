# B40 笔记：阅读模式、AI 润色、生成标题和标签、三栏可调

用户 2026-09-30 提出，让 Claude 直接写。

## 要什么

- 点开已有内容的笔记，默认是阅读模式，显示渲染后的 Markdown。点“编辑”才进编辑模式。新建的空笔记直接进编辑模式。
- 编辑工具栏加“AI 润色”：
  - 直接点：按内容自动润色、整理格式和排版。
  - 也可以自己输入提示词，比如“改成要点列表”“翻译成英文”。
  - 结果先给用户看，确认后替换正文，可以撤销。
- 标题为空、正文有内容时，保存后自动生成标题和标签（沿用 B32 的开关）。
- 标题旁边和标签旁边各加一个按钮，手动生成。
- 笔记本的三栏（笔记本和标签、笔记列表、编辑区）可以拖动调宽，宽度保存下来，下次打开还是这样。

## 接口

- `POST /notes/ai/polish`：请求 `{body, prompt?}`，回 `{body}`。用快速模型。正文最多 20000 字。
- `POST /notes/{id}/ai/title`：回 `{title}`，只生成不保存。
- `POST /notes/{id}/ai/tags`：回 `{tags}`，只生成不保存，最多 3 个，优先用已有标签。
- 隐藏笔记也能用这三个接口，但要隐藏空间已解锁；自动生成仍然跳过隐藏笔记。
- 保存后自动生成：标题为空、正文超过 50 字时，不再等 10 秒，保存后马上排队。

## 前端

- 阅读和编辑切换放在编辑区顶部。
- 润色结果用对比或预览的方式展示，按钮“替换”“取消”。
- 三栏宽度存在 `localStorage`，每栏有最小宽度，手机上不显示拖动条。

## 验收

- 假模型测三个接口：润色带不带提示词，标题和标签只返回不保存。
- 前端测试：已有笔记打开是阅读模式，点编辑进入编辑；润色结果替换正文；拖动后刷新宽度不变。
