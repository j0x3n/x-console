# B11 备忘改名为笔记，重做列表和编辑器，支持图片和附件

## 用户要什么

- “备忘”改叫“笔记”。侧边栏、页头、命令面板、设置里都改。
- 笔记列表和编辑框现在不好看，要重做。
- 笔记里能放图片和其他文件。

## 界面

### 布局

- 桌面三栏：左边是分类栏（全部、置顶、各标签、已归档），中间是笔记列表，右边是编辑区。
- 宽度小于 1100px 时分类栏收进列表顶部的下拉。小于 720px 时列表和编辑区切换显示。

### 列表

- 每条笔记是一张卡片：标题（没有标题时取正文第一行），两行摘要，底部是标签和相对时间。
- 正文里有图片时，卡片右侧显示第一张图的缩略图（56px 方形）。
- 置顶的笔记在最上面一组，组标题“置顶”。其余按“今天、昨天、本周、更早”分组。
- 当前选中的卡片有底色和左侧色条。
- 顶部是搜索框和“新建”按钮。搜索命中的字高亮。

### 编辑区

- 顶部工具条：保存状态、置顶、标签、更多菜单（转 Issue、转提醒、归档、删除）。
- 标题是一行大字输入框，没有边框。下面是标签，可以直接加减。
- 正文编辑和预览：
  - 默认“编辑”模式，等宽字体换成正文字体，行高 1.7，正文最大宽度 760px 居中。
  - 格式工具条：标题、粗体、斜体、列表、待办、引用、代码、链接、图片。点按钮在光标处插入 Markdown。
  - “预览”模式用 Markdown 渲染，图片按宽度自适应，点图片看大图。
  - 宽屏可以选“分栏”，左边编辑右边预览。
- 底部显示字数和最后修改时间。

### 图片和附件

- 插入方式：工具条的图片按钮、粘贴、拖进编辑区。
- 上传时在光标处先插入 `![上传中…]()`，完成后换成正式地址。
- 图片插入 `![文件名](/api/v1/notes/attachments/<id>)`，其他文件插入 `[文件名](/api/v1/notes/attachments/<id>)`。
- 单个文件最大 50 MB。

## 后端

### 表

`note_attachments`：id、note_id（外键，笔记删除时一起删）、name、mime、size、sha256、created_at。

文件存在 `<数据目录>/notes/attachments/<id>`。

### 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/notes/{noteId}/attachments` | multipart，字段 `file`。返回 Attachment `{id, noteId, name, mime, size, url}` |
| GET | `/notes/{noteId}/attachments` | 这条笔记的附件 |
| GET | `/notes/attachments/{attachmentId}` | 下载。图片用 `inline`，其他用 `attachment`。带 `Cache-Control: private, max-age=31536000` |
| DELETE | `/notes/attachments/{attachmentId}` | |

- 下载要登录。隐藏笔记的附件只有解锁后能下载（见 B13）。
- `mime` 以服务端检测为准（`http.DetectContentType`），不信任上传时的类型。SVG 按附件下载，不内联显示。
- NoteSummary 加 `thumbnail`：正文里第一张附件图片的地址，没有就不返回。

## 验收
