# B11 页头与笔记页面

## 需求

- 页面左上角已有小标题时，不再显示内容区重复的大标题。保留页面一级标题的无障碍语义。
- 把界面上的“备忘”统一改为“笔记”。
- 调整笔记列表、搜索框、标签和正文编辑区的样式。桌面编辑区使用可用宽度，手机继续使用列表与内容切换。
- 概览页另在 B2 任务中按初版“今日”页面的结构重做。

## 做法

- 通过通用 `PageHeading` 收起大标题，并保留副标题和操作按钮。
- 修改笔记模块的布局与表单样式，不改笔记的数据模型和自动保存逻辑。
- 修改全局词典和笔记命令分组的中文文案。

## 验收

- 日历等页面只出现左上角的小标题；页面操作仍可用。
- 笔记在导航、命令和提示中统一显示为“笔记”。
- 桌面笔记列表和编辑区清晰、编辑区用满剩余宽度。
- 在 390px 宽度下，列表与编辑页可切换，没有横向溢出。
