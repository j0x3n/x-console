# B54 公共组件：菜单不被截掉，图片页内放大

用户 2026-10-01 提的。看板列表的“…”菜单显示不全；Markdown 里的图片点开会打开新窗口。

## 前端（已完成）

- `components/ui/MoreMenu`：菜单用 `createPortal` 挂到 `body`，`position: fixed`。打开时按按钮位置算坐标（`menuPosition`），默认在按钮下方右对齐，下方放不下就放到上方，左右不超出窗口。页面滚动、窗口缩放、按 Esc 时关闭。手机（≤640px）还是从底部弹出。层级改成 69/70，弹窗里的菜单也在弹窗上面。云盘原来单独调层级的样式删掉了。
- 新增 `components/ui/ImageLightbox`：页内看大图。点背景或按 Esc 关闭；多张图时显示“2 / 5”，左右键或两侧按钮切换；右上角“打开原图”和“关闭”。
- `components/markdown/Markdown`：没传 `onImageClick` 时，点图片打开 `ImageLightbox`，同一段内容里的图片可以左右切换。公共上传的图片仍然显示缩略图，大图看原图。笔记原来自己写的大图层删掉，改用这个。

## 后端

不涉及。

## 验收

- 项目看板最右边一列的“…”菜单完整显示，靠近窗口底部时往上弹。
- 卡片描述、笔记、提醒里的图片点开在页内显示，Esc 关闭，多张图能左右切换。
