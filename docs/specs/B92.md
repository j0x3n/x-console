# B92 通知正文清理

用户 2026-10-02 提的：

- 邮件通知正文里会显示 `<!--[if !mso]>` 这类 HTML 代码，要只显示干净的文字。
- 所有通知都不要单独多占一行显示「from x console」。
- 早报通知在 AI 正常时只显示总结内容，其他都不要，包括「【总结】」小标题。

## 怎么做（后端，Codex）

- **邮件通知正文**：新邮件通知的正文用邮件的纯文本摘要。只有 HTML 时先转成纯文字：去掉 `<!-- -->` 注释（包括 `<!--[if mso]>…<![endif]-->` 这种条件注释）、`<style>`、`<script>`、`<head>`，标签换成空格或换行，解码 HTML 实体，合并连续空白，最多 200 字。邮件页的列表摘要用同一个函数。
- **“from X Console”**：先查是哪条通道多出来的这一行。
  - 服务端自己加的（推送正文、Telegram、Server 酱、Bark 的 group 等）：去掉。
  - 浏览器自己显示的（Windows 通知里的来源网址或应用名，Android 通知顶部的应用名）：网页改不了。查清楚后在规格里写明，告诉用户。
- **早报通知**：AI 总结生成成功时，通知正文只放总结的文字，不加“【总结】”小标题，不附天气、日程这些分节。AI 失败或没配时照旧发各分节。

## 验收

- 收到一封营销邮件（HTML，带 Outlook 条件注释），通知正文是干净的文字。
- 早报通知只有一段总结。
