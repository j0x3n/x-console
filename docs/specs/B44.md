# B44 手机上字号整体放大

用户 2026-09-30 提出：面板在手机上整体字体太小。

## 现状

样式里的字号全部写死像素，桌面和手机一样大。按出现次数：12px 149 处、11px 92 处、12.5px 48 处、10px 47 处、13px 43 处、9px 18 处。手机正文大多是 12 到 13px，辅助文字 9 到 11px。

参考数字：iOS 系统正文是 17pt，最小的说明文字 11pt 以上；输入框字号小于 16px 时 Safari 聚焦会自动放大页面。

## 做法

1. 在 `styles/tokens.css` 定义字号令牌，桌面值等于现在的值，手机（`max-width: 720px`）换一套：

   | 令牌 | 桌面 | 手机 | 用在哪 |
   | --- | --- | --- | --- |
   | `--fs-2xs` | 9px | 11px | 角标、计数 |
   | `--fs-xs` | 10px | 12px | 时间、次要标签 |
   | `--fs-sm` | 11px | 13px | 说明文字、表头 |
   | `--fs-base` | 12px | 15px | 列表、表格正文 |
   | `--fs-md` | 12.5px | 15px | 卡片标题、按钮 |
   | `--fs-lg` | 13px | 16px | 段落正文 |
   | `--fs-xl` | 14px | 17px | 小标题 |
   | `--fs-2xl` | 16px | 19px | 页面标题 |

   更大的标题（20px 以上）手机上不放大。

2. 写一个一次性脚本，把 `web/src/styles/` 和 `web/src/features/**/*.css` 里的 `font-size: Npx` 按上表换成令牌。表里没有的值（15px、27px 等）人工看一遍，归到最近的令牌或保留。提交里附上脚本的替换统计。
3. 手机上的输入框、下拉框、文本框一律 16px，避免 Safari 聚焦放大。
4. 手机上可以点的东西（按钮、图标按钮、列表行）点击区域至少 44 × 44px。图标跟着放大一档（14px 换 16px，16px 换 18px）。
5. 行高：正文 1.5，列表行不低于 1.4。
6. `docs/07-design.md` 的字号一节改成令牌表，以后新写的样式只用令牌，不写像素。在 CI 里加一个检查：`web/src` 的 CSS 里出现新的 `font-size: <数字>px` 就报错（已有的白名单文件除外）。

## 验收

- 在 Playwright 里写一个检查，390px 宽打开全部页面（和 `npm run shots` 同一份列表），读所有可见文字元素的计算字号：
  - 没有小于 12px 的（角标 `--fs-2xs` 除外，它最小 11px）。
  - 正文段落和列表行不小于 15px。
  - `input`、`select`、`textarea` 等于 16px。
  - 可点元素的尺寸不小于 44px（只检查 `button`、`a`、`[role=button]`，列出不合格的，由开发者逐个改或者说明理由）。
- 1360px 截图和改之前逐页对比，桌面不应该有变化。
- 390px 截图逐页看：没有横向溢出、文字没有被截断到看不懂、按钮没有挤成两行。
