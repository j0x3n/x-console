# B250 左栏合并（XC-57）

用户 2026-10-19 已确认分组和样式方案 B。本规格按 `docs/handoff.md` 的 XC-57 一节整理。

## 要什么

左栏合并相近功能。复用 B179 的 `navMerges`，所有页面地址保持不变。今日仍固定在顶部。

| 入口 | 地址 | 包含的功能，按显示顺序 |
| --- | --- | --- |
| 项目 | `/projects` | 项目 |
| Agent | `/coding` | Agent、仓库 `/github` |
| 笔记 | `/notes` | 笔记、稍后读 `/readlater`、复习卡片 `/cards`、资讯 `/feeds` |
| 问我的数据 | `/ask` | 问我的数据 |
| 邮件 | `/mail` | 邮件 |
| 日程 | `/calendar` | 日程和专注、提醒事项 `/reminders`、今日计划 `/plan`、收集箱 `/inbox` |
| 音乐 | `/music` | 音乐 |
| 云盘 | `/drive` | 云盘 |
| 设备 | `/servers` | 服务器、电脑 `/pc`、路由器 `/router`、智能家居 `/home`、屏幕时间 `/screentime` |
| 个人 | `/habits` | 习惯和健身、目标 `/goals`、状态打卡 `/checkins`、自我实验 `/experiments`、技能 `/skills`、证件档案 `/documents`、联系人 `/contacts`、菜谱 `/recipes`、预测 `/forecasts` |
| 运维 | `/monitoring` | 监控、密钥 `/credentials`、自动化 `/automations` |

旧的“家”入口拆掉。设备、个人、运维各有新图标。入口英文键是 `Devices`、`Personal`、`Ops`，中文是“设备”“个人”“运维”。删除旧入口名称覆盖 `Home and network`。

## 默认固定与旧偏好

`defaultNavPins` 包含全部 11 个入口，按以下顺序分三段：

1. 项目、Agent。
2. 笔记、问我的数据、邮件、日程、音乐、云盘。
3. 设备、个人、运维。

两条分隔线分别是 `/-/1` 和 `/-/2`。

旧固定项通过 `entryOf` 映射到新入口。保留用户原来的先后顺序，重复入口只保留第一次。比如 `/reminders` 变为 `/calendar`，`/router` 变为 `/servers`。

`railItems`、`railEntries`、`togglePin`、`isPinned` 使用同一套映射规则。分隔线沿用现有清理规则。打开页面不会主动重写后端保存的偏好。

启动台的“左栏顺序”也要兼容旧固定项。显示、排序和移除必须与图标栏一致。隐藏的功能不出现在入口成员或搜索结果里。

## 二级菜单

- 标题栏显示入口名。顶部显示组内功能，横线下显示当前功能自己的菜单。
- 组内功能顺序与 `navItems` 一致。`buildEntries` 和 `MergedNavPanel` 使用相同顺序。
- 可见功能不超过 5 项时单列，行高 34px。
- 可见功能超过 5 项时两列，行高 28px，字号使用 `--fs-12`。本次只有个人组需要两列。
- 手机上的抽屉显示相同内容。390px 宽度下不能横向溢出。
- 进到成员页面时高亮所属入口。点击入口沿用原有的组内页面记忆。

## 启动台

启动台保留工作、个人、设备三组。入口的分组取入口自身的 `navItems` 行。云盘、设备、运维设为 `machines`。空的集成分组不显示。

按入口名或成员名都能搜索。搜索“菜谱”找到个人，搜索“仓库”找到 Agent，搜索“资讯”找到笔记。沿用现有搜索实现并补回归测试。

## 接口与改动范围

不改 API 定义，不增加数据库迁移。`navPins` 仍是原有字符串数组。

主要改动：`app/nav.ts`、`components/layout/navEntries.ts`、`Sidebar.tsx`、`Launcher.tsx`、`styles/nav.css`，以及必要的词典和测试。

导航属于公共基础代码。只为本次合并修改必要位置，保持现有导出和调用兼容。原因和兼容方式记入 `docs/api-changes.md`。同步更新 `docs/07-design.md` 的左栏说明。
