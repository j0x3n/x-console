# B180 设置改成弹窗

2026-10-13 用户提的：设置页的标签太多（22 个），重新规划，改成弹窗。

## 要什么

- 设置从单独的页面改成弹窗，开在当前页面上面，关掉后回到原来的页面。
- 左边分组菜单，右边是选中的那一页。手机上全屏，先显示菜单，点进去再显示内容，左上角返回菜单。
- 减少设置项。

## 分组

| 分组 | 设置项                                                                    |
| ---- | ------------------------------------------------------------------------- |
| 通用 | 我的状态、通知、早报                                                      |
| 安全 | 登录与验证、设备与代理、远程访问、审计日志                                |
| AI   | AI（AI 用量并进来，排在下面）                                             |
| 集成 | Git 与仓库（Linear 并进来）、Home Assistant、邮件、路由器、稍后阅读、音乐 |
| 数据 | 存储、备份                                                                |
| 系统 | 维护（最近错误并进来）                                                    |

只和一个功能有关的设置挪回功能页：

- 复习卡片：复习卡片页本来就有“复习设置”标签，设置里不再放。
- 专注屏蔽：番茄钟页（`/calendar/focus`）顶栏加“专注屏蔽”按钮，点开弹窗。地址带 `?block=1` 时直接打开。

## 怎么做

- 地址用 `?settings=<id>` 表示弹窗开着、开的是哪一页，刷新后还在。值为空时电脑上显示第一项，手机上显示菜单。
- 旧地址 `/settings/<id>` 都能用：路由在加载前把它换成“上一个页面 + `?settings=<id>`”，页面不会先跳走再跳回来。原地址上的其他参数（`?add=desktop`、`?gdrive=ok`）一起带过去。直接打开设置地址时，弹窗开在今日页上面。
- 合并掉的旧地址跳到合并后的那页：`linear`、`github` → `git`，`ai-usage` → `assistant`，`errors` → `maintenance`；`cards` → `/cards?tab=settings`，`focus-block` → `/calendar/focus?block=1`。
- 路由加载时拿不到地址里的 `#`，要滚到某一块时用 `?section=<元素 id>`，跳转时换成 `#<元素 id>`，弹窗等内容出来后滚过去。
- 从页面里点开时多记一条历史，关闭时后退，浏览器的返回键也能关。弹窗里换页不多记历史。
- Esc 关闭。设置里又开了别的弹窗时，Esc 只关上面那个。

## 验收

- 从任何页面点开设置，背后的页面不变；关掉后页面状态还在。
- 各模块里原来的设置链接都能打开对应的页。
- 1360px 和 390px 截图没有横向溢出和报错。
- 测试：`features/settings/SettingsHost.test.tsx`。
