## 前端（已完成，提交 B22）

- 个人菜单（头像弹出的菜单）：设置、夜间模式（开 / 关 / 自动）、主题色（六个色块）、语言、安装应用（已安装时不显示）、退出登录。
- 主题色：暖橙（默认）、紫罗兰、薄荷绿、海蓝、玫瑰、石墨。只在白天生效，`html[data-accent]` 切换，定义在 `styles/tokens.css`。夜间固定用深色配色。
- 偏好先存在 `localStorage`（`x-console-theme`、`x-console-accent`、`x-console-language`），首屏不闪。
- 登录后调用 `GET /me/preferences`：
  - 回 501 或 404（后端还没做）：只用本地的，不报错。
  - 回 200 且带 `updatedAt`：用服务端的覆盖本地。
  - 回 200 但没有 `updatedAt`（从没存过）：把本地的偏好 `PUT` 上去。
- 之后用户每改一次，前端 `PUT /me/preferences` 整份提交。失败时不提示，本地仍然生效。
- 代码：`hooks/usePreferencesSync.ts`、`stores/preferences-store.ts`、`components/layout/Sidebar.tsx`、`features/pwa/InstallMenu.tsx`。

## 后端（待做，给开发者）

契约在 `api/modules/core.yaml` 的 `/me/preferences` 和 `Preferences`。现在由 `backend/internal/server/core/pending.go` 回 501，实现后删掉那个文件。

### 存储

不用新表。用已有的设置存储（`internal/server/settings`），键 `ui.preferences`，值是 JSON：

```json
{ "nightMode": "auto", "accent": "ember", "language": "zh", "updatedAt": "2026-09-28T10:00:00Z" }
```

只有一个用户，所以不按用户区分。以后支持多用户时再改成按用户 ID 存。

### GET /me/preferences

- 要登录（走现有的会话中间件，和其他 `/auth` 以外的接口一样）。
- 读 `ui.preferences`。`settings.ErrNotSet` 时返回默认值 `{"nightMode":"auto","accent":"ember","language":"zh"}`，**不带** `updatedAt`。
- 读到的值里某个字段不在枚举里（比如以后删了一个主题色），那个字段换成默认值。

### PUT /me/preferences

- 用 `httpx.Decode` 读 `api.Preferences`。三个字段必填，值必须在枚举里，否则 400（`httpx.Invalid("主题色不对")` 这样的中文提示）。
- `updatedAt` 由服务端写当前 UTC 时间，忽略请求里的值。
- 存进 `ui.preferences`，回 200 和保存后的完整对象（带 `updatedAt`）。
- 不记审计日志（改外观不算安全操作）。
- 发事件 `ui.preferences_changed`，数据是保存后的对象。前端暂时不订阅，留给以后多个标签页同步。

### 测试

在 `core` 的集成测试里加：

1. 没存过时 GET 返回默认值，没有 `updatedAt`。
2. PUT 一个合法值后 GET 返回同样的值，带 `updatedAt`。
3. PUT `accent: "pink"` 回 400。
4. 未登录 GET 回 401。

### 验收

- 在一个浏览器里把主题色换成海蓝、夜间模式换成“开”，在另一个浏览器（清空 localStorage）登录，打开后就是海蓝和夜间。
- 旧浏览器里已有本地设置、服务端从没存过时，登录后服务端存上的是本地的值，不是默认值。
