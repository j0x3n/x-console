# M1 概览首页

状态：进行中（任务 B2）。依赖所有模块的查询接口。

## 目标

打开面板第一眼看到今天要关心的事。

## 卡片

| 卡片 | 数据来源 | 点击去哪 |
| --- | --- | --- |
| 问候和日期 | 本地 | 无 |
| 今日待办 | M5 `GET /issues?due=today` 或 contracts.Issues.ListDue | Issue 详情 |
| 即将到期的提醒 | M7 | /reminders |
| 习惯进度 | M8 今日进度，卡片上能直接打卡 | /habits |
| 服务器状态 | M2 汇总，异常的排前面 | 服务器详情 |
| 编码任务 | M4 运行中和待你决定的任务 | 任务详情 |
| 天气 | M11 早报用的天气接口 | 无 |
| HA 快捷开关 | M9 收藏的实体 | /home |
| 今日日程 | M11 | /calendar |

## 后端

只加一个布局接口，数据都走各模块已有接口。

- `GET /dashboard/layout`：`{cards: [{id, visible, order}]}`
- `PUT /dashboard/layout`
- 存在 `settings` 的 `dashboard.layout` 键。可以直接放在一个很小的 `modules/dashboard` 里。

## 前端

- `features/overview/`。每张卡片一个组件，各自用对应模块的 hooks 取数据。
- 卡片外面包错误边界。一张出错只显示这张的错误。
- 编辑模式：拖动排序、勾选显示。
- 手机上单列。

## 验收

- 没配置任何集成时，首页也能打开，每张卡片显示“去设置”或空状态。
- 某个模块接口报错时，其他卡片正常。
- 布局修改后刷新页面仍然保留。
