# B14 云盘

## 用户要什么

- 在面板里存文件：上传、下载、建文件夹、改名、移动、删除、预览。
- 文件可以隐藏（见 B13）。
- 能同步到 S3 兼容的存储（AWS S3、Cloudflare R2、MinIO、阿里云 OSS 等）。

## 界面 `features/drive`，路径 `/drive`，侧边栏“个人”组

- 顶部：面包屑路径、搜索框、“上传”“新建文件夹”按钮、列表和网格视图切换。
- 概要条：文件数、占用空间、S3 同步状态（已同步、同步中、失败、未配置）。
- 列表视图：名称（带类型图标）、大小、修改时间、同步状态图标。可按名称、大小、时间排序。
- 网格视图：图片显示缩略图，其他文件显示类型图标。
- 多选后可以批量下载、移动、删除。
- 拖文件到页面任何位置就上传，显示每个文件的进度条。
- 预览：图片、PDF、视频、音频、文本和代码（前 1 MB）直接在弹窗里看，其他文件只能下载。
- 右键菜单或更多按钮：下载、改名、移动、复制链接、设为隐藏、删除。
- 删除进回收站，30 天后自动清掉。回收站里可以恢复或彻底删除。
- 手机上：列表单列，操作收进底部菜单。

## 数据

`drive_items`：id、parent_id（空表示根目录）、name、is_dir、size、mime、sha256、hidden、trashed_at、created_at、updated_at、s3_synced_at、s3_etag、s3_error。同一目录下名称唯一（不含回收站）。

文件存在 `<数据目录>/drive/blobs/<sha256 前两位>/<sha256>`。内容相同的文件只存一份，没有引用时删除。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/drive/items?parent=&q=&trashed=&hidden=` | 某个目录的内容。有 `q` 时全盘搜名称 |
| GET | `/drive/items/{id}` | 单个条目，带路径 `path: [{id, name}]` |
| POST | `/drive/folders` | `{parentId?, name}` |
| POST | `/drive/upload?parent=` | multipart，可以一次多个文件。同名时自动加“ (1)” |
| PATCH | `/drive/items/{id}` | `{name?, parentId?, hidden?}` |
| DELETE | `/drive/items/{id}` | 进回收站。`?permanent=true` 彻底删除，要提升权限 |
| POST | `/drive/items/{id}/restore` | 从回收站恢复 |
| GET | `/drive/items/{id}/content` | 下载，支持 Range。`?inline=1` 用于预览 |
| GET | `/drive/items/{id}/thumbnail` | 图片缩略图，最长边 320px，缓存到磁盘 |
| GET | `/drive/usage` | `{files, bytes, trashBytes}` |
| GET/PUT | `/drive/s3` | S3 配置：endpoint、region、bucket、prefix、accessKeyId、secretAccessKey（只写）、pathStyle、enabled、includeHidden |
| POST | `/drive/s3/test` | 测试连接：写一个小文件再删掉 |
| POST | `/drive/s3/sync` | 立刻同步一次 |
| GET | `/drive/s3/status` | `{state, lastRunAt, lastError, pending, synced, failed}` |

## S3 同步

- 单向：面板是准，S3 是备份。
- 上传、改名、移动后排队同步。每 10 分钟全量对一遍，补漏。
- 对象键：`<prefix>/<路径>`，和面板里的目录结构一样，方便直接在 S3 上看。改名和移动就是复制加删除。
- 面板里彻底删除后，S3 上也删除。进回收站时 S3 上先不动。
- 隐藏文件默认不同步。打开 `includeHidden` 后同步到 `<prefix>/.hidden/` 下。
- Secret Access Key 用 `Settings.SetSecret` 加密保存。修改 S3 配置要提升权限。
- 用 `github.com/minio/minio-go/v7`。

## 事件和动作

- 事件：`drive_item.created`、`drive_item.updated`、`drive_item.deleted`、`drive.sync_status`。隐藏内容只推 `{id, hidden: true}`。
- 动作（AI 助手用，看不到隐藏内容）：`drive.list`（read）、`drive.search`（read）、`drive.read_text`（read，文本文件前 100 KB）、`drive.create_folder`（write）、`drive.write_text`（write，新建或覆盖文本文件）、`drive.move`（write）、`drive.rename`（write）、`drive.delete`（write，进回收站）。

## 验收

- 上传 1 GB 文件不占满内存（流式写盘）。
- 同一文件上传两次只存一份。
- 配好 MinIO（测试里用假的 S3 服务器）后，上传的文件出现在桶里，路径和面板一致。改名后桶里的对象也改名。
- 没解锁时隐藏文件夹在列表和搜索里都看不到。
- 390px 下能上传、预览、删除。

## 2026-09-27 补充：隐藏空间（用户要求）

- 隐藏空间是一棵单独的目录树，可以在里面建文件夹、移动。
- `PATCH hidden=true`：记下条目原来所在的文件夹（加一列 `hidden_from`，根目录记 0），条目移到隐藏空间最上层，里面的东西跟着走。
- `PATCH hidden=false`：放回 `hidden_from`；那个文件夹已经删了、进了回收站或者也被隐藏了，就放回根目录。重名时自动加“ (1)”。
- 隐藏空间最上层的条目返回 `restoreTo`（比如 `/项目资料`），界面上显示“原来在 /项目资料”，还原后提示“已还原到 /项目资料”。
