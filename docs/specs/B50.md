# B50 网站监控：补 https、站标、证书和域名合并

用户 2026-10-01 提的：

- 添加网站时只填域名，自动补 `https://`。手动写了 `http://` 的保留。
- 添加后拿到网站的站标，显示在列表里。
- 添加时不再区分证书和域名，两项默认勾上，可以取消。
- 证书和域名列表里，一个域名只显示一行。

## 前端（已完成）

- `lib.ts` 新增 `normalizeSiteUrl`、`hostOf`、`registrableDomain`（去掉子域名，认识 `com.cn`、`co.uk` 这类两段后缀）、`tlsTarget`、`companionMonitors`、`groupByDomain`，都有测试。
- `MonitorDialog` 重写：
  - 新建网站：先填网址，离开输入框时补 `https://`。名称不填就用主机名。下面“同时检查”两个勾选框：证书到期、域名到期，默认勾上。`http://` 的网站证书那项是灰的。保存时先建 http 监控，再按勾选建 `tls`（主机名，非 443 端口带端口）和 `domain`（主域名）。已经有同样目标的跳过。
  - 新建证书和域名（证书页的“添加监控”）：不再选类型，填域名，勾选要查的两项，至少勾一项。检查间隔用后端默认值。
  - 编辑：和原来一样。`domain` 监控多一个“到期日期（手动）”，见 B51。
- 新组件 `SiteIcon`：`iconAt` 有值时显示 `/api/v1/monitors/{id}/icon?v=<iconAt>`，没有或加载失败时显示域名首字母。网站列表每行前面显示它。
- `CertsTab`：按主域名合成一行。左边是主域名和组里的目标，右边每项一个小标签，比如“证书 52 天”“域名 200 天”，按到期远近标颜色。点标签打开那一项的详情，点整行打开最快到期的那一项。
- 端到端测试加了一段：只填 `www.e2e-site.example.com` 添加网站，检查建了三条监控（http、tls、domain）。

## 后端（待做，给开发者）

都在 `backend/internal/server/modules/monitoring/`。

### 1. 只填域名补 https

`monitors.go` 的 `normalizeTarget`，`kindHTTP` 分支：目标里没有 `://` 时，前面补 `https://` 再解析。补完还不合法的照旧报错。测试：`example.com` → `https://example.com`；`http://a.com` 不变；`ftp://a.com` 报错。

### 2. 站标

迁移 `backend/internal/server/store/migrations/20261001000200_m10_b50_monitor_icons.sql`：

```sql
-- +goose Up
CREATE TABLE monitor_icons (
    monitor_id INTEGER  PRIMARY KEY REFERENCES monitors (id) ON DELETE CASCADE,
    mime       TEXT     NOT NULL,
    data       BLOB     NOT NULL,
    fetched_at DATETIME NOT NULL
);

-- +goose Down
DROP TABLE monitor_icons;
```

新文件 `icons.go`：

- 什么时候抓：http 监控新建后（异步，不挡接口返回）；之后每次检查成功时，如果没有站标或者 `fetched_at` 超过 7 天，就再抓一次。抓失败不影响检查结果，只记日志。同一个监控同时只抓一次。
- 怎么找：
  1. GET 网站首页（监控目标的 scheme + host，路径换成 `/`），读最多 512 KB。用 `golang.org/x/net/html` 解析（已经在依赖里的话；没有就用简单的正则找 `<link ... rel="...icon..." ... href="...">`）。`rel` 里含 `icon` 的都算，优先 `apple-touch-icon`，其次带 `sizes` 的最大的那个，再其次第一个。`href` 按页面地址解析成绝对地址。
  2. 页面里没有就用 `<scheme>://<host>/favicon.ico`。
- 下载图标：只跟 `http`、`https`，最多 3 次跳转，超时 5 秒，最多 64 KB，超了就不要。`Content-Type` 只收 `image/png`、`image/x-icon`、`image/vnd.microsoft.icon`、`image/jpeg`、`image/gif`、`image/webp`、`image/svg+xml`。类型不对但内容是 PNG 或 ICO 文件头的，按内容认。HTTP 客户端用 `m.transport()`。
- 存进 `monitor_icons`，有就覆盖。
- `toAPIMonitor`：有站标时填 `IconAt`。列表接口不要一条一条查，`ListMonitors` 用 `LEFT JOIN monitor_icons` 只取 `fetched_at`，或者另加一个查询一次取全部 `monitor_id, fetched_at`。
- `GetMonitorIcon`：从 `pending.go` 挪到 `icons.go`。不存在回 404。响应头：`Content-Type` 用存的类型，`Cache-Control: private, max-age=604800`（前端地址带 `?v=`，换了图标地址就变），`X-Content-Type-Options: nosniff`。SVG 另加 `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; sandbox`，防止 SVG 里的脚本执行。
- 测试：用 `httptest` 起一个网站，页面里有 `<link rel="icon" href="/i.png">`，检查能存下来、接口能取到；没有 `link` 时取 `/favicon.ico`；图标超过 64 KB 时不存；SVG 响应带上面的 CSP 头；删除监控后站标一起删掉。
