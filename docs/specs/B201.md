# B201 早睡早起自动打卡

2026-10-14 用户提的：“我想养成早睡早起。”

## 要什么

早睡、早起这两个习惯不用每天手动点。睡着、起床的时间达到设定就自动打卡。

## 做法

- 习惯加 `autoCheck`：`kind` 是 `bedtime`（几点前睡着）或 `wake`（几点前起床），`before` 是 `HH:MM`。改习惯时传 `none` 关掉。迁移给 `habits` 加 `auto_check`、`auto_before`。
- 数据来自“我的状态”（B162）。它判断起床时发出 `me.woke`，里面有这一晚的入睡和起床时间。习惯模块收到后：
  - 推测出来的（`guessed`）不算，不到 3 小时的睡眠当午睡，不算。
  - 起床：起床时间不晚于设定就打卡，记在起床那天。
  - 入睡：按中午到第二天中午算一晚，所以 00:30 比 23:30 晚。不晚于设定就打卡，记在上床的那个晚上（过了零点睡着也记在前一天）。
  - 那天已经有打卡（手动打过，或者重复收到事件）就不再打。
  - 来源记 `me`，备注写“23:10 睡着”“07:05 起床”。
- 自动打卡的习惯每天目标固定是 1，只能用在普通习惯上，不能和“跟着提醒走”一起用。
- 推荐习惯里加“早睡”（23:30 前睡着，23:00 提醒）和“早起”（07:30 前起床）。说明里写：从现在的作息开始，每周往前挪 15 到 30 分钟。
- 习惯卡片上显示规则，编辑窗口里可以改。
- AI 助手建习惯、改习惯时可以传 `autoCheck`。

## 没有验证的

- “我的状态”的真实入睡、起床信号（手机快捷指令、Home Assistant）还没在线上验证过，见 B162 的已知问题。收不到信号时，这两个习惯只能手动打卡。

## 验收

- 建“早睡”，设 23:30。“我的状态”报 23:10 睡着、07:05 起床，前一天的早睡自动打卡，备注“23:10 睡着”。
- 设 00:30，00:20 睡着也算，记在前一天。
- 午睡、推测的作息不打卡。同一天不重复打卡。
