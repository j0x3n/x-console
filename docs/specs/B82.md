# B82 服务器信息、IP、国家、排序

## 后端实施说明（2026-10-02）

本批只实现后端、契约和生成类型。信息编辑、国旗、密码显示计时、拖动排序由 Claude 接入。现有左栏仍按在线状态和名称排序，前端需要改为直接使用服务端顺序。前端还要订阅 host.info.updated 和 host.order.updated，并刷新主机列表与详情。

信息密码和配对侧表内容都用主密钥加密。配对码消费、代理创建和信息写入使用一个事务，失败后仍可重试。SSH 登录凭据与信息卡片密码独立保存。排序必须提交该类型全部有效主机，新机器排末尾。

代理来源接口使用有效代理令牌鉴权。XC_TRUSTED_PROXIES 支持逗号分隔的 IP 或网段，默认留空；只有直连来源命中配置才读取 X-Forwarded-For。笔记与云盘分享沿用相同规则。反向代理应重写该请求头。代理每六小时更新来源，服务端每五分钟后台刷新地址；详情请求也更新缓存，列表不发远程调用。

地址去重并过滤回环和链路本地地址。CGNAT 和文档示例地址按非公网处理。国家优先公网 IPv4，然后 IPv6。DB-IP 库异步每月更新，失败保留旧库并一小时后重试。国家中文名使用 Unicode CLDR。维护总览返回 DB-IP 来源与许可，前端需显示来源链接。


用户 2026-10-01 提的：

- 添加服务器时能填一些信息。有的是客户的服务器，要备注用户名、密码和其他注意事项。添加以后也能改。
- 服务器详情的网络卡片底部显示 IPv4、IPv6 地址。
- 根据 IP 自动显示服务器在哪个国家：服务器首页的卡片上显示；详情页显示在左上角服务器名称左边，鼠标移上去显示国家名。
- 左栏二级菜单里服务器的顺序要和服务器页一样，也能拖动排序。

## 界面

### 服务器信息

- 服务器卡片和详情页的“更多”里加“编辑信息”，打开弹窗：
  - 名称；
  - 归属：自己的、客户的（单选）。选了“客户的”再填客户名称；
  - 登录用户名、登录密码（密码框，存的时候加密）；
  - 备注（多行，Markdown，用 `MarkdownEditor`）；
  - 标签（逗号分开，比如“生产”“香港”）。
- 添加服务器时（设置 → 设备与代理 → 添加服务器，生成安装命令那一步；SSH 主机的新建弹窗）也有这几项，选填，折叠在“更多信息”里。
- 详情页概览标签加一张“信息”卡片：归属、客户、用户名、密码（显示成圆点，“显示”按钮要提升权限，显示 30 秒后自动收起，旁边“复制”）、备注、标签。没填过时卡片显示“还没填写信息”和“填写”按钮。
- 服务器卡片上：客户的服务器在名称后面有一个“客户：xxx”的小标签；有标签时显示前两个。

### IP 和国家

- 详情页网络卡片底部一行：`IPv4 1.2.3.4`、`IPv6 2001:db8::1`，各带复制按钮。有多个时都列出来，公网的在前，内网的灰字。
- 国家：
  - 服务器卡片：名称左边一个国旗。
  - 详情页：左上角面包屑“服务器 / 名称”里名称左边一个国旗，鼠标移上去提示国家名（比如“日本”）。
  - 国旗用 emoji。Windows 上浏览器不显示国旗 emoji，所以前端带一个只含国旗的字体（Twemoji 国旗字体，约 80 KB，放在 `web/public/fonts/`，按需加载）。
  - 判断不出来（内网机器、没有公网 IP）时不显示。

### 排序

- 服务器页的卡片可以拖动排序（桌面上拖卡片；手机上卡片“更多”里“上移”“下移”）。
- 左栏二级菜单按同一个顺序，不再“在线的排前面”。离线的仍然显示灰点。
- 二级菜单里也能拖动排序，拖完两边一起变。
- 电脑页（`/pc`）用同一套排序，和服务器分开排。

## 契约（`api/modules/hosts.yaml`，已改）

- `HostListItem`、`Host` 加：
  - `info: HostInfo`：`{ ownership: own|client, client?, username?, hasPassword, note?, tags[] }`；
  - `addresses: HostAddress[]`：`{ ip, family: v4|v6, public }`；
  - `country?: { code, name }`：ISO 3166 两位代码和中文名；
  - `sortOrder: integer`。
- `PATCH /hosts/{hostId}`：`HostPatch = { name?, info?: HostInfoInput }`，`HostInfoInput` 带 `password?`（不传不改）和 `clearPassword?`。改密码要提升权限。
- `GET /hosts/{hostId}/password`：返回 `{ password }`，要提升权限，写审计。
- `PUT /hosts/order`：`{ kind: server|desktop, ids: string[] }`，按给的顺序写 `sortOrder`。
- `GET /hosts` 按 `sortOrder`、再按名称排序返回。
- `core.yaml` 的 `POST /agents/pairing-codes` 请求加可选的 `info: HostInfoInput`（配对成功后写到这台机器上）。`hosts.yaml` 的 SSH 主机新建和修改加可选的 `info`。

## 后端（待做）

1. 迁移：新表 `host_info`（`host_id` 主键：代理机器用代理 id，SSH 用 `ssh:<id>`；`ownership`、`client`、`username`、`password_enc`、`note`、`tags` JSON、`sort_order`、`country_code`、`country_checked_at`）。不改原来的表。
2. 密码用 `secrets.Box` 加密。接口只返回 `hasPassword`。
3. 名称：代理机器改名写原来代理表的 `name`；SSH 主机写 `ssh_hosts.name`。
4. 地址：
   - 代理在系统信息里报网卡地址（协议 `SystemInfo` 加 `addresses`，`omitempty`，旧代理不报）。代理按网卡列出 IPv4、IPv6，去掉回环和链路本地地址。
   - 公网地址：代理每 6 小时请求一次服务端的 `GET /agent/whoami`（新的代理接口，返回服务端看到的连接来源 IP），加到列表里并标成 public。连接经过反向代理时取 `X-Forwarded-For` 的第一个（只在配置了可信代理时）。
   - SSH 主机：用连接时解析出的 IP。
5. 国家：
   - 用 DB-IP 的免费国家库（`dbip-country-lite`，CC BY 4.0，每月更新，mmdb 格式约 7 MB）。服务端第一次需要时下载到 `data/geo/`，每月更新一次；下载不了时不显示国家，不报错。用 `github.com/oschwald/maxminddb-golang` 读。
   - 只用公网 IPv4 判断，没有时用公网 IPv6。结果存 `country_code`，IP 变了重新判断。
   - 中文国家名在后端用一张表（ISO 代码 → 中文名）。
   - 页面上写来源：维护页（B79）或关于里写“IP 地理位置数据来自 DB-IP”。
6. 排序：`PUT /hosts/order` 在一个事务里更新。新加的机器排在最后。
7. 审计：改信息、看密码、改排序都记。
8. 测试：信息读写和密码加密；看密码要提升权限；排序；国家判断（用测试用的小 mmdb，`maxminddb` 官方仓库里有测试数据）；旧代理不报地址时接口照常。

## 验收

- 添加一台客户的服务器，填用户名密码和备注。详情页能看到，看密码要验证。
