# M9 Home Assistant

负责批次：1（任务卡 D）。

## 连接

- 设置：`ha.url`（如 `http://homeassistant.local:8123`）、`ha.token`（长期访问令牌，加密存）。
- 面板服务器在公网，HA 在家里。两种接法，文档里都要写清楚：
  1. HA 有公网地址（Nabu Casa 或自己的反代）：直接填。
  2. 没有公网地址：HA 所在网络里有一台装了代理的机器时，走代理转发。代理端提供 `http.proxy` 方法（请求/响应）和 `ws.proxy` 流方法，服务端通过它访问 HA。设置里选“通过代理 <名称> 访问”。先实现方式 1，方式 2 作为同一任务卡的第二步。
- 用 HA 的 WebSocket API（`/api/websocket`）：认证后 `subscribe_events` 订阅 `state_changed`，`get_states` 取全量，`call_service` 调服务。断线自动重连，间隔 1 秒起步翻倍，最长 1 分钟。
- 内存里保存全部实体的最新状态。

## 接口

| 方法 | 路径 |
| --- | --- |
| GET/PUT | `/ha/config`（令牌打码返回） |
| POST | `/ha/test` |
| GET | `/ha/status`（连接状态、HA 版本、实体数） |
| GET | `/ha/states?domain=&q=` |
| GET | `/ha/states/{entityId}` |
| POST | `/ha/services/{domain}/{service}`（`{entityId?, data?}`） |
| GET/PUT | `/ha/favorites` |

## 事件

- `ha.state_changed`：数据是 `contracts.HAState`，只转发收藏实体和被习惯、自动化引用的实体（避免刷屏）。其余实体变化只更新内存。
- 其他模块用 `contracts.HomeAssistant.WatchEntity(entityID)` 注册需要转发的实体（M8 习惯、M12 自动化）。
- `ha.connection_changed`：`{connected}`。

## 对外

- 提供 `contracts.HomeAssistant`。
- 动作：`ha.list_entities`（read）、`ha.get_state`（read）、`ha.call_service`（write；domain 是 lock、alarm_control_panel、cover 的 open 时算 dangerous）。

## 前端 `features/home`

- 收藏区：大按钮卡片，灯和开关点一下切换，温度计显示读数，场景点一下执行。
- 全部实体：按域分组，可搜索，可加入收藏。
- 未配置时显示设置引导。
- 设置页加“Home Assistant”标签：地址、令牌、测试连接、连接方式。

## 验收

- 用一个假的 HA WebSocket 服务器（测试里用 httptest + coder/websocket 实现认证、get_states、subscribe_events、call_service）跑通：连接、取状态、调服务、收到状态变化事件、断线重连。
- 令牌错误时显示明确的错误信息。
