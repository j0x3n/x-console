# M11 个人生活：日历、早报、番茄钟

负责批次：2（任务卡 G）。早报依赖多个 contracts，取不到的部分就跳过。

## 日历

| 表 | 列 |
| --- | --- |
| `calendars` | id、name、kind（ics/caldav）、url、username、secret（加密）、color、enabled、last_synced_at、last_error |
| `calendar_events` | id、calendar_id、uid、title、start、end、all_day、location、description、rrule、recurrence_id |

- 每 15 分钟同步一次。ICS 用 `github.com/arran4/golang-ical` 解析，重复事件在查询时按范围展开（rrule-go）。
- CalDAV 用 `github.com/emersion/go-webdav/caldav`，先只读。
- 接口：`/calendars` CRUD，`POST /calendars/{id}/sync`，`GET /calendar/events?from=&to=`。
- 提供 `contracts.Calendar`，动作 `calendar.events`（read）。
- 前端 `features/calendar`：日视图和周视图，手机默认日视图。

## 每日早报

- 设置：`brief.time`（默认 `08:00`）、`brief.channels`（走哪些渠道，默认按路由规则）、`brief.location`（天气城市的经纬度）、`brief.sections`（启用哪些部分）。
- 内容：天气（Open-Meteo，无需密钥）、今日日程、今天和逾期的 Issue、今天的提醒、昨天的服务器告警、习惯昨天的完成情况和今天目标、续费提醒（M10 有的话）。
- 每部分由一个函数生成，拿不到数据（contracts 取不到或出错）就跳过这部分，不影响其他部分。
- 生成的内容存表 `briefs`（date、content Markdown、sent_at），面板里能看历史。
- 发送用 `notify.Send`，kind `brief.daily`。
- 可选：设置里打开“用 AI 润色”后，把原始内容交给 Claude 生成一段简短的中文总结放在最前面（用 M12 的 Claude 客户端；M12 未完成时隐藏这个开关）。
- 接口：`GET /briefs`、`GET /briefs/{date}`、`POST /briefs/generate`（立即生成一份预览）、`GET/PUT /briefs/settings`。
- 天气单独提供 `GET /weather`，M1 首页用。

## 番茄钟

| 表 | 列 |
| --- | --- |
| `focus_sessions` | id、issue_key、started_at、ended_at、planned_minutes、actual_seconds、completed、note |

- 服务端只记录。计时在前端，但开始和结束都要调接口，这样换设备也能看到正在进行的番茄钟。
- 结束时间到了由服务端发通知（kind `focus.done`），防止页面关掉后收不到。
- 接口：`POST /focus/start`、`POST /focus/{id}/stop`、`GET /focus/current`、`GET /focus/stats?days=`。
- 前端：页头按钮（`app/TopbarActions.tsx` 加一行），显示剩余时间；点开可选关联 Issue。Issue 详情页也能开始番茄钟（给 M5 页面加一个按钮，改动尽量小）。

## 验收

- ICS 测试文件含重复事件，周视图展开正确，时区正确。
- 早报在所有依赖模块都缺失时仍能生成（只有天气和日期）。
- 番茄钟开始后关闭页面，到点收到通知。
