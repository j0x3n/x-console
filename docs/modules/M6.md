# M6 备忘

负责批次：1（任务卡 A）。

## 数据

| 表 | 列 |
| --- | --- |
| `notes` | id、title、body（Markdown）、pinned、archived_at、created_at、updated_at |
| `note_tags` | note_id、tag |
| `notes_fts` | FTS5 虚拟表，列 title、body，content=notes，用触发器同步 |

中文分词：FTS5 默认分词器不切中文。用 `trigram` 分词器（`tokenize='trigram'`），三个字以上能匹配。一两个字的查询退回 `LIKE`。

sqlc 可能解析不了 FTS5，这部分查询直接用 `database/sql` 写。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/notes?q=&tag=&pinned=&cursor=&limit=` | 有 q 时按相关度排序并返回高亮片段 |
| POST | `/notes` | |
| GET/PATCH/DELETE | `/notes/{id}` | |
| GET | `/notes/tags` | 所有标签及数量 |
| POST | `/notes/{id}/to-issue` | `{projectId}`，用 contracts.Issues 创建，并在笔记里记下链接 |
| POST | `/notes/{id}/to-reminder` | `{at, rrule?}`，用 contracts.Reminders |

## 事件

`note.created/updated/deleted`。

## 对外

- 提供 `contracts.Notes`。
- 动作：`notes.search`（read）、`notes.create`（write）、`notes.append`（write，往已有笔记末尾追加）。

## 前端 `features/notes`

- 左边列表（置顶在前、标签筛选、搜索框），右边编辑器。手机上两栏切换。
- 编辑自动保存（停止输入 800 毫秒后），显示“已保存”。
- Markdown 预览切换。
- 快速记录：命令面板输入 `> 内容` 直接存成新笔记；也可以用页头按钮。
- 笔记菜单：转 Issue、转提醒、置顶、归档、删除。

## 验收

- 中文三字词能搜到，两字词也能搜到（走 LIKE）。
- 自动保存不丢字：快速连续输入后刷新，内容完整。
- 转 Issue 后，笔记里出现 Issue 链接，Issue 的关联里也能看到这条笔记。
