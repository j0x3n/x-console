# M0 基础（已完成）

## 已有能力

| 能力 | 代码 |
| --- | --- |
| 初始化、登录、退出、TOTP、提升权限 | `internal/server/auth`，接口在 `api/modules/core.yaml` |
| 审计日志 | `internal/server/audit`，`GET /audit` |
| 加密存储 | `internal/server/secrets`、`internal/server/settings` |
| 事件总线和浏览器推送 | `internal/server/events`、`internal/server/ws`，`GET /events`（WebSocket） |
| 定时任务 | `internal/server/scheduler` |
| 通知中心 | `internal/server/notify`，`GET /notifications` 等 |
| 代理配对和连接 | `internal/server/agenthub`，`POST /agents/pairing-codes`、`POST /agent/pair`、`GET /agent/connect` |
| 动作目录 | `internal/server/actions` |
| 跨模块接口 | `internal/server/contracts` |
| 测试工具 | `internal/server/testutil` |
| 前端外壳 | 登录、初始化、侧边栏、页头、命令面板、通知弹层、提升权限弹窗、设置页（通用、设备、审计） |

## 表

`users`、`sessions`、`audit_log`、`settings`、`agents`、`pairing_codes`、`notifications`。见 `store/migrations/20260927000000_m0_core.sql`。

## 事件

| 主题 | 数据 |
| --- | --- |
| `agent.paired` / `agent.online` / `agent.offline` / `agent.revoked` | `{agentId}` |
| `notification.created` | 通知对象 |
| `notification.delivery_failed` | `{id, channel, error}` |

## 已知限制

- 同一个 TOTP 码在 30 秒窗口内可以重复使用。
- 只支持一个用户。
