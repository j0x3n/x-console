# M2 服务器 与 M3 本机

负责批次：1（任务卡 C）。M10 的 Docker 页面在这之上做。

两个模块共用一个后端模块 `modules/hosts`，前端分成 `features/servers`（kind=server）和 `features/pc`（kind=desktop）。

## 代理端方法

写在 `pkg/protocol/methods_hosts.go`，实现放 `internal/agent/{metrics,proc,svc,pty,files,exec,clipboard,power}`。指标用 gopsutil。

| 方法 / 事件 | 类型 | 说明 |
| --- | --- | --- |
| `metrics`（事件） | 事件 | 每 10 秒一次：CPU%、每核 CPU%、内存已用/总量、交换区、每个挂载点的磁盘用量、网络收发速率、磁盘读写速率、load1/5/15、开机时长、进程数 |
| `system.info` | 请求 | 用 gopsutil 补全 `protocol.SystemInfo` |
| `proc.list` | 请求 | 参数：排序字段、条数。返回 pid、名称、用户、CPU%、内存、命令行、启动时间 |
| `proc.kill` | 请求 | pid、信号（Windows 只支持结束） |
| `svc.list` | 请求 | systemd 单元或 Windows 服务：名称、描述、状态、是否开机启动 |
| `svc.action` | 请求 | start、stop、restart、enable、disable |
| `svc.logs` | 请求 | 最近 N 行（journalctl -u / Windows 事件日志可以先返回 unsupported） |
| `pty.open` | 流 | 参数：shell（可空）、cols、rows、cwd。Linux 用 creack/pty，Windows 用 ConPTY |
| `files.list` | 请求 | 路径下的条目：名称、类型、大小、修改时间、权限 |
| `files.read` | 流 | 下载。代理分块发送，每块 64 KB |
| `files.write` | 流 | 上传。服务端分块发送，结束后代理回一个确认 |
| `files.remove` / `files.mkdir` / `files.rename` | 请求 | |
| `exec.run` | 请求 | 命令、超时（默认 60 秒，最长 30 分钟）、工作目录。返回退出码、stdout、stderr（各最多 1 MB） |
| `clipboard.get` / `clipboard.set` | 请求 | 只在 desktop。文本 |
| `power.action` | 请求 | lock、sleep、shutdown、restart。只在 desktop |
| `app.open` | 请求 | 打开程序或网址。只在 desktop |

### 终端流的格式

代理和服务端之间的流里，每块数据第一个字节是类型：

- `0`：终端数据
- `1`：窗口大小，后面是 JSON `{"cols":120,"rows":32}`

浏览器和服务端之间的 WebSocket：二进制帧是终端数据，文本帧是 JSON 控制消息 `{"type":"resize","cols":..,"rows":..}`。

## 后端 `modules/hosts`

### 表

| 表 | 列 |
| --- | --- |
| `host_metrics_1m` | agent_id、at、cpu、mem_used、mem_total、disk_json、net_rx、net_tx、load1 |
| `host_metrics_1h` | 同上，按小时汇总 |
| `ssh_hosts` | id、name、address、port、username、auth（key/password）、secret（加密）、created_at |
| `alert_rules` | id、host_id（空表示所有）、metric（cpu/memory/disk/offline）、op、threshold、duration_seconds、severity、enabled |
| `alert_events` | id、rule_id、host_id、fired_at、resolved_at、message |

内存里为每台机器保留最近 1 小时的 10 秒原始数据（环形缓冲），每分钟落一条 1m 数据，每小时落一条 1h 数据。定时清理过期数据。

### 接口

`{id}` 是 agent id，SSH 主机用 `ssh:<数字>`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/hosts` | 所有机器及最新指标 |
| GET | `/hosts/{id}` | 详情：系统信息、最新指标、能力 |
| GET | `/hosts/{id}/metrics?range=1h\|24h\|7d` | 曲线数据 |
| GET | `/hosts/{id}/processes` | |
| POST | `/hosts/{id}/processes/{pid}/kill` | 要提升权限 |
| GET | `/hosts/{id}/services` | |
| POST | `/hosts/{id}/services/{name}/{action}` | stop、disable 要提升权限 |
| GET | `/hosts/{id}/services/{name}/logs?lines=200` | |
| GET（WS） | `/hosts/{id}/terminal?cols=&rows=` | 要提升权限（在升级前检查） |
| GET | `/hosts/{id}/files?path=` | |
| GET | `/hosts/{id}/files/content?path=` | 下载 |
| PUT | `/hosts/{id}/files/content?path=` | 上传，要提升权限 |
| DELETE | `/hosts/{id}/files?path=` | 要提升权限 |
| POST | `/hosts/{id}/exec` | 要提升权限 |
| GET/PUT | `/hosts/{id}/clipboard` | |
| POST | `/hosts/{id}/power` | shutdown、restart 要提升权限 |
| POST | `/hosts/{id}/open` | |
| CRUD | `/ssh-hosts` | 保存和测试 SSH 连接 |
| CRUD | `/alert-rules` | |
| GET | `/alerts?since=` | 告警历史 |

SSH 主机只支持：终端、exec、基础指标（通过 exec 读 /proc，可以 1 分钟一次）。用 `golang.org/x/crypto/ssh`。

### 事件

| 主题 | 数据 |
| --- | --- |
| `host.metrics` | `{hostId, sample}`，每台机器最多 10 秒一次 |
| `host.alert.fired` / `host.alert.resolved` | 告警对象 |
| `host.process.killed`、`host.service.changed` | |

### 对外

- 提供 `contracts.Hosts`。
- 注册动作：`hosts.list`（read）、`hosts.get_metrics`（read）、`hosts.service_action`（dangerous）、`hosts.exec`（dangerous）、`hosts.clipboard_set`（write）、`hosts.power`（dangerous）、`hosts.open`（write）。
- 告警触发时调用 `Notify.Send`，kind 为 `host.alert`，优先级 high。

## 前端

- `features/servers`：列表页（卡片或表格，显示 CPU/内存/磁盘小条和在线状态），详情页标签：概览（曲线）、进程、服务、终端、文件、告警。
- `features/pc`：只显示 kind=desktop 的机器（通常只有一台，直接进详情）。额外有剪贴板和快捷操作卡片。
- 终端用 `@xterm/xterm` 和 `@xterm/addon-fit`。
- 实时指标用 `useServerEvent("host.metrics", ...)` 写进 Query 缓存。
- 曲线可以用 `components/ui/LineChart` 或加一个轻量库，比如 uPlot。

## 验收

- 本地起服务端和一个 Linux 代理，列表 10 秒内出现数据。
- 终端能跑 `top`，调整窗口大小后显示正常。关闭页面后代理端 shell 进程退出。
- 未提升权限时打开终端、结束进程返回 403 elevation_required，前端弹出验证框，验证后自动继续。
- `GOOS=windows go build ./cmd/agent` 通过。Windows 专属实现有单元测试（能在 Linux 上跑的部分）。
- 断开代理后页面显示离线和最后在线时间，离线告警规则能触发通知。
