# M5 项目

负责批次：1（任务卡 A）。Linear 同步在批次 2 由任务卡 H 做。

## 数据

| 表 | 列 |
| --- | --- |
| `projects` | id、key（2 到 5 个大写字母，如 XC）、name、description、color、icon、archived_at、next_number、created_at、updated_at |
| `issues` | id、project_id、number、title、description（Markdown）、status、priority（0 无、1 紧急、2 高、3 中、4 低）、due_date、milestone_id、sort_order（浮点，看板内排序）、external_source、external_id、created_at、updated_at、completed_at |
| `labels` | id、project_id（空表示全局）、name、color |
| `issue_labels` | issue_id、label_id |
| `milestones` | id、project_id、name、due_date、created_at |
| `issue_links` | id、issue_id、kind、title、url、ref、created_at |
| `issue_comments` | id、issue_id、body、created_at（先做简单评论，用于记录进展） |

状态固定为：`backlog`、`todo`、`in_progress`、`in_review`、`done`、`canceled`。Issue 的 key 是 `<项目 key>-<number>`。

`external_source`、`external_id` 给 Linear 同步用，本批次只建列。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/projects` | |
| GET/PATCH/DELETE | `/projects/{projectId}` | 删除改为归档 |
| GET | `/issues` | 过滤：projectId、status（可多个）、priority、labelId、milestoneId、due（today/week/overdue）、q（标题搜索）。排序：updated、priority、due、manual |
| POST | `/projects/{projectId}/issues` | |
| GET/PATCH/DELETE | `/issues/{key}` | PATCH 可以改任意字段 |
| POST | `/issues/{key}/move` | 看板拖动：`{status, beforeKey?, afterKey?}`，服务端算 sort_order |
| GET/POST | `/issues/{key}/comments` | |
| GET/POST/DELETE | `/issues/{key}/links` | |
| CRUD | `/projects/{projectId}/labels`、`/projects/{projectId}/milestones` | |

## 事件

`project.created/updated/archived`，`issue.created/updated/deleted`（数据为 Issue 对象），`issue.status_changed`（`{key, from, to}`）。

## 前端 `features/projects`

参考旧代码里的看板和列表：`git show 3215f0f:src/features/work/components/WorkBoard.tsx` 等，样式 `styles/workspace/work-board.css`、`work-list.css` 还在。

- `/projects`：项目列表和“我的 Issue”（跨项目，按截止日期）。
- `/projects/:projectKey`：切换看板和列表。筛选栏：状态、优先级、标签、里程碑、搜索。列表可按状态或优先级分组。
- `/projects/:projectKey/:number` 或抽屉：Issue 详情。Markdown 编辑和预览（先用 textarea + 预览，不必上富文本编辑器）。右侧属性面板。下方是关联（PR、编码任务、笔记）和评论。
- 看板拖动排序，乐观更新，失败回滚。
- 键盘：`C` 新建，`J/K` 上下，`Enter` 打开，`E` 编辑标题，`1-6` 改状态，`Esc` 关闭。
- Issue 详情有“交给编码助手”按钮：调用 `POST /coding/tasks`（M4 还没好时按钮置灰并提示）。
- 命令面板：“新建 Issue”“跳到 Issue …”（输入 key）。

## 验收

- 新建项目、建 Issue、拖动看板、改状态后刷新仍正确。
- 两个浏览器窗口同时打开，一边改，另一边 1 秒内更新（事件推送）。
- key 在项目内连续递增，删除后不复用。
- 列表 500 条 Issue 时滚动流畅。
