# M10 运维监控

负责批次：2（任务卡 F）。依赖 M2 的 hosts 模块和代理。

## 四个部分

### 1. Docker

- 代理端方法（`methods_docker.go`，实现 `internal/agent/docker`，用 Docker Engine API over unix socket，直接用 net/http 调，不引入完整 SDK 也可以）：`docker.ps`、`docker.action`（start/stop/restart/remove）、`docker.logs`（流，支持 follow）、`docker.stats`、`docker.images`。
- 代理检测到 `/var/run/docker.sock` 可访问时上报 `docker` 能力。
- 前端：在服务器详情页加“容器”标签（修改 `features/servers` 的标签列表，一行）。

### 2. 脚本库

| 表 | 列 |
| --- | --- |
| `scripts` | id、name、description、shell（bash/sh/powershell）、body、default_host_ids（JSON）、timeout_seconds、created_at、updated_at |
| `script_runs` | id、script_id、host_id、started_at、finished_at、exit_code、stdout、stderr、triggered_by（user/automation/ai） |

- 执行通过 `contracts.Hosts.Exec`，要提升权限。可以一次选多台机器并行跑。
- 接口：`/scripts` CRUD，`POST /scripts/{id}/run`（`{hostIds}`），`GET /scripts/{id}/runs`，`GET /script-runs/{id}`。
- 动作：`scripts.list`（read）、`scripts.run`（dangerous）。

### 3. 网站、证书、域名

| 表 | 列 |
| --- | --- |
| `monitors` | id、kind（http/tls/domain）、name、target（URL 或域名）、interval_seconds、expected_status、keyword、timeout_ms、enabled、last_status、last_checked_at、created_at |
| `monitor_results` | id、monitor_id、at、ok、status_code、latency_ms、error、detail（JSON：证书到期、域名到期） |

- http：GET 目标，检查状态码和可选关键词。连续失败 2 次发告警，恢复后发恢复通知。
- tls：握手取证书到期时间，剩 14 天、7 天、3 天各提醒一次。
- domain：RDAP 查到期时间（`https://rdap.org/domain/<域名>`），剩 30 天、7 天提醒。每天查一次。
- 结果保留 30 天。
- 接口：`/monitors` CRUD，`POST /monitors/{id}/check`，`GET /monitors/{id}/results?range=`。
- 事件：`monitor.down`、`monitor.up`、`monitor.expiring`。

### 4. 订阅与续费

| 表 | 列 |
| --- | --- |
| `subscriptions` | id、name、category（server/domain/saas/other）、amount、currency、cycle（monthly/yearly/custom_days）、next_renewal、remind_days_before（JSON，如 `[7,1]`）、url、note、auto_renew、archived_at |

- 每天检查，按 remind_days_before 发提醒。
- 过了续费日且是自动续费的，自动把 next_renewal 往后推一个周期。
- 接口：`/subscriptions` CRUD，`GET /subscriptions/summary`（按月和按年折算的总支出）。

## 前端 `features/monitoring`

标签页：网站、证书与域名、脚本、订阅。每个都是列表 + 新建弹窗 + 详情（历史曲线或运行记录）。

## 验收

- http 监控用 httptest 模拟宕机和恢复，各收到一次通知。
- 脚本在两台假代理上并行执行，结果分别记录。未提升权限时拒绝。
- 订阅续费提醒在提前 7 天和 1 天各发一次，不重复发。
