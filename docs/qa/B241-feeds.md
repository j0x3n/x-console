# B241 资讯：界面检查记录

2026-10-17，本地服务端加前端，1360px 和 390px，浅色主题。用真实的代理和 `deploy/feeds-api/feeds_api.py` 跑通了整条链路：在本机配对一个代理，小接口读一个和 ai-news 结构一样的演示库（60 条新闻，其中 20 条有正文和译文）和 30 条推文。

截图只在本地看，没有提交（仓库是公开的）。

## 看过的页面

- 新闻 `/feeds`：工具栏左边是分类、时间两个下拉框和“只看重要的”“只看推过的”，右边是搜索框。每条新闻有中文标题、来源、分类、时间、摘要（最多 3 行）、重要度、Telegram 标记和标签，右边是“打开原网页”和“存进稍后读”。二级菜单是新闻、推文和最近 30 天最多的标签。
- 新闻详情 `/feeds?item=58`：宽弹窗，有来源链接、原标题、摘要、标签、译文和原文切换、正文，底部是“打开原网页”和“存进稍后读”。
- 推文 `/feeds/tweets`：左边是作者筛选框，右边是搜索框。正文保留换行，引用推文按原样显示。点作者名会按账号筛选。二级菜单不显示新闻的标签。
- 设置 → 资讯：机器、接口地址、接口令牌，安装步骤默认收起，“关闭”“测试连接”“保存”在右下角。
- 没配置时新闻页和推文页显示“资讯还没配置”和“去设置”。

## 结果

- `npm run shots -- --only /feeds,/feeds/tweets,/settings/feeds` 通过，两个宽度都没有横向溢出，没有页面报错。详情弹窗用临时脚本登录后截的。
- 第一次截图时两个下拉框占满一整行、上下叠着，已改成按内容宽度排在一行。推文页的作者框比搜索框高 2px，已改成一样高。
- 经过真实代理调接口：中文关键词走 LIKE，英文走 FTS，都能搜到；带多余参数的请求，多余的参数不会转给小接口。
