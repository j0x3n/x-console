# B166 降水提醒合并检查

2026-10-12，直接在 develop 修改。

## 改动

天气设置用一个“降水提醒”开关。提醒方式可选“按分钟预报（雨或雪）”和“按降水概率”，只显示当前方式的参数。

沿用现有接口。保存时先关闭另一种方式，再保存选中的方式。两步之间查询刷新不会覆盖用户正在保存的表单。失败后保留选择并允许重试。

旧配置两项都开时，界面优先显示分钟预报。后端概率提醒在分钟提醒开启时直接跳过，部署后立即生效。

## 部署检查发现的修正

第一次部署的端到端第一部分在取消后立即重开时读到未保存的开关状态。表单原来在 useEffect 中初始化，可能晚于弹窗首次显示。改用 useLayoutEffect，在显示前恢复服务端设置。

修正后，在本机连续三次运行完整浏览器流程，打开操作没有增加延迟，全部通过。第一次部署的前后端检查、模块测试、第二部分端到端和镜像构建均通过，线上部署因第一部分失败而跳过。
