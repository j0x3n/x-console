# B167 检查和构建提速验证

2026-10-12，本机 Windows、Node 22.23.3、Chromium 153、Docker Desktop 29.5.3。

## 已完成

- CI 使用 `toJSON(inputs.race) != 'false'`。部署显式 false 时关闭，PR 或手动 CI 缺参数时开启，避免 GitHub 表达式把空值当 false。
- 镜像先编译无提交号程序，再写当前版本。Go 编译缓存存在镜像编译层内，沿用 Actions 的 mode=max 层缓存。
- 代理单独阶段只复制 cmd/agent、internal/agent、pkg 和依赖文件。Actions 下载产物改为从镜像提取，保留原有 Linux、Windows artifact 名称。
- `.dockerignore` 排除本地数据库、依赖和构建输出。原本本机 backend/data 被复制进编译层，数据库更新会使缓存失效。
- `npm run check:weather` 自动起临时 Go 服务与 Vite，复用天气提醒浏览器流程，检查桌面和手机。无需完整前端构建和代理编译。
- 浏览器页面异常立即失败并记录正文、截图和近期进程日志。预期的接口 500 不会被当成页面异常。
- 快速检查支持 --worktree。新增脚本语法、Node 测试、流水线回归检查和每步耗时。CI 端到端也开启阶段耗时输出。

## 实测

- 独立天气浏览器检查通过，脚本计时 14.7 秒，含编译、启动和完整操作。设置读写用真实 Go 服务和临时 SQLite，天气展示用模拟响应。
- 4 个诊断测试通过。其中真实 Chromium 故意抛出脚本错误，两秒内结束等待。整体测试含浏览器启动和关闭约 2.9 秒。
- actionlint、脚本语法、构建流程回归、格式、类型检查通过。依赖齐全时快速检查约 4 到 5 秒。最终一轮因 package.json 变化安装依赖，检查用时 14 秒，其中安装 9 秒。
- 代理第一次编译四个平台用 20.6 秒，换版本号后编译层 CACHED，写入新版本只用 1.2 秒。linux amd64 version 输出 b167-b，四个 SHA256SUMS 均检查通过。
- 服务端第一次编译 22.4 秒，换版本号后编译层 CACHED，写入版本 1.3 秒。临时数据库启动后的健康接口返回 status=ok、version=b167-b。
- 最终 .dockerignore 加入后构建成功，上下文传输 111.45 kB、0.1 秒。此前带本地输出时为 67.33 MB、5.1 秒。Docker 增量传输值不代表完整源码大小。

## 限制

只测服务端和代理镜像阶段，没有重复完整前端镜像构建。没有触发线上部署，Actions 缓存下载上传时间和实际提速等下一次部署测。第一次 Actions 构建需要建立新的编译层缓存。

Actions 代理 artifact 的上传流程经 actionlint 和回归检查确认，未在远程 runner 执行。未改任何产品界面。
