# B168 页头播放器改版检查

2026-10-12，直接在 develop 修改，Claude 做。

## 改动

- 页头默认只有一个播放按钮。点了开始播放并展开封面、暂停、下一首，最右边的小箭头收起。收起时如果在播放，按钮显示三根跳动的竖条。展开状态记在本地。
- 点封面弹出迷你播放器：封面、歌名、进度、上一首、播放暂停、下一首、播放模式、定时、歌词（当前行居中高亮，点一行跳过去）、音量、全屏。底部按钮展开或收起播放列表。上半部分用模糊的封面做很淡的底色。
- 固定和关闭沿用以前的逻辑。页头上单独的队列、歌词按钮和小组件去掉了，都并进迷你播放器。
- 系统媒体控制：以前 `setPositionState` 只在播放时间比上次大 1 秒以上时才调，换歌和往回拖以后不再更新，Windows 媒体浮窗的进度是错的。现在换歌、读到时长、播放、暂停、拖动、改速度时都马上更新，播放中每 5 秒校准一次。没有时长时清空。`seekto` 支持 `fastSeek`。

## 检查结果

- 页头播放器测试 7 条通过：展开收起、点封面开迷你播放器、列表展开收起、固定后点别处不收起、暂停、进度同步。
- 起本地服务端和前端，用 Chrome 截了 1360 和 390 宽的收起、展开、迷你播放器、迷你播放器加列表四种状态，没有横向溢出和页面报错。用的是假歌曲和模拟歌词，没有真实播放。
- 没有在真实 Windows 媒体浮窗里拖过进度，上线后要确认。
