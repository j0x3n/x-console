# B242 笔记导出图片：检查记录

2026-10-17，Claude Opus 5.5。本地起服务端和前端，用 Chromium 实际导出。

## 做了什么

- 造了一篇黄色背景的笔记：标题、标签、二级标题、加粗、斜体、待办、引用、长代码、表格、隐藏块、提示块、站内图片附件、一张读不到的外链图片、一个视频。
- 打开“更多 → 导出图片”，点“保存图片”。

## 结果

- 下载的文件是 PNG，宽 1080，高 2901，文件名 `周末爬山计划-20261017.png`。
- 背景是笔记的黄色。站内图片正常画进去了。外链图片显示灰色方块“图片无法导出”，弹窗下面写“有 1 张图片没导出”。视频显示成“视频：视频”。
- 长代码在图片里换行，表格没有超出 400 宽。
- 隐藏块默认不出现。勾上“隐藏块的内容”后直接展开，没有“点击显示”按钮。勾上标签和底部字样后都出现了。
- 把界面切成深色再导出，图片还是浅色。第一次代码块是黑底，原因是 `--xc-panel` 没固定成浅色，已补上，再导出是浅色。
- 弹窗在 1360 和 390 宽各截一张。390 宽下预览框一开始太高，按钮被挤到屏幕边上，已把手机上的预览高度改成 38dvh。
- 页面没有报错。`npm run shots -- --only /notes` 没有横向溢出。

## 没验证的

- 中文加粗在这台开发机上看不出粗细，是容器里的中文字体没有粗体。真机上的苹方、微软雅黑有粗体，没在真机上看过导出效果。
- 手机上的“分享”（系统分享面板）和电脑上的“复制图片”只写了，没在真机和真实剪贴板上试过。截图用的无头浏览器不算手机，显示的是“复制图片”和“保存图片”。
- iOS Safari 的 canvas 上限按 1600 万像素算，没在 iPhone 上试过超长笔记。
