# B234 网站自动化卡片和截图清理：界面检查记录

2026-10-15，本地服务端加前端，1360px 和 390px，浅色主题。数据是直接写进本地数据库的：4 个任务（正常、需要登录、AI 在摸索、X），一个任务有 16 次运行（8 次一样的失败、一次成功、一次保活失败等）、29 张截图、7 条变化。

截图只在本地看，没有提交（仓库是公开的）。

## 看过的页面

- 列表页 `/monitoring/watchers`：卡片多列排，手机一列。卡片上有名字、状态、当前值（多行最多 4 行）、最近一次变化和时间、上次检查、“立即检查”和“更多”。需要登录的卡片排第一，边框是警告色。还没读到值的卡片写“AI 在找要盯的内容”。
- 详情页 `/monitoring/watchers/1`：变化先显示 5 条，下面“显示全部 7”。检查记录默认折叠，8 次一样的失败合成一行，写“同样 8 次”。标题旁写“截图 29 张，共 416 KB”和“清理截图”。展开后截图是 160px 宽的小图，点了在页面里看大图，可以左右切换这次运行的几张图，Esc 关掉。
- 清理弹窗：两个选项和取消，手机上一行放得下。
- 今日页：右边“网站自动化”卡片，等你处理的在前，每行名字、当前值一行、状态。

## 结果

- 两个宽度都没有横向溢出，没有页面报错。
- `npm run shots -- --only /monitoring/watchers,/` 通过。详情页不在脚本的页面列表里，用临时脚本登录后截的。
