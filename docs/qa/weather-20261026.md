## 原因

- `brief/extra.go` 直接保留上游分钟降水量和摘要，没有把雾或湿度换算成雨量。
- 前端 `overview/weather.ts` 与后端 `brief/weather_notify.go` 都按有效五分钟时段内的降水量大于 0 判断。因此上述弱降水会触发显示和推送。
- 后端的两小时限制是静默期。同一轮预报持续有雨时，静默期结束仍会再推，并非整轮只推一次。
- 实况、逐小时概率与分钟预报属于不同数据。实况为雾或概率较低，不能单独证明分钟预报错误。
- B165 规格明确要求保留分钟原始数据，禁止用自定的逐小时概率门槛清零。此次没有恢复该旧逻辑。

## 后续选择

- 现有功能可改用“按降水概率”提醒，减少这类弱降水推送；这不会关闭天气条里的分钟预报提示。
- 如果继续使用分钟提醒，可另定弱降水的显示与推送标准，并将同一轮降水去重。当前尚未改变这两条规则。
