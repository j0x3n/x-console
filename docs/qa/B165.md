# B165 天气降水判断检查

日期：2026-10-12。基于最新 develop `bcfaa595`，在 codex 分支修复。

## 依据与修正

- 用户提供的 `/weather/extra?refresh=true` 中有 24 个 `kind: rain, precip: 0` 点。这些点本身不能表示有雨。
- 摘要“现在是雾，未来两小时降水概率 0%，没有降水”由旧的 `rainDoubtful` 生成。旧代码会把上游非零降水量清零，因此这份本地接口返回不能还原和风原始返回。
- 删除页面和分钟降水推送中的自定概率门槛，不再改写上游数值和摘要。普通逐小时概率提醒继续使用用户设置的门槛。
- 前端忽略结束超过五分钟的点，未来时段显示未来降水。停雨时间只在连续五分钟数据中计算，数据不足时不声称两小时内不会停。
