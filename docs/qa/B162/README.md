## 自动检查

- 后端：判断规则的单元测试（每种状态、优先级、30 分钟暂离、推测睡觉的时段、跨午夜的作息、起床后不再推测、事件解析、HA 状态到事件）。集成测试用假时钟和假电脑状态，覆盖在用、空闲、30 分钟后变化，手机上报睡觉和起床，睡了不到 3 小时不算起床，令牌错误、重新生成、关闭、未知事件、`at` 越界、请求体过大，2 分钟去重，电脑在用时结束睡觉，刚躺下时电脑空闲时间不结束睡觉，手动设定到期，假 Home Assistant 的位置和睡眠传感器，手机和 HA 同时报，历史接口，清理，`contracts.Me`，动作 `me.state`，重启后状态恢复。
- 公开路径按前缀匹配，`/me/report/token` 和 `DELETE /me/report` 也在公开前缀下。测试确认它们没有登录会话时回 401，有会话没有 CSRF 头时回 403。
- 习惯模块：起床后填睡眠、已填的不改、推测的不填、按作息时区算日期。
- 前端：纯逻辑、今日卡片（状态、推测、手动、弹窗、手动设定、改回自动）、设置页（工作电脑、推测开关、令牌、Home Assistant 没连上和已连上）。今日页的卡片顺序测试加了这张卡片。
- 端到端第一部分：设置页生成令牌，用接口报 `sleep.start`，今日页卡片显示“睡觉”，在卡片上改成外出再改回自动，关闭后令牌失效。
