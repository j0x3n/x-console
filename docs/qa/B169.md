# B169 歌词和封面分开匹配检查

2026-10-12，直接在 develop 修改。后端由 Codex 写，Claude 审核并改了一处。前端由 Claude 写。

## 为什么以前只拿到 iTunes 封面

本地（国内网络）直接请求过网易云和 QQ 音乐的搜索、歌词、详情接口，都正常返回，`code` 是 200。LRCLIB 在本地超时。
线上候选里只有 iTunes，说明线上服务器请求网易云和 QQ 音乐时失败了。以前失败只打 Debug 日志，看不到原因。
另一个原因：选了只有封面的 iTunes 候选后，后端用它的英文歌手名去别的来源找歌词，再要求歌手有交集，中文歌手名对不上就找不到。

## 改动

- 新接口 `POST /music/sources/check`：每个来源并发搜一次，返回能不能用、命中数、失败原因、耗时。音乐页“在线匹配”弹窗里的“检查来源”按钮调用它。
- 网易云请求带 `X-Real-IP`，返回 `abroad: true` 或 `code` 不是 200 时报明确的原因。各来源返回格式不对时报“返回的不是预期格式（可能限制了海外访问）”。
- 来源搜索失败改成 Warn 日志。
- `parts` 只匹配歌词或只匹配封面。待确认里每个候选分开有“用歌词”“用封面”两个按钮。歌的菜单里“从其他来源选歌词”“从其他来源选封面”分开。
- 用了一个候选后，歌还缺另一样且还有候选能提供时，候选留着，状态保持待确认。
- 不再拿只有封面的候选去别的来源补歌词。
- 审核时改的一处：不传 `parts` 时候选有哪样用哪样，不再因为候选没有歌词报 400。
