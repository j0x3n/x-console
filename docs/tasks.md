# 任务看板

这是进度的唯一来源：现在做什么、下一步是什么。这个文件只放没做完的事，保持短。

- 开发者从“待做”里按顺序取第一个任务，开工前移到“进行中”，写上自己的名字。
- 做完的任务从看板删掉，在 [tasks-done.md](tasks-done.md) 的“已完成”表加一行，写上提交号。
- 接口和基础代码的变更记在 [api-changes.md](api-changes.md)。
- 大任务的做法和验收标准在 `docs/specs/` 里。小任务直接写在这里。
- 用户提的新需求，由审查者加到“待做”末尾（编号顺延），需要时写规格文件。
- 看板超过 150 行时，先把做完的挪走再加新内容。
